# Слоги и ударение

Модуль `ruts.syllables` делит русское слово на слоги и находит его ударный слог: слоги - по правилам, ударение - по словарю [`StressDict`](datasets/stressdict.md). На этих функциях построены базовые, фонетические и стиховедческие статистики и формулы удобочитаемости. Знаки ударения и мягкие переносы в слове снимаются (`ruts.utils.strip_marks`), а ударение по знаку (за́мок, замо́к) важнее словаря.

## Деление на слоги { #syllabify }

``` {.python .signature}
syllabify(word)
```

Деление слова на слоги по правилу восходящей звучности (Аванесов): слогов столько, сколько гласных, у слова без гласных (в, к, с) слогов нет. Граница слога проходит по правилам:

| Правило | Пример |
| :------ | :----- |
| одиночный согласный между гласными отходит к следующему слогу | ко-ро-ва, ра-йон |
| сочетание шумных и шумного с сонорным отходит к следующему слогу | ко-шка, се-стра, о-ткрыть, по-зна-ко-мить |
| сонорный перед шумным отходит к предыдущему слогу | кар-та, пол-ка |
| между двумя сонорными проходит граница | вол-на, кар-ман |
| й перед согласным отходит к предыдущему слогу | май-ка, вой-на |
| ь и ъ отходят к предыдущей букве | боль-шой, по-дъезд |
| каждая гласная зияния образует свой слог | а-э-ро-порт, а-ист |

Деление орфографическое, по буквам, как в школьной фонетике; составное слово делится по частям (`со-рок-во-ро-вка`).

| Параметр | Тип | По умолчанию | Описание |
| :------- | :-- | :----------- | :------- |
| `word` | `str` | - | Слово |

Исключения:

- `SourceTypeError` - слово, которое не строка.

=== "Код"

    ``` python
    from ruts.syllables import syllabify

    syllabify("здравствуйте")
    ```

=== "Результат"

    ```
    ['здра', 'вствуй', 'те']
    ```

## Ударный слог { #word_stress }

``` {.python .signature}
word_stress(word, stress_dict=None)
```

Номер ударного слога слова, считая с нуля: по букве ё, у односложного слова - единственный слог, иначе по словарю (пункт 1 [алгоритма](stats/verse_stats.md#algorithm) стиховедческих статистик); у составного слова - последнее из ударений [`word_stresses`](#word_stresses).

| Параметр | Тип | По умолчанию | Описание |
| :------- | :-- | :----------- | :------- |
| `word` | `str` | - | Слово |
| `stress_dict` | `StressDict` | `None` | Словарь ударений; по умолчанию `StressDict()` |

Возвращает `None`, если слово не найдено или в нем нет гласных.

Исключения:

- `SourceTypeError` - слово, которое не строка, словарь ударений другого типа;
- `DatasetNotFoundError` - словарь ударений не загружен.

=== "Код"

    ``` python
    from ruts.syllables import syllabify, word_stress

    word_stress("корова"), word_stress("ещё"), word_stress("желанье"), word_stress("кто-нибудь")
    word_stress("за́мок"), word_stress("замо́к"), word_stress("сорок-воровка")
    word_stress("хмурота"), word_stress("в")
    syllabify("корова")[word_stress("корова")]
    ```

=== "Результат"

    ```
    (1, 1, 1, 0)
    (0, 1, 3)
    (None, None)
    'ро'
    ```

## Все ударения { #word_stresses }

``` {.python .signature}
word_stresses(word, stress_dict=None)
```

Все ударные слоги слова по возрастанию. Составное слово через дефис, которого нет в словаре целиком, получает ударение каждой знаменательной части (`со-рок-во-ро-вка` - 0 и 3), частицы (-то, -либо, -нибудь и другие) безударны.

| Параметр | Тип | По умолчанию | Описание |
| :------- | :-- | :----------- | :------- |
| `word` | `str` | - | Слово |
| `stress_dict` | `StressDict` | `None` | Словарь ударений; по умолчанию `StressDict()` |

Возвращает пустой список, если слово не найдено или в нем нет гласных.

Исключения:

- `SourceTypeError` - слово, которое не строка, словарь ударений другого типа;
- `DatasetNotFoundError` - словарь ударений не загружен.

=== "Код"

    ``` python
    from ruts.syllables import word_stresses

    word_stresses("сорок-воровка"), word_stresses("северо-западный"), word_stresses("кто-нибудь")
    ```

=== "Результат"

    ```
    ([0, 3], [3], [0])
    ```

## Тип окончания { #stress_type }

``` {.python .signature}
stress_type(word, stress_dict=None)
```

Тип окончания слова по месту главного ударения. Названия - как у клаузул стиха (`VERSE_CLAUSULAS`):

| Тип | Ударение | Пример |
| :-- | :------- | :----- |
| мужская | на последнем слоге | зем-**ля** |
| женская | на предпоследнем слоге | ко-**ро**-ва |
| дактилическая | на третьем слоге от конца | **зо**-ло-то |
| гипердактилическая | раньше | **вы**-ско-чи-вший |

| Параметр | Тип | По умолчанию | Описание |
| :------- | :-- | :----------- | :------- |
| `word` | `str` | - | Слово |
| `stress_dict` | `StressDict` | `None` | Словарь ударений; по умолчанию `StressDict()` |

Возвращает `None`, если слово не найдено или в нем нет гласных.

Исключения:

- `SourceTypeError` - слово, которое не строка, словарь ударений другого типа;
- `DatasetNotFoundError` - словарь ударений не загружен.

=== "Код"

    ``` python
    from ruts.syllables import stress_type

    tuple(stress_type(word) for word in ("земля", "корова", "золото", "выскочивший"))
    ```

=== "Результат"

    ```
    ('мужская', 'женская', 'дактилическая', 'гипердактилическая')
    ```
