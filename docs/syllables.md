# Слоги и ударение

!!! info ""
    **ruts.syllables**

## Описание

Модуль делит русское слово на слоги и находит его ударный слог. Деление на слоги и подсчет слогов работают по правилам без внешних ресурсов, ударение берется из словаря [`StressDict`](datasets/stressdict.md). На этих функциях построены базовые статистики и формулы удобочитаемости (число слогов), фоностатистики (слоги) и стиховедческие статистики (ударения).

## Деление на слоги { #syllabify }

!!! info ""
    **ruts.syllables.syllabify()**

Деление слова на слоги по правилу восходящей звучности (Аванесов). Слогов в слове столько, сколько гласных; слово без гласных (предлоги в, к, с) слога не образует - это проклитика, для него возвращается пустой список. Граница слога проходит по правилам:

| Правило | Пример |
| :------ | :----: |
| одиночный согласный между гласными отходит к следующему слогу | ко-ро-ва, ра-йон |
| сочетание шумных и шумного с сонорным отходит к следующему слогу | ко-шка, се-стра, о-ткрыть, по-зна-ко-мить |
| сонорный перед шумным отходит к предыдущему слогу | кар-та, пол-ка |
| между двумя сонорными проходит граница | вол-на, кар-ман |
| й перед согласным отходит к предыдущему слогу | май-ка, вой-на |
| ь и ъ отходят к предыдущей букве | боль-шой, по-дъезд |
| каждая гласная зияния образует свой слог | а-э-ро-порт, а-ист |

Правила применяются к буквам, а не звукам, поэтому деление орфографическое, как в школьной фонетике, а не морфемное. Составное слово делится по частям (`со-рок-во-ро-вка`), часть без гласных примыкает к соседней (`втре-тьих`); остальные символы, кроме русских букв (цифры, латиница), отбрасываются.

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `word` | str | `-` | Слово |

!!! example "Пример"

    ``` python
    from ruts.syllables import syllabify

    syllabify("здравствуйте")
    # ['здра', 'вствуй', 'те']
    ```

## Количество слогов { #count_syllables }

!!! info ""
    **ruts.syllables.count_syllables()**

Количество слогов слова - число гласных букв, столько же слогов дает `syllabify`. Результаты кэшируются по словоформе.

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `word` | str | `-` | Слово |

!!! example "Пример"

    ``` python
    from ruts.syllables import count_syllables

    count_syllables("здравствуйте")
    # 3
    ```

## Ударный слог { #word_stress }

!!! info ""
    **ruts.syllables.word_stress()**

Определение ударного слога слова по словарю (пункт 1 [алгоритма](stats/verse_stats_funcs.md#algorithm) стиховедческих статистик). Слоги считаются по гласным с нуля; ударный слог можно получить, поделив слово функцией [`syllabify`](#syllabify).

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `word` | str | `-` | Слово |
| `stress_dict` | StressDict | `None` | Словарь ударений; если не задан, используется `StressDict()` |

Возвращает `None`, если слово не найдено или в нем нет гласных.

!!! example "Пример"

    ``` python
    from ruts.syllables import syllabify, word_stress

    word_stress("корова"), word_stress("ещё"), word_stress("желанье"), word_stress("кто-нибудь")
    # (1, 1, 1, 0)
    word_stress("хмурота")
    # None
    syllabify("корова")[word_stress("корова")]
    # 'ро'
    ```

## Все ударения { #word_stresses }

!!! info ""
    **ruts.syllables.word_stresses()**

Все ударные слоги слова по возрастанию. У большинства слов одно ударение, как у `word_stress`. Составное слово через дефис, которого нет в словаре целиком, получает ударение каждой знаменательной части (`со-рок-во-ро-вка` - 0 и 3); частицы -то, -нибудь, -ка, -ли, -же и приставка по- наречий (`по-французски`) безударны. Составное слово с ё делится на части всегда (`чёр-но-бе-лый` - 0 и 2): словарь ищет форму без ё и может дать ударение другого слова (`далеко-далеко` вместо `далёко-далёко`). Словарь хранит одно ударение слова, поэтому у составных слов, найденных целиком (`северо-западный`), побочное ударение не выделяется.

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `word` | str | `-` | Слово |
| `stress_dict` | StressDict | `None` | Словарь ударений; если не задан, используется `StressDict()` |

Возвращает пустой список, если слово не найдено или в нем нет гласных.

!!! example "Пример"

    ``` python
    from ruts.syllables import word_stresses

    word_stresses("сорок-воровка"), word_stresses("северо-западный"), word_stresses("кто-нибудь")
    # ([0, 3], [3], [0])
    ```

## Тип окончания { #stress_type }

!!! info ""
    **ruts.syllables.stress_type()**

Тип окончания слова по месту главного ударения. Названия - как у клаузул стиха (`VERSE_CLAUSULAS`):

| Тип | Ударение | Пример |
| :-- | :------- | :----: |
| мужская | на последнем слоге | зем-**ля** |
| женская | на предпоследнем слоге | ко-**ро**-ва |
| дактилическая | на третьем слоге от конца | **зо**-ло-то |
| гипердактилическая | раньше | **вы**-ско-чи-вший |

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `word` | str | `-` | Слово |
| `stress_dict` | StressDict | `None` | Словарь ударений; если не задан, используется `StressDict()` |

Возвращает `None`, если слово не найдено или в нем нет гласных.

!!! example "Пример"

    ``` python
    from ruts.syllables import stress_type

    tuple(stress_type(word) for word in ("земля", "корова", "золото", "выскочивший"))
    # ('мужская', 'женская', 'дактилическая', 'гипердактилическая')
    ```
