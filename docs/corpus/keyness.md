# Ключевые слова

!!! info ""
    **ruts.corpus.keyness()**, **ruts.corpus.Keyword**, **ruts.corpus.FrequencyReference**

## Описание

<!-- core: corpus/keyness.md:keyness 0018a96 -->
Поиск ключевых слов (keyness) целевого корпуса относительно эталонного: слова, которые в целевом корпусе встречаются значимо чаще, чем в эталонном.

Для каждого слова считаются две величины, которые [Gabrielatos и Marchi](http://eprints.lancs.ac.uk/51449/4/Gabrielatos_Marchi_Keyness.pdf) и [Hardie](http://cass.lancs.ac.uk/log-ratio-an-informal-introduction/) рекомендуют смотреть вместе: логарифм правдоподобия $G^2$ с p-значением (значимость различия - есть ли оно) и Log Ratio (размер эффекта - насколько оно велико). Также считается выбранная мера `score`, по которой список сортируется. Меры значимости ($G^2$, хи-квадрат, BIC) и ELL, размер эффекта $G^2$, получают знак: отрицательный, если слово чаще в эталоне; остальные меры эффекта (%DIFF, Log Ratio, отношение шансов) направленные по построению.

Эталоном может быть список слов, справочник частот (его объем - сумма частот) или `FrequencyReference`. Слова сравниваются как есть: регистр, лемматизация и стоп-слова - на стороне экстрактора слов, и оба корпуса должны быть извлечены одинаково.

Функция оборачивает `keyness` ядра [anyTS](https://sergeyshk.github.io/anyTS/corpus/keyness/) и принимает эталоном также [частотный словарь Ляшевской и Шарова](../datasets/freq2011.md) `FreqDict`; `FrequencyReference` лежит рядом с ней в `ruts.corpus`, а функции мер - в `ruts.corpus.keyness` (`from ruts.corpus.keyness import calc_log_likelihood`). Слова извлекает [`WordsExtractor`](../extractors/words.md).

## Меры

<!-- core: corpus/keyness.md:keyness-measures 7d98aa3 -->
Для слова с частотой $a$ в целевом корпусе объемом $c$ и частотой $b$ в эталонном корпусе объемом $d$, $N = c + d$:

| Мера | Ключ | Формула | Описание |
| :--- | :--- | :------ | :------- |
| Логарифм правдоподобия | `log_likelihood` | $G^2 = 2\,(a \ln \frac{a}{E_1} + b \ln \frac{b}{E_2})$, $E_1 = \frac{c\,(a+b)}{N}$, $E_2 = \frac{d\,(a+b)}{N}$ | [Rayson и Garside (2000)](https://ucrel.lancs.ac.uk/llwizard.html); критические значения `anyts.constants.G2_CRITICAL_VALUES`: 3.84 для p < 0.05, 6.63 для p < 0.01, 10.83 для p < 0.001, 15.13 для p < 0.0001 |
| Хи-квадрат | `chi2` | $\chi^2 = \frac{N\,\max(\lvert a(d-b) - b(c-a) \rvert - N/2,\ 0)^2}{(a+b)(N-a-b)\,c\,d}$ | с поправкой Йейтса по таблице сопряженности 2×2; если поправка больше разности, статистика равна нулю |
| %DIFF | `diff` | $\frac{NF_a - NF_b}{NF_b} \cdot 100$ | [Gabrielatos и Marchi (2011)](http://eprints.lancs.ac.uk/51449/4/Gabrielatos_Marchi_Keyness.pdf); $NF$ - частота на миллион слов |
| Log Ratio | `log_ratio` | $\log_2 \frac{NF_a}{NF_b}$ | [Hardie (2014)](http://cass.lancs.ac.uk/log-ratio-an-informal-introduction/); единица - слово вдвое чаще в целевом корпусе |
| BIC | `bic` | $\operatorname{sign}(G^2) \cdot (\lvert G^2 \rvert - \ln N)$ | Wilson (2013); по модулю выше 2 - положительное свидетельство различия, выше 6 - сильное, выше 10 - очень сильное; отрицательное значение при $\lvert G^2 \rvert < \ln N$ означает отсутствие свидетельства, а не обратное направление |
| ELL | `ell` | $\frac{G^2}{N \ln \min(E_1, E_2)}$ | Johnston, Berry и Mielke (2006); размер эффекта $G^2$, доля наибольшего возможного отклонения от ожидаемых частот, от 0 до 1; `nan`, когда наименьшая ожидаемая частота не больше единицы - тогда логарифм нулевой или отрицательный; чуть выше единицы мера неограниченно растет |
| Отношение шансов | `odds_ratio` | $\frac{a / (c - a)}{b / (d - b)}$ | единица - шансы равны; `inf`, если слово занимает весь целевой корпус, 0 - если весь эталонный |

Нулевая частота в одном из корпусов для %DIFF, Log Ratio и отношения шансов заменяется на 0.5 (Hardie 2014). p-значение $G^2$ берется из распределения хи-квадрат с одной степенью свободы (`calc_p_value`). Меры доступны как функции `calc_log_likelihood`, `calc_chi2`, `calc_diff`, `calc_log_ratio`, `calc_bic`, `calc_ell` и `calc_odds_ratio` с аргументами `(a, b, c, d)` из модуля `anyts.corpus.keyness`; их названия и описания - в `anyts.constants.KEYNESS_MEASURES`.

## Параметры

<!-- core: corpus/keyness.md:keyness-parameters 6f31f0b -->
| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `target` | list[str]/dict[str, int] | `-` | Слова целевого корпуса или их частоты |
| `reference` | list[str]/dict[str, float]/FrequencyReference | `-` | Слова эталонного корпуса, их частоты или эталон по частотам |
| `measure` | str | `log_likelihood` | Мера из `anyts.constants.KEYNESS_MEASURES` для `score` и сортировки |
| `min_freq` | int | `1` | Минимальная частота ключевого слова в своем корпусе |
| `positive` | bool | `True` | Положительные ключевые слова (чаще в целевом корпусе) или отрицательные (чаще в эталонном) |
| `top_n` | int | `None` | Количество ключевых слов; `None` - все |

`reference` может быть и `FreqDict`, и еще один параметр говорит, из чего при нем целевой корпус:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `lemmatize` | bool | `True` | Целевой корпус из словоформ, `False` - из лемм (только с `FreqDict`) |

## Эталон по частотам

<!-- core: corpus/keyness.md:FrequencyReference 3fc867c -->
`FrequencyReference(counts, size, missing=0.0, key=None, keep=None)` описывает эталонный корпус одними частотами - например, частотный словарь, построенный по корпусу, слишком большому, чтобы передать его словами:

| Поле | Тип | По умолчанию | Описание |
| :--: | :-: | :----------: | :------- |
| `counts` | dict[str, float] | `-` | Частоты ключей в эталонном корпусе |
| `size` | float | `-` | Объем эталонного корпуса в словах |
| `missing` | float | `0.0` | Частота ключа, которого нет в `counts` |
| `key` | callable | `None` | Ключ слова целевого корпуса в `counts`, например его лемма; `None` - само слово |
| `keep` | callable | `None` | Учитывается ли слово целевого корпуса; `None` - каждое слово |

Слова целевого корпуса, которые пропускает `keep`, считаются под своим `key`, а отброшенные не входят и в его объем; отрицательные ключевые слова берутся только из ключей `counts`, которые пропускает `keep`. Частота ключа, которого нет в `counts`, - `missing`: словарь дает свою наименьшую частоту, верхнюю границу истинной, поэтому такое слово может быть положительным ключевым словом, но никогда - отрицательным.

Частотный словарь `FreqDict`, переданный как `reference`, превращается в такой эталон:

| Поле | `FreqDict` |
| :--: | :--------- |
| `counts` | ipm лемм `FreqDict.entries`, переведенные в число употреблений в корпусе словаря |
| `size` | `CORPUS_SIZE` из `ruts.datasets.freq2011`, 92 млн словоупотреблений современного подкорпуса Национального корпуса русского языка |
| `missing` | наименьшая частота словаря `FreqDict.min_ipm`, 0.4 ipm (около 37 употреблений) |
| `key` | лемма словаря: словоформа лемматизируется pymorphy3 (с `lemmatize=False` берется как лемма) и приводится к соглашениям словаря функцией `ruts.lexical_stats.dictionary_lemma`, как в [`LexicalStats`](../stats/lexical_stats.md) |
| `keep` | слова из кириллических букв `ruts.lexical_stats.DICTIONARY_WORD`; числа и слова с латиницей отбрасываются |

Статья словаря, которой нет в тексте, бывает отрицательным ключевым словом, только если к ней приводится хотя бы одна форма слова: статьи «его», «ее», «их» (притяжательные местоимения) и «во», «со» словарь ведет отдельно, а pymorphy3 приводит эти словоформы к «он», «она», «они», «в», «с», и без этого правила они выходили бы отрицательными ключевыми словами у любого текста. Такие статьи - около 1 100 для словоформ и 1 500 для лемм - перечислены в ресурсах пакета; слов, которые pymorphy3 только предсказывает («Михайлыч», «дитё»), правило не видит.

С `lemmatize=False` соглашения словаря по лемме не восстановить: краткая форма, множественное число и вариант написания теряются («должный» вместо «должен», «деньга» вместо «деньги», «счастие» вместо «счастье»), и такие статьи выходят ложными ключевыми словами. Для сравнения со словарем передавайте словоформы.

## Результат

<!-- core: corpus/keyness.md:Keyword 33ab9a7 -->
Список именованных кортежей `Keyword` по убыванию ключевости (при равенстве - по убыванию частоты и по алфавиту, слова с неопределенной мерой в конце); `pd.DataFrame(keywords)` дает таблицу.

| Поле | Тип | Описание |
| :--: | :-: | :------- |
| `word` | str | Слово |
| `freq_target` | int | Частота в целевом корпусе |
| `freq_reference` | float | Частота в эталонном корпусе |
| `ipm_target` | float | Частота в целевом корпусе на миллион слов |
| `ipm_reference` | float | Частота в эталонном корпусе на миллион слов |
| `g2` | float | $G^2$ со знаком направления |
| `p_value` | float | p-значение $G^2$ |
| `log_ratio` | float | Log Ratio |
| `score` | float | Значение выбранной меры |

## Пример

!!! example "Пример"

    ``` python
    from ruts import WordsExtractor
    from ruts.corpus import keyness

    we = WordsExtractor(use_lexemes=True, lowercase=True)
    target = we.extract(
        "Кот сидел на окне и смотрел на птиц. Птицы улетели, и кот уснул на окне. "
        "Завтра кот снова будет сидеть на окне и смотреть на птиц."
    )
    reference = we.extract(
        "Собака лежала на полу и дремала. Потом собака ела и снова дремала. Завтра собака будет гулять."
    )

    keyness(target, reference, top_n=1)
    # [Keyword(word='кот', freq_target=3, freq_reference=0.0, ipm_target=115384.61538461539,
    #  ipm_reference=0.0, g2=2.8774384815713177, p_value=0.08982881315854577,
    #  log_ratio=1.8845227825800641, score=2.8774384815713177)]

    [(k.word, round(k.g2, 2)) for k in keyness(target, reference, positive=False, top_n=2)]
    # [('собака', -5.79), ('дремать', -3.86)]

    # Относительно частотного словаря (после FreqDict().download()) - по словоформам
    from ruts.datasets import FreqDict

    words = WordsExtractor().extract(
        "Кот сидел на окне и смотрел на птиц. Птицы улетели, и кот уснул на окне. "
        "Завтра кот снова будет сидеть на окне и смотреть на птиц."
    )
    [(k.word, round(k.log_ratio, 1)) for k in keyness(words, FreqDict(), min_freq=3, top_n=2)]
    # [('кот', 11.5), ('птица', 10.3)]
    ```
