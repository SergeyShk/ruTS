# Конкорданс KWIC

``` {.python .signature}
kwic(source, keyword, window=5, by_lemma=False, ignore_case=True)
```

<!-- core: corpus/kwic.md:kwic 8e91237 -->
Конкорданс KWIC (keyword in context) - все вхождения слова или словосочетания с контекстом с обеих сторон. Вхождения ищутся среди слов текста по словоформе без учета регистра или с его учетом (`ignore_case=False`) или по лемме (`by_lemma=True`); ключевое слово лемматизируется как строка, так что с лемматизатором словосочетание можно записать в любой форме, а без него оно задается леммами. Слова - это слова [документа](https://sergeyshk.github.io/anyTS/document/) текста (токены строки - по токенизатору, `Doc` и `Document` - их собственные), а ключевое слово делится как строка: токенизатор, который режет строку так же, как пайплайн, находит в обоих одно и то же. В слове есть буква или цифра, поэтому знаки препинания и символы словами не считаются; словоформы сравниваются в нормальной форме композиции Unicode (NFC), без мягких переносов, а словоформы и леммы - без конечной точки слова с буквой: токенизатор по Universal Dependencies оставляет точку сокращения при нем внутри предложения и отделяет ее в конце, поэтому ключевое слово `Sr.` находит слово из `El Sr. García vino`, а `EE. UU.` - слова из `Viajó a EE. UU. en mayo`.

Словосочетание не переходит через конец предложения или абзаца документа, если в ключевом слове нет конечного знака или начала предложения на том же месте (`U.S. Army`). Предложения - предложения `Doc` или `Document`, а у строки, ключевого слова и `Doc` без предложений - сегментатора предложений (по умолчанию `SentsExtractor`). Контекст - `window` слов с каждой стороны, как они записаны в тексте, со знаками препинания; пробельные символы схлопываются в один пробел, вхождения не пересекаются.

Функция вызывает `kwic` ядра [anyTS](https://sergeyshk.github.io/anyTS/corpus/kwic/) с крючками русского языка: слова и предложения строки и ключевого слова дает сегментатор [anySeg](https://github.com/SergeyShk/anySeg), леммы - ruMorph в контексте предложения (в размеченных `Doc` и `Document` - по части речи слова), так что «стали» находится по «сталь» или по «стать» в зависимости от соседних слов; у слова ключевого слова контекста нет, и оно совпадает по любой лемме своих разборов (`стали` находит оба). Знаки ударения при сравнении не учитываются, а словоформы с `ignore_case` и леммы сравниваются в нижнем регистре с ё как е.

=== "Код"

    ``` python
    from ruts.corpus import kwic, print_kwic

    text = (
        "Кот сидел на окне и смотрел на птиц. Птицы улетели, и кот уснул на окне. "
        "Завтра кот снова будет сидеть на окне и смотреть на птиц."
    )
    lines = kwic(text, "окно", by_lemma=True, window=3)
    lines[0]
    print_kwic(lines, width=20)

    [line.keyword for line in kwic(text, "смотреть на птица", by_lemma=True)]
    ```

=== "Результат"

    ```
    Concordance(start=13, end=17, left='Кот сидел на', keyword='окне', right='и смотрел на')
            Кот сидел на  окне  и смотрел на
            кот уснул на  окне  . Завтра кот снова
         будет сидеть на  окне  и смотреть на
    ['смотрел на птиц', 'смотреть на птиц']
    ```

## Параметры

<!-- core: corpus/kwic.md:kwic-parameters cb6665e -->
| Параметр | Тип | По умолчанию | Описание |
| :------- | :-- | :----------- | :------- |
| `source` | `str` / `Doc` / `Document` | - | Текст, объект Doc или Document |
| `keyword` | `str` | - | Слово или словосочетание |
| `window` | `int` | `5` | Число слов контекста с каждой стороны |
| `by_lemma` | `bool` | `False` | Сравнивать леммы, а не словоформы |
| `ignore_case` | `bool` | `True` | Не учитывать регистр при сравнении словоформ |

Ключевое слово без слов, окно, которое не целое число или отрицательно, и `by_lemma` или `ignore_case`, который не `bool`, дают `ParameterError`; источник, который не строка, не `Doc` и не `Document`, ключевое слово, которое не строка, и крючок, который нельзя вызвать, - `SourceTypeError`, а `Doc`, токен которого проходит через пустую строку, - `SourceError`.

## Результат

<!-- core: corpus/kwic.md:Concordance ce8d89f -->
``` {.python .signature}
Concordance(start, end, left, keyword, right)
```

Список именованных кортежей `Concordance` по порядку в тексте.

| Поле | Тип | Описание |
| :--- | :-- | :------- |
| `start` | `int` | Позиция первого символа вхождения в тексте |
| `end` | `int` | Позиция за последним символом вхождения |
| `left` | `str` | Контекст слева |
| `keyword` | `str` | Вхождение, как оно записано в тексте |
| `right` | `str` | Контекст справа |

## Выровненные строки { #format_kwic }

<!-- core: corpus/kwic.md:format_kwic a511562 -->
``` {.python .signature}
format_kwic(concordances, width=40, *, messages=None)
```

Собирает строки в текст, выровненный по ключевому слову, по строке на вхождение: левый контекст обрезается слева и прижимается к правому краю, правый обрезается справа. Строки могут прийти из любого итерируемого объекта и берутся в нормальной форме композиции Unicode (NFC), так что ширина считает символы так, как они показываются.

| Параметр | Тип | По умолчанию | Описание |
| :------- | :-- | :----------- | :------- |
| `concordances` | `list[Concordance]` | - | Строки конкорданса |
| `width` | `int` | `40` | Ширина контекста в символах |
| `messages` | `dict[str, str]` | `None` | Сообщения об ошибках по ключам вместо русских `CORE_MESSAGES` |

Строки, переданные строкой (`str`) или неитерируемым объектом, дают `SourceTypeError`, а `width`, который не целое число не меньше единицы, - `ParameterError`.

<!-- core: corpus/kwic.md:print_kwic ec934d7 -->
``` {.python .signature}
print_kwic(concordances, width=40, *, messages=None)
```

Печатает результат `format_kwic`.
