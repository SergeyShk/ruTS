# Конкорданс KWIC

!!! info ""
    **ruts.corpus.kwic()**, **ruts.corpus.format_kwic()**, **ruts.corpus.print_kwic()**, **ruts.corpus.Concordance**

## Описание

<!-- core: corpus/kwic.md:kwic dadc1ee -->
Конкорданс KWIC (keyword in context) - все вхождения слова или словосочетания с контекстом слева и справа. Вхождения ищутся среди слов текста по словоформе без учета регистра или с его учетом (`ignore_case=False`) или по лемме (`by_lemma=True`), причем слова ключевого слова лемматизируются как слова строки: с лемматизатором словосочетание можно записать в любой форме, без него оно задается леммами. Слова строки и ключевого слова дает токенизатор, слова `Doc` - его токены, так что токенизатор, который режет строку так же, как пайплайн, находит в `Doc` то же, что в его тексте; знаки препинания и символы словами не считаются. Словоформы сравниваются в нормальной форме композиции Unicode (NFC), без мягких переносов. Словосочетание не переходит через конец абзаца или предложения - границу `Doc` в любом месте между его словами, включая открывающий знак, или в тексте без границ начало предложения сегментатора предложений, по умолчанию конечный знак перед пробелом, - если в ключевом слове нет конечного знака или начала предложения на том же месте (`U.S. Army`). Контекст - `window` слов с каждой стороны, как они записаны в тексте, со знаками препинания между ними; пробельные символы схлопываются в один пробел, вхождения не пересекаются.

## Языковые крючки

Функция вызывает `kwic` ядра [anyTS](https://sergeyshk.github.io/anyTS/corpus/kwic/) с крючками русского языка: слова и предложения строки и ключевого слова дает [razdel](https://github.com/natasha/razdel), лемма слова - pymorphy3, в `Doc` с разметкой частей речи - с частью речи токена (`ruts.utils.lemmatize`), так что «стали» находится по «сталь» или по «стать» в зависимости от разметки, а словоформы (с `ignore_case`) и леммы сравниваются в нижнем регистре с ё как е. Части дефисного слова, разрезанного spaCy, склеиваются (`кто-то` - одно слово).

## Параметры

<!-- core: corpus/kwic.md:kwic-parameters e17a79b -->
| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `source` | str/Doc | `-` | Текст или объект Doc |
| `keyword` | str | `-` | Слово или словосочетание |
| `window` | int | `5` | Число слов контекста с каждой стороны |
| `by_lemma` | bool | `False` | Сравнивать леммы, а не словоформы |
| `ignore_case` | bool | `True` | Не учитывать регистр при сравнении словоформ |

Ключевое слово без слов и отрицательное окно дают `ParameterError`; источник, который не строка и не `Doc`, ключевое слово, которое не строка, и крючок, который нельзя вызвать, - `SourceTypeError`.

<!-- core: corpus/kwic.md:format_kwic 532aaaa -->
`format_kwic(concordances, width=40)` выравнивает строки по ключевому слову: левый контекст обрезается слева и прижимается к правому краю, правый обрезается справа; `width` - ширина контекста в символах, не меньше единицы. Строки могут прийти из любого итерируемого объекта и берутся в нормальной форме композиции Unicode (NFC), чтобы ширина считала символы так, как они показываются.

<!-- core: corpus/kwic.md:print_kwic 92f3d36 -->
`print_kwic(concordances, width=40)` печатает результат `format_kwic`.

## Результат

<!-- core: corpus/kwic.md:Concordance f0916bd -->
Список именованных кортежей `Concordance` по порядку в тексте.

| Поле | Тип | Описание |
| :--: | :-: | :------- |
| `start` | int | Позиция первого символа вхождения в тексте |
| `end` | int | Позиция за последним символом вхождения |
| `left` | str | Контекст слева |
| `keyword` | str | Вхождение, как оно записано в тексте |
| `right` | str | Контекст справа |

## Пример

!!! example "Пример"

    ``` python
    from ruts.corpus import kwic, print_kwic

    text = (
        "Кот сидел на окне и смотрел на птиц. Птицы улетели, и кот уснул на окне. "
        "Завтра кот снова будет сидеть на окне и смотреть на птиц."
    )
    lines = kwic(text, "окно", by_lemma=True, window=3)
    lines[0]
    # Concordance(start=13, end=17, left='Кот сидел на', keyword='окне', right='и смотрел на')

    print_kwic(lines, width=20)
    #         Кот сидел на  окне  и смотрел на
    #         кот уснул на  окне  . Завтра кот снова
    #      будет сидеть на  окне  и смотреть на

    [line.keyword for line in kwic(text, "смотреть на птица", by_lemma=True)]
    # ['смотрел на птиц', 'смотреть на птиц']
    ```
