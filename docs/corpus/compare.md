# Сравнение корпусов

``` {.python .signature}
compare_corpora(a, b, window=1000, features=None, labels=('A', 'B'), n_bootstrap=1000, seed=0, min_words=None)
```

Сравнивает два корпуса русских текстов по всем признакам текста сразу: какие статистики различают авторов, жанры, переводы, человеческие и сгенерированные тексты - и насколько. Для отдельных слов то же делает [`keyness`](keyness.md), для расстояний между текстами - [`delta`](stylometry.md#delta).

Тексты режутся подряд на окна ровно по `window` слов функцией [`split_windows`](#split_windows), так что окна всех текстов одной длины; неполный остаток в конце текста и текст короче окна отбрасываются, если `min_words` не разрешает окна короче. Признаки каждого окна считает [`text_features`](#text_features) или своя функция, а таблицы двух корпусов сравнивает [`compare_features`](#compare_features) ядра [anyTS](https://sergeyshk.github.io/anyTS/corpus/compare/).

Чехов против Толстого по прозе из набора [`RussianLiterature`](../datasets/russianliterature.md): 77 и 42 произведения, 249 и 1423 окна по 1000 слов, меньше минуты.

=== "Код"

    ``` python
    from ruts.corpus import compare_corpora
    from ruts.datasets import RussianLiterature

    rl = RussianLiterature()
    chekhov = list(rl.get_texts(genre="prose", author="Чехов"))
    tolstoy = list(rl.get_texts(genre="prose", author="Толстой"))

    result = compare_corpora(chekhov, tolstoy, window=1000, labels=("Чехов", "Толстой"))
    columns = [
        "median_Чехов",
        "median_Толстой",
        "ci_low",
        "ci_high",
        "cohen_d",
        "cliff_delta",
        "auc",
        "p_holm",
    ]
    result[columns].head(10).round(3)
    result.loc["sents_mean", ["n_Чехов", "n_Толстой", "n_texts_Чехов", "n_texts_Толстой"]].to_dict()
    ```

## Параметры

| Параметр | Тип | По умолчанию | Описание |
| :------- | :-- | :----------- | :------- |
| `a` | `list[str]` | - | Тексты первого корпуса |
| `b` | `list[str]` | - | Тексты второго корпуса |
| `window` | `int` | `1000` | Размер окна в словах; `None` - тексты целиком |
| `features` | `Callable` | `None` | Функция признаков текста; `None` - `text_features` |
| `min_words` | `int` | `None` | Наименьшее число слов в окне, не больше `window`; `None` - окно целиком, при `window=None` - одно слово |

`labels`, `n_bootstrap` и `seed` передаются в [`compare_features`](#compare_features). `compare_corpora` первым делом проверяет их функцией `check_comparison_params`, так что неверное имя корпуса или зерно дает ошибку до обработки текстов. Тексты, которые не список строк, и `features`, который нельзя вызвать, дают `SourceTypeError`, корпус без окна из `min_words` и более слов - `SourceError`, а `window` или `min_words`, который не целое число не меньше единицы, и `min_words` больше `window` - `ParameterError`.

## Признаки { #text_features }

``` {.python .signature}
text_features(text)
```

Возвращает 113 признаков текста с префиксом по источнику; неопределенный признак равен `nan`.

| Префикс | Признаки | Источник |
| :------ | :------- | :------- |
| `basic_` | доли длинных, сложных, простых, одно- и многосложных слов, букв, пробелов и знаков препинания; буквы и слоги на слово | [`BasicStats`](../stats/basic_stats.md) |
| `readability_` | все формулы удобочитаемости и сводный класс | [`ReadabilityStats`](../stats/readability_stats.md) |
| `diversity_` | меры лексического разнообразия | [`DiversityStats`](../stats/diversity_stats.md) |
| `morph_` | доли частей речи и признаков с одним значением от числа слов (`morph_pos_NOUN`, `morph_polarity_Neg`, `morph_style_variant_Short`) и доли значений внутри остальных признаков (`morph_case_Gen`, `morph_tense_Past`, `morph_degree_Cmp`; у двузначных - одна доля, `morph_number_Plur`) | [`MorphStats`](../stats/morph_stats.md) по pymorphy3 |
| `sents_` | средняя длина предложения в словах, стандартное отклонение, коэффициент вариации, автокорреляция соседних длин ([`sentence_rhythm`](#sentence_rhythm)) - ритм текста | [`sentence_lengths`](../visualizers/sentences.md) |
| `punct_` | частоты знаков по типам на 1000 слов и доля буквы ё | [`punctuation_profile`](../stats/basic_stats.md#punctuation) |

На окно в 1000 слов уходит около 0.02 с. Признаки по разбору spaCy (`SyntaxStats`, `CohesionStats`) в набор по умолчанию не входят - функция работает по строкам; их можно добавить своей функцией признаков через `features`, см. пример ниже.

Доли пробелов, букв и знаков (`basic_p_spaces`, `basic_p_letters`, `basic_p_punctuations`) считаются по символам как есть: отступы строк, двойные и неразрывные пробелы в файлах отражают верстку издания, а не текст. В корпусе из разных источников их стоит схлопнуть заранее, например `re.sub(r"[^\S\n]+", " ", text)`.

Текст, который не строка, дает `SourceTypeError`, а текст без слов - `SourceError`.

``` {.python .signature}
corpus_features(texts, window=1000, features=text_features, min_words=None)
```

Возвращает матрицу признаков окон с индексом (номер текста, номер окна), в том числе для своих классификаторов; уровень `text` этого индекса и пересэмплирует бутстрэп `compare_features`. Параметры и ошибки - как у `compare_corpora`; тексты без слов и окна короче `min_words` пропускаются. `compare_corpora` - это `corpus_features` для каждого корпуса и `compare_features`; разделение нужно, когда признаки посчитаны один раз для нескольких корпусов, а сравнить надо пары, например всех авторов попарно.

Свои признаки, например синтаксические по spaCy, передаются функцией; с разбором то же сравнение занимает около восьми минут:

=== "Код"

    ``` python
    import spacy
    from ruts import SyntaxStats
    from ruts.corpus import compare_corpora, text_features

    nlp = spacy.load("ru_core_news_sm")


    def features(text):
        stats = SyntaxStats(nlp(text)).get_stats()
        return {**text_features(text), **{f"syntax_{key}": value for key, value in stats.items()}}


    result = compare_corpora(
        chekhov, tolstoy, window=1000, features=features, labels=("Чехов", "Толстой")
    )
    result.filter(like="syntax_", axis=0)[columns].head(5).round(3)
    ```

## Сравнение таблиц признаков { #compare_features }

<!-- core: corpus/compare.md:compare_features 96478f4 -->
``` {.python .signature}
compare_features(table_a, table_b, labels=('A', 'B'), n_bootstrap=1000, seed=0)
```

Сравнивает два корпуса признак за признаком. Каждый корпус - таблица признаков своих окон, частей текстов примерно одинакового размера, чтобы признаки не зависели от длины текстов. Результат - по строке на столбец, по убыванию модуля дельты Клиффа, признаки без статистик - в конце. Бутстрэп пересэмплирует целые тексты по уровню `text` индекса; без него каждая строка считается отдельным текстом. Столбец, которого нет в одной из таблиц, дает `nan`.

<!-- core: corpus/compare.md:compare_features-parameters 2ed21c1 -->
| Параметр | Тип | По умолчанию | Описание |
| :------- | :-- | :----------- | :------- |
| `table_a` | `DataFrame` | - | Признаки окон первого корпуса, по строке на окно |
| `table_b` | `DataFrame` | - | Признаки окон второго корпуса |
| `labels` | `tuple[str, str]` | `('A', 'B')` | Имена корпусов для столбцов, две строки, дающие разные столбцы |
| `n_bootstrap` | `int` | `1000` | Число выборок бутстрэпа |
| `seed` | `int` / `Generator` | `0` | Зерно генератора случайных чисел, неотрицательное целое число, или `Generator` numpy; `None` - случайное |

Таблица, которая не `DataFrame`, повторяет имя столбца или содержит столбец, который не числовой, дает `SourceTypeError`; остальные параметры проверяет `check_comparison_params`.

<!-- core: corpus/compare.md:check_comparison_params a56a706 -->
``` {.python .signature}
check_comparison_params(labels=('A', 'B'), n_bootstrap=1000, seed=0)
```

Проверяет параметры `compare_features` до обработки текстов: дает `ParameterError`, если метки - не две строки, дающие разные столбцы (`("diff", "B")` повторило бы `median_diff`), число выборок бутстрэпа - не целое число не меньше единицы или зерно - не `None`, не неотрицательное целое число и не `Generator` numpy.

## Статистики { #statistics }

<!-- core: corpus/compare.md:compare_features-statistics 99869be -->
Для признака со значениями $x_1 \dots x_{n_A}$ в корпусе A и $y_1 \dots y_{n_B}$ в корпусе B (неопределенные и бесконечные значения отброшены; при менее чем двух значениях на стороне - `nan`):

| Столбец | Описание |
| :------ | :------- |
| `mean_A`, `mean_B`, `median_A`, `median_B` | средние и медианы |
| `median_diff`, `ci_low`, `ci_high` | разность медиан и ее перцентильный бутстрэп-интервал 95%: оба набора пересэмплируются `n_bootstrap` раз (`bootstrap_median_diff`) |
| `cohen_d` | $d = (\bar{x} - \bar{y}) / s$, $s$ - объединенное стандартное отклонение; 0.2 - малый эффект, 0.5 - средний, 0.8 - большой (`calc_cohen_d`) |
| `cliff_delta` | $\delta = P(x > y) - P(x < y)$ от −1 до 1; $\lvert\delta\rvert$ < 0.147 - пренебрежимый эффект, < 0.33 - малый, < 0.474 - средний, иначе большой (Romano и др. 2006; `calc_cliff_delta`) |
| `auc` | признак как классификатор: доля пар окон, где значение в A больше, чем в B, ничьи за половину; $\delta = 2 \cdot AUC - 1$, 0.5 - признак не различает корпуса |
| `u`, `p_value` | U-критерий Манна-Уитни и двустороннее p-значение (`scipy.stats.mannwhitneyu`) |
| `p_holm` | p-значение с поправкой Холма на число признаков (`holm_correction`) |
| `n_A`, `n_B` | число окон с определенным значением |
| `n_texts_A`, `n_texts_B` | число текстов, из которых взяты эти окна |

Столбцы - `anyts.corpus.COMPARISON_COLUMNS`, где суффиксы `a` и `b` заменены метками корпусов. Дельта Клиффа и AUC считаются из той же U-статистики и согласованы; d Коэна чувствителен к выбросам и отклонениям от нормальности, его стоит смотреть рядом с дельтой.

!!! warning "Окна одного текста не независимы"
    Критерий и размеры эффекта считают окна независимыми наблюдениями, а окна одного текста не независимы: при небольшом числе текстов p-значения слишком малы и отражают выбор текстов не меньше, чем сами корпуса. Бутстрэп пересэмплирует целые тексты (кластерный бутстрэп), так что его интервал учитывает разброс между текстами; ему нужно не меньше двух текстов с каждой стороны, а при немногих текстах он груб.

<!-- core: corpus/compare.md:calc_cliff_delta ccd5938 -->

``` {.python .signature}
calc_cliff_delta(values_a, values_b)
```

| Параметр | Тип | По умолчанию | Описание |
| :------- | :-- | :----------- | :------- |
| `values_a` | `list[float]` | - | Значения в первом корпусе |
| `values_b` | `list[float]` | - | Значения во втором корпусе |

Значение, которое не число и не пропуск (`None`, `NA`), и значения, которые не плоский список, дают `SourceTypeError`.

<!-- core: corpus/compare.md:bootstrap_median_diff b20d95f -->

Перцентильный бутстрэп-интервал разности медиан. С `texts_a` и `texts_b` пересэмплируются целые тексты, а медиана выборки берется по значениям ее текстов; при менее чем двух текстах на стороне интервал - `nan`.

| :------- | :-- | :----------- | :------- |
| `values_a` | `list[float]` | - | Значения в первом корпусе |
| `values_b` | `list[float]` | - | Значения во втором корпусе |
| `n_bootstrap` | `int` | `1000` | Число выборок бутстрэпа |
| `rng` | `Generator` | `None` | Генератор случайных чисел numpy; `None` - новый без зерна |
| `confidence` | `float` | `0.95` | Уровень доверия |
| `texts_a` | `list` | `None` | Тексты значений в первом корпусе; `None` - каждое значение пересэмплируется отдельно |

Значение, которое не число и не пропуск, значения, которые не плоский список, и тексты, которые не метки одного типа, дают `SourceTypeError`; `n_bootstrap`, который не целое число не меньше единицы, `confidence`, который не число в интервале (0, 1), число текстов, не равное числу значений, и `rng`, который не `Generator` numpy, - `ParameterError`.

<!-- core: corpus/compare.md:holm_correction 7006482 -->
``` {.python .signature}

```

Поправка Холма на множественные сравнения: p-значения сортируются по возрастанию, i-е умножается на (m − i + 1), где m - число определенных значений, затем берется накопленный максимум, ограниченный единицей; `nan` остается `nan`.

| Параметр | Тип | По умолчанию | Описание |
| :------- | :-- | :----------- | :------- |
| `p_values` | `list[float]` | - | p-значения |

P-значение, которое не число и не пропуск, и p-значения, которые не плоский список, дают `SourceTypeError`, а p-значение вне [0, 1] - `ParameterError`.

=== "Код"

    ``` python
    from ruts.corpus import calc_cliff_delta, calc_cohen_d, holm_correction

    round(calc_cohen_d([2, 4, 6, 8], [1, 3, 5, 7]), 3)
    calc_cliff_delta([2, 4, 6, 8], [1, 3, 5, 7])
    holm_correction([0.01, 0.04, 0.03]).round(3).tolist()
    ```

=== "Результат"

    ```

    0.25
    [0.03, 0.06, 0.06]
    ```

## Окна текста { #split_windows }

``` {.python .signature}
split_windows(text, window=1000, min_words=None)
```

Режет текст подряд на окна ровно по `window` слов, так что признаки, зависящие от длины, сравнимы между текстами. Остаток становится окном, только если в нем не меньше `min_words` слов (по умолчанию окно целиком, то есть остаток отбрасывается). Граница проходит перед первым словом окна и его открывающими знаками; симметричный знак, например прямая кавычка или тире вставки, закрывает предыдущее окно, если примыкает к его последнему слову или стоит после закрывающего знака. Пробельные символы по краям окон снимаются; `window=None` дает текст целиком. Слова - слова [`WordsExtractor`](../extractors/words.md), знаки - из `ruts.constants`: кавычки, скобки и тире открывают фразу (`OPENING_MARKS`), прямые и английские кавычки и тире симметричны (`SYMMETRIC_MARKS`), а конечные знаки, запятая, точка с запятой, закрывающие скобки и кавычка-елочка закрывают ее (`CLOSING_MARKS`).

| Параметр | Тип | По умолчанию | Описание |
| :------- | :-- | :----------- | :------- |
| `text` | `str` | - | Строка текста |
| `window` | `int` | `1000` | Размер окна в словах; `None` - текст целиком |
| `min_words` | `int` | `None` | Наименьшее число слов в окне; `None` - окно целиком, при `window=None` - одно слово |

Текст, который не строка, дает `SourceTypeError`, а `window` или `min_words`, который не целое число не меньше единицы, и `min_words` больше окна - `ParameterError`. Текст без слов или короче `min_words` дает пустой список.

=== "Код"

    ``` python
    from ruts.corpus import split_windows

    split_windows("Раз два три четыре пять", 2, min_words=1)
    split_windows("Он сказал: «Иди домой». Потом он вышел из комнаты", 4)
    ```

=== "Результат"

    ```
    ['Раз два', 'три четыре', 'пять']
    ['Он сказал: «Иди домой».', 'Потом он вышел из']
    ```

## Ритм предложений { #sentence_rhythm }

``` {.python .signature}
sentence_rhythm(lengths)
```

Дает ритм предложений по их длинам в словах: среднее `sents_mean`, стандартное отклонение `sents_std`, коэффициент вариации `sents_cv` и автокорреляцию лага 1 - связь длин соседних предложений `sents_autocorr` (Yule, 1939). Отклонению нужно два предложения, автокорреляции - три неравной длины, коэффициенту вариации - среднее больше нуля; иначе, как и без предложений, признак равен `nan`.

| Параметр | Тип | По умолчанию | Описание |
| :------- | :-- | :----------- | :------- |
| `lengths` | `list[int]` | - | Длины предложений в словах |

Длины, которые не список целых чисел, дают `SourceTypeError`, а отрицательная длина - `ParameterError`.

=== "Код"

    ``` python
    from ruts.corpus import sentence_rhythm

    {key: round(value, 3) for key, value in sentence_rhythm([4, 8, 2, 7]).items()}
    ```

=== "Результат"

    ```
    {'sents_mean': 5.25, 'sents_std': 2.754, 'sents_cv': 0.525, 'sents_autocorr': -0.794}
    ```
