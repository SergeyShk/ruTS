# Словарь ударений Козиева

``` {.python .signature}
StressDict(data_dir=DEFAULT_DATASET_DIR)
```

[Словарь ударений](https://github.com/Koziev/NLP_Datasets#ударения) Ильи Козиева (all_accents): 1 680 535 словоформ с позицией основного ударения. Данные Википедии и Викисловаря дополнены формами по таблицам словоизменения грамматического словаря автора в предположении, что ударение при склонении и спряжении не сдвигается, поэтому у форм с подвижным ударением (реки́ - ре́ки, воды́ - во́ды) записан один из вариантов, омографы (за́мок - замо́к) даны одной строкой, а буква ё везде заменена на е.

Словарь распространяется под лицензией CC0 и загружается из репозитория автора по закрепленному коммиту (10.6 МБ, файл 77 МБ) с проверкой контрольной суммы SHA-256. Файл читается один раз на процесс и индексируется целиком в памяти без разбора строк: поиск словоформы идет двоичным поиском по отсортированному файлу, поэтому загрузка занимает доли секунды, а словарь - около 100 МБ памяти.

Словарь используется классом [`VerseStats`](../stats/verse_stats.md) и функциями расстановки ударений [`word_stress`](../syllables.md#word_stress) и [`accentuate`](../stats/verse_stats.md#accentuate): они поправляют известные ошибки словаря, восстанавливают ударение по букве ё и подгоняют его под метр.

Исключения:

- `SourceTypeError` - `data_dir`, который не строка и не `Path`.

=== "Код"

    ``` python
    from ruts.datasets import StressDict

    sd = StressDict()
    sd.download()
    sd.info["license"]
    ```

=== "Результат"

    ```
    'CC0-1.0'
    ```

## Параметры

| Параметр | Тип | По умолчанию | Описание |
| :------- | :-- | :----------- | :------- |
| `data_dir` | `str` / `Path` | `DEFAULT_DATASET_DIR` | Путь к директории со словарем; по умолчанию `dicts` в `DEFAULT_DATA_DIR` |

## Методы

`download(force=False)` загружает словарь из сети и извлекает файл. Загруженный архив сверяется с контрольной суммой SHA-256; поврежденный или подмененный файл удаляется с ошибкой `DownloadError`, чтобы повторная загрузка не пропускалась. Если архив уже есть, а файла словаря нет, архив извлекается заново.

| Параметр | Тип | По умолчанию | Описание |
| :------- | :-- | :----------- | :------- |
| `force` | `bool` | `False` | Загрузить словарь, даже если он уже загружен |

Файл, который не удалось загрузить, тоже дает `DownloadError`, архив, который не удалось извлечь, - `DataFileError`.

`check_data()` проверяет, что файл словаря на месте, и возвращает `True`; незагруженный словарь дает `DatasetNotFoundError` с командами загрузки, как и поиск по нему.

`lookup(word)` возвращает номер ударного слога словоформы, считая с нуля (слоги считаются по гласным), `None` для словоформы вне словаря или без указанного ударения. Словоформа приводится к нижнему регистру, ё заменяется на е, как в словаре.

| Параметр | Тип | По умолчанию | Описание |
| :------- | :-- | :----------- | :------- |
| `word` | `str` | - | Словоформа |

=== "Код"

    ``` python
    sd.lookup("корова"), sd.lookup("ёжик"), sd.lookup("котоведение")
    "корова" in sd, len(sd)
    ```

=== "Результат"

    ```
    (1, 0, None)
    (True, 1680535)
    ```

`get_records(limit=None)` возвращает генератор записей словаря в порядке файла (алфавитном): словоформа и номер ударного слога; `get_texts` с тем же параметром - генератор словоформ.

| Параметр | Тип | По умолчанию | Описание |
| :------- | :-- | :----------- | :------- |
| `limit` | `int` | `None` | Количество записей |

`limit`, который не целое неотрицательное число, дает `ParameterError`.

=== "Код"

    ``` python
    for record in sd.get_records(limit=2):
        print(record)
    list(sd.get_texts(limit=2))
    ```

=== "Результат"

    ```
    {'word': '-де', 'stress': 0}
    {'word': '-ка', 'stress': 0}
    ['-де', '-ка']
    ```
