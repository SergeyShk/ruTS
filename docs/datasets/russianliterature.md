# Русская классическая литература

``` {.python .signature}
RussianLiterature(data_dir=DEFAULT_DATASET_DIR)
```

Собрание русской классической литературы [RusLit](https://github.com/d0rj/RusLit) (на Kaggle - [russian-literature](https://www.kaggle.com/datasets/d0rj3228/russian-literature)): 373 произведения 12 авторов XIX - начала XX века, 38 млн символов, четыре жанра:

| Жанр | Ключ | Авторы | Произведений |
| :--- | :--- | :----- | :----------- |
| Проза | `prose` | Чехов (75), Толстой (42), Достоевский (33), Горький (31), Брюсов (30), Гоголь (15), Герцен (11), Пушкин (10), Тургенев (10), Блок (4), Лермонтов (3) | 264 |
| Поэзия | `poems` | Пушкин (30), Лермонтов (18), Некрасов (15), Блок (10) | 73 |
| Публицистика | `publicism` | Толстой | 26 |
| Драма | `drama` | Пушкин (5), Чехов (2), Горький (2), Гоголь (1) | 10 |

Тексты в общественном достоянии (на Kaggle указана лицензия PDDL), собраны с сайтов LitLib, Wikisource и Ilibrary. Год написания (`1825` или `1824-1825`) есть у всех произведений, кроме 27. Авторы в записях - русские имена вместо названий папок (`Chekhov` → «Антон Чехов»). Пьесы собрания лежат в папках прозы и поэзии, набор относит их к драме. Из текстов убраны примечания и сноски, в том числе авторские, комментарии и статьи изданий, варианты, оглавления и переводы, а из трех файлов - предисловие публикатора и повторы других произведений. Собрание подходит для атрибуции авторства и сравнения жанров.

Архив репозитория (20 МБ) загружается по закрепленному коммиту, тексты читаются по одному.

Исключения:

- `SourceTypeError` - `data_dir`, который не строка и не `Path`.

=== "Код"

    ``` python
    from ruts.datasets import RussianLiterature

    rl = RussianLiterature()
    rl.download()
    rl.info
    ```

=== "Результат"

## Параметры

| Параметр | Тип | По умолчанию | Описание |
| :------- | :-- | :----------- | :------- |
| `data_dir` | `str` / `Path` | `DEFAULT_DATASET_DIR` | Путь к директории с набором данных; по умолчанию `texts` в `DEFAULT_DATA_DIR` |

## Атрибуты

| Атрибут | Тип | Описание |
| :------ | :-- | :------- |
| `genres` | `tuple[str]` | Кортеж жанров: `prose`, `poems`, `publicism`, `drama` |
| `authors` | `dict[str, str]` | Русские имена авторов по названиям папок |
| `info` | `dict[str, str]` | Наименование набора данных и справочная информация о нем |

## Методы

`download(force=False)` загружает архив из сети с проверкой контрольной суммы и извлекает файлы.

| Параметр | Тип | По умолчанию | Описание |
| :------- | :-- | :----------- | :------- |
| `force` | `bool` | `False` | Загрузить набор данных, даже если он уже загружен |

Архив, который не удалось загрузить или который дважды не прошел проверку контрольной суммы, дает `DownloadError`, архив, который не удалось извлечь, - `DataFileError`.

`check_data()` проверяет, что набор данных загружен полностью, и возвращает `True`; незагруженный или неполный набор дает `DatasetNotFoundError` с командами загрузки.

`get_texts(genre=None, author=None, year_from=None, year_to=None, min_len=None, max_len=None, limit=None)` извлекает тексты (без заголовков) из набора данных.

| Параметр | Тип | По умолчанию | Описание |
| :------- | :-- | :----------- | :------- |
| `genre` | `str` | `None` | Жанр: `prose`, `poems`, `publicism` или `drama` |
| `author` | `str` | `None` | Автор (подстрока русского имени без учета регистра и буквы ё) |
| `year_from` | `int` | `None` | Наименьший год написания |
| `year_to` | `int` | `None` | Наибольший год написания |
| `min_len` | `int` | `None` | Минимальная длина текста (в символах) |
| `max_len` | `int` | `None` | Максимальная длина текста (в символах) |
| `limit` | `int` | `None` | Количество текстов |

Произведения без года не проходят фильтры по годам. Неизвестный жанр, `author`, который не строка, наименьший год больше наибольшего, граница длины, которая не целое положительное число, минимум больше максимума и `limit`, который не целое неотрицательное число, дают `ParameterError`; незагруженный набор данных - `DatasetNotFoundError`, файл, который не удалось прочитать, - `DataFileError`.

=== "Код"

    ``` python
    for text in rl.get_texts(genre="poems", author="Пушкин", limit=1):
        print(text[:57])
    ```

!!! warning "Имя автора в тексте"
    Большинство файлов источника начинается с имени автора и названия («Александр Пушкин» и «19 ОКТЯБРЯ», «Валерий Брюсов. Бемоль»), для атрибуции авторства это утечка признака. Однозначные заголовки срезаются, так очищены 288 из 373 текстов. У 8 текстов фамилия автора остается в первых 200 символах - в заголовках других форм («Антон Павлович Чехов. Палата No 6») и посвящениях («Посвящается графине М. Н. Толстой»). Для строгой атрибуции проверяйте начало текстов или отбрасывайте первые строки.

`get_records` с теми же параметрами извлекает записи (с заголовками) из набора данных. Поля записи: `genre` - жанр, `author` - автор, `title` - название, `year_from` и `year_to` - годы написания (`None` без даты), `text` - очищенный текст без заголовка с автором и названием, `file` - путь к файлу.

=== "Код"

    ``` python
    for record in rl.get_records(author="Некрасов", year_from=1860, year_to=1870):
        print(record["title"], record["year_from"], record["year_to"], len(record["text"]))
    ```
