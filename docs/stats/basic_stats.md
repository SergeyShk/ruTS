# Базовые статистики

!!! info ""
    **ruts.basic_stats.BasicStats**

## Описание

<!-- core: stats/basic_stats.md:BasicStats 9bab5af -->
Базовые статистики текста: количество предложений, слов, символов, букв, пробелов, слогов и знаков препинания, распределения слов по числу букв и слогов, длинные, сложные, простые, односложные и многосложные слова. Источником данных может быть текст или объект `Doc` библиотеки [spaCy](https://github.com/explosion/spaCy). Буквы считаются по `str.isalpha`, поэтому цифры, дефисы и знаки внутри слова буквами не являются.

Слова строки дает экстрактор слов, ее предложения - экстрактор предложений. Слова `Doc` берутся из его токенов (знаки препинания и символы вроде `€` или `%` отбрасываются), предложения - из его границ, а если их нет - из экстрактора предложений; явно переданный экстрактор применяется к тексту `Doc`. Предложение из одних знаков препинания не содержит слов и не считается.

Знаки ударения и мягкие переносы не считаются ни символами, ни частями слов, а й и ё из двух символов - одна буква (`ruts.utils.strip_marks`): текст с ударениями дает те же статистики, что без них.

!!! note "Примечание"
    Вычисление статистик происходит в момент инициализации объекта класса `BasicStats`.

## Языковые крючки

Класс расширяет `BasicStats` ядра [anyTS](https://sergeyshk.github.io/anyTS/stats/basic_stats/) крючками русского языка: слоги слова считает [`count_syllables`](../syllables.md#count_syllables), экстракторы по умолчанию - русские [`SentsExtractor`](../extractors/sentences.md) и [`WordsExtractor`](../extractors/words.md), а части дефисного слова, разрезанного spaCy, склеиваются (`во-первых` - одно слово). `Doc` без границ предложений (`spacy.blank`, пайплайн без `parser` и `senter`) берет предложения из текста через `SentsExtractor`.

## Параметры

<!-- core: stats/basic_stats.md:BasicStats-parameters 2296788 -->
| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `source` | str/Doc | `-` | Источник данных (строка или объект Doc) |
| `sents_extractor` | SentsExtractor | `None` | Инструмент для извлечения предложений; для Doc применяется к его тексту |
| `words_extractor` | WordsExtractor | `None` | Инструмент для извлечения слов; для Doc применяется к его тексту |
| `normalize` | bool | `False` | Вычислять нормализованные статистики |
| `complex_syl_factor` | int | `COMPLEX_SYL_FACTOR` | Минимальное количество слогов в сложном слове |
| `long_word_letter_factor` | int | `LONG_WORD_LETTER_FACTOR` | Минимальное количество букв в длинном слове |

Источник, который не строка и не `Doc`, и экстрактор другого типа дают `SourceTypeError`, источник без слов - `SourceError`, порог, который не целое число не меньше единицы, - `ParameterError`.

!!! note "Примечание"
    В ruTS сложное слово - от четырех слогов, длинное - от шести букв: `COMPLEX_SYL_FACTOR = 4` и `LONG_WORD_LETTER_FACTOR = 6` из `ruts.constants`.

## Методы

### count_words_by_syllables, count_words_by_letters

<!-- core: stats/basic_stats.md:BasicStats-count_words_by abc6821 -->
`count_words_by_syllables(min_syllables)` и `count_words_by_letters(min_letters)` возвращают количество слов не меньше чем с заданным числом слогов или букв; минимум, который не целое число, дает `ParameterError`.

!!! note "Примечание"
    Методы позволяют пересчитать количество сложных и длинных слов с порогом, отличным от заданного при инициализации объекта. Так, класс [`ReadabilityStats`](readability_stats.md) использует их для вычисления индекса SMOG (сложное слово - от 5 слогов) и индекса LIX (длинное слово - от 7 букв).

### get_stats

<!-- core: stats/basic_stats.md:BasicStats-get_stats c61b85d -->
Возвращает справочник с вычисленными статистиками - копию: ее правка не меняет объект.

Рассмотрим пример вычисления базовых текстовых статистик с использованием нормализации:

!!! example "Пример"

    _Код_:

    ``` python
    # Загрузка библиотек
    from ruts import BasicStats

    # Подготовка данных
    text = "Существуют три вида лжи: ложь, наглая ложь и статистика"

    # Вычисление статистик
    bs = BasicStats(text, normalize=True)
    bs.get_stats()
    ```

<!-- core: stats/basic_stats.md:BasicStats-print_stats 3af6554 -->

## Профиль пунктуации { #punctuation }

!!! info ""
    **ruts.basic_stats.count_punctuations()**, **ruts.basic_stats.punctuation_profile()**

<!-- core: stats/basic_stats.md:count_punctuations fdfb6b0 -->
`count_punctuations(text, marks, dash_pattern)` считает знаки препинания по типам - это же распределение лежит в атрибуте `c_punctuations`: запятые, точки, вопросительные и восклицательные знаки, многоточия, двоеточия, точки с запятой, тире, дефисы, кавычки-ёлочки, кавычки, скобки и прочие знаки. Сначала считаются тире, набранные дефисами (`dash_pattern`), затем многоточия - символ `…`, три и более точек или две точки после `?` и `!`, один знак, точки которого в точки не входят (`Кто там?..` - вопрос и многоточие), - а затем каждый знак по его типу в `marks`; любой другой символ категорий Unicode P и S - прочий знак (`§`, `€`, `°`). `marks` сопоставляет каждому знаку, одному символу, один из типов, иначе `ParameterError`, а `dash_pattern` - скомпилированное регулярное выражение; текст, который не строка, знаки, которые не словарь, и тире, которые не скомпилированное выражение, дают `SourceTypeError`.

В ruTS `count_punctuations(text)` берет знаки ядра с нижней кавычкой `„` в роли кавычки, а висячий дефис перед `и`, `или`, `либо` или запятой остается дефисом (`двух- и трёхкомнатные`, `сорока-, пятидесятилетние`), тогда как тире реплики, набранное дефисом, - тире (`- Ушли, - сказал он`). `punctuation_profile(text, n_words=None)` переводит количества в частоты на 1000 слов и добавляет `yo_share` - долю буквы ё среди букв е и ё, то есть пишет ли автор ё.

Профиль - редакторский и стилометрический признак: у Чехова многоточий и восклицаний в разы больше, чем у Толстого (см. [сравнение корпусов](../corpus/compare.md)). Он зависит от оформления текста - типографских кавычек и тире, буквы ё - и легко подделывается, поэтому его стоит смотреть отдельно от лингвистических признаков.

!!! example "Пример"

    ``` python
    from ruts.basic_stats import count_punctuations, punctuation_profile

    text = "Кот — «зверь»... Пёс, конечно, - друг; а кто-то (тот, что ещё жив) — нет!"
    {kind: count for kind, count in count_punctuations(text).items() if count}
    # {'comma': 3, 'exclamation': 1, 'ellipsis': 1, 'semicolon': 1, 'dash': 3, 'hyphen': 1, 'angle_quotes': 2, 'parentheses': 2}

    round(punctuation_profile(text)["dash"], 1), round(punctuation_profile(text)["yo_share"], 2)
    # (250.0, 0.33)
    ```
