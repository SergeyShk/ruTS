Метрики [удобочитаемости](https://ru.wikipedia.org/wiki/%D0%A3%D0%B4%D0%BE%D0%B1%D0%BE%D1%87%D0%B8%D1%82%D0%B0%D0%B5%D0%BC%D0%BE%D1%81%D1%82%D1%8C) текста по его базовым статистикам: средней длине предложения в словах, средней длине слова в слогах или буквах, доле сложных и длинных слов и вариативности длины слова. Источник данных - текст, объект `Doc` библиотеки [spaCy](https://github.com/explosion/spaCy) или готовые базовые статистики, которые берутся как есть; экстракторы передаются базовым статистикам текста или `Doc`. Формулы считают только буквы учтенных слов, поэтому экстрактор слов, который отбрасывает слова, не удлиняет среднее слово.

Метрики - свойства, которые вычисляются при каждом обращении, поэтому изменение `coefficients` объекта действует сразу.

Исключения:

- `SourceTypeError` - источник, который не строка, не `Doc` и не базовые статистики, базовые статистики не того класса, что у библиотеки, экстрактор другого типа, строка или `Doc` для класса без `basic_stats_class`;
- `SourceError` - источник без слов или предложений;
- `ParameterError` - неизвестный пресет или пресет, который не строка.

Метрики оценивают удобочитаемость со стороны языка - сложности слов и синтаксических конструкций, а не полиграфического исполнения текста. Они исходят из того, что короткие предложения читать легче, чем длинные, длинные слова затрудняют чтение, а низкочастотные и незнакомые слова замедляют читателя.

Класс расширяет `ReadabilityStats` ядра [anyTS](https://sergeyshk.github.io/anyTS/stats/readability_stats/) крючками русского языка, о которых говорят карточки метрик: [базовыми статистиками](basic_stats.md) ruTS, которые по умолчанию берут русские [`SentsExtractor`](../extractors/sentences.md) и [`WordsExtractor`](../extractors/words.md), [пресетами](#presets) коэффициентов, русскими формулами, сводным классом по формулам ruTS, ступенями обучения российской школы, шкалами с русскими подписями и скоростями чтения русских читателей. Таблица `print_stats` и сообщения об ошибках - по-русски (`READABILITY_STATS_DESC` и `CORE_MESSAGES` из `ruts.constants`).

=== "Код"

    ``` python
    from ruts import ReadabilityStats

    text = "Ног нет, а хожу, рта нет, а скажу: когда спать, когда вставать, когда работу начинать"
    rs = ReadabilityStats(text)
    rs.print_stats()
    ```

## Параметры

| Параметр | Тип | По умолчанию | Описание |
| :------- | :-- | :----------- | :------- |
| `source` | `str` / `Doc` / `BasicStats` | - | Источник данных (строка, объект Doc или готовые базовые статистики) |
| `sents_extractor` | `SentsExtractor` | `None` | Инструмент для извлечения предложений |
| `words_extractor` | `WordsExtractor` | `None` | Инструмент для извлечения слов |
| `preset` | `str` | `'plainrussian'` | Пресет коэффициентов: `plainrussian`, `fiction` или `academic` |

Объект хранит базовые статистики текста в `bs`, название пресета - в `preset`, только для чтения, а коэффициенты формул пресета - в `coefficients`, копии, которую можно менять для отдельного объекта. Объект другого пресета может взять готовые базовые статистики: `ReadabilityStats(rs.bs, preset="fiction")`.

## Пресеты коэффициентов { #presets }

Коэффициенты формул - параметры их функций, а пресет задает их по формулам. Пресеты различаются коэффициентами теста Флеша-Кинкайда и индекса Флеша; коэффициенты индексов Колман-Лиау, SMOG и ARI во всех пресетах взяты из проекта plainrussian, так как других адаптаций для русского языка не опубликовано, а остальные формулы от пресета не зависят.

| Пресет | Источник | Корпус | Тест Флеша-Кинкайда | Индекс Флеша |
| :----- | :------- | :----- | :------------------ | :----------- |
| `plainrussian` | [Plain Russian Language](https://github.com/infoculture/plainrussian) (Бегтин) | 68 текстов с метками класса | `0.318·ASL + 14.2·ASW − 30.5` | `206.835 − 1.3·ASL − 60.1·ASW` (Оборнева, вариант А, так как plainrussian индекс Флеша не выводит) |
| `fiction` | Оборнева (2005/2006) | около 6 млн слов художественных текстов | `0.5·ASL + 8.4·ASW − 15.59` | `206.835 − 1.3·ASL − 60.1·ASW` (вариант А) |
| `academic` | Соловьёв, Иванов, Солнышкина (2018); Солнышкина и Кисельников (2015) | 14 учебников обществознания для 5-11 классов | `0.36·ASL + 5.76·ASW − 11.97` (FKG_SIS) | `206.836 − 1.52·ASL − 65.14·ASW` (Оборнева, вариант Б) |

Здесь ASL - среднее число слов в предложении, ASW - среднее число слогов в слове. Справочник всех коэффициентов - `ruts.constants.READABILITY_PRESETS`.

=== "Код"

    ``` python
    ReadabilityStats(text).flesch_kincaid_grade
    ReadabilityStats(text, preset="fiction").flesch_kincaid_grade
    ReadabilityStats(text, preset="academic").flesch_kincaid_grade
    ```

=== "Результат"

    ```
    -2.0633333333333326
    5.91
    3.0299999999999994
    ```

Пресеты одинаково согласуются с меткой класса, но дают разную шкалу, а порядок текстов у них совпадает не полностью. На наборе [`TextsByGrade`](../datasets/textsbygrade.md) корреляция Спирмена теста Флеша-Кинкайда с меткой класса у всех трех пресетов 0.79, а медианы теста по группам меток различаются:

| Метка | Текстов | `plainrussian` | `fiction` | `academic` |
| :---- | :------ | :------------- | :-------- | :--------- |
| 1 | 11 | 2.9 | 7.5 | 4.0 |
| 3-4 | 10 | 4.2 | 8.7 | 4.9 |
| 5-9 | 12 | 4.4 | 8.7 | 4.9 |
| 10-11 | 18 | 6.7 | 11.7 | 7.0 |
| 12-17 | 17 | 23.7 | 24.4 | 15.9 |
| 1 ([`SovChLit`](../datasets/sovchlit.md)) | 179 | 1.5 | 6.1 | 3.1 |

На школьных текстах (метки 1-11) тест с пресетом `fiction` выше метки примерно на четыре класса (медиана отклонения +3.9 против −0.9 у `plainrussian` и −0.2 у `academic`), на хрестоматии для 1 класса `SovChLit` - примерно на пять. Поэтому его значение не стоит читать как класс российской школы: для класса читателя подходят `plainrussian` (по умолчанию; его коэффициенты подбирались на `TextsByGrade`) и `academic`, а `fiction` - для сравнения с работами, где использованы коэффициенты Оборневой. Сводный класс от пресета зависит меньше: тест Флеша-Кинкайда в нем лишь одна из формул (медиана на `TextsByGrade` 7.75 у `fiction` против 6.75 у `plainrussian`).

## Метрики

Формулу считает функция из ее карточки по количествам `bs`; коэффициенты по умолчанию функций адаптированы для русского языка. Формулы ядра берут коэффициенты из `coefficients`, где пресет задает коэффициенты теста Флеша-Кинкайда, индекса Флеша и индексов Колман-Лиау, SMOG и ARI; формулы Соловьёва, Иванова, Солнышкиной, Мацковского и Дейла-Чейла считаются с коэффициентами своих функций, и `coefficients` на них не действует. Формула по количествам дает `nan`, если количество слов или предложений, на которое она делит, равно нулю.

| Метрика | Что измеряет | Диапазон | Чем больше, тем |
| :------ | :----------- | :------- | :-------------- |
| [`flesch_kincaid_grade`](#flesch_kincaid_grade) | Класс по длине предложения и слогам на слово | годы обучения, ниже 0 у простейших текстов | сложнее текст |
| [`flesch_reading_easy`](#flesch_reading_easy) | Легкость чтения по длине предложения и слогам на слово | номинально 0-100, выше 100 у простейших текстов и ниже 0 у сложнейших | легче текст |
| [`coleman_liau_index`](#coleman_liau_index) | Класс по буквам и предложениям на 100 слов | годы обучения, ниже 0 у простейших текстов | сложнее текст |
| [`smog_index`](#smog_index) | Класс по сложным словам на предложение | годы обучения | сложнее текст |
| [`automated_readability_index`](#automated_readability_index) | Класс по буквам на слово и длине предложения | годы обучения, ниже 0 у простейших текстов | сложнее текст |
| [`lix`](#lix) | Длина предложения и доля длинных слов | от 0 | сложнее текст |
| [`rix`](#rix) | Длинные слова на предложение | от 0 | сложнее текст |
| [`sis_grade`](#sis_grade) | Класс по длине предложения и буквам на слово | класс школы, ниже 0 у простейших текстов | сложнее текст |
| [`matskovsky_index`](#matskovsky_index) | Длина предложения и доля сложных слов | от 0 | сложнее текст |
| [`dale_chall_index`](#dale_chall_index) | Класс по доле сложных слов и длине предложения | годы обучения | сложнее текст |
| [`gunning_fog_index`](#gunning_fog_index) | Класс по длине предложения и доле сложных слов | годы обучения | сложнее текст |
| [`consensus_grade`](#consensus_grade) | Медиана формул класса и индекса Флеша как класса | годы обучения, ниже 0 у простейших текстов | сложнее текст |
| [`reading_time`](#reading_time) | Время чтения при скорости `reading_speed` | минуты, больше 0 | длиннее текст |
| [`mu_index`](#mu_index) | Средняя длина слова в буквах против ее дисперсии; вне `get_stats` | больше 0, `nan` меньше чем с двумя словами или без вариативности | легче текст |

### Тест Флеша-Кинкайда { #flesch_kincaid_grade }

`flesch_kincaid_grade` · Kincaid et al., 1975
{ .metric-meta }

``` {.python .signature}
calc_flesch_kincaid_grade(n_syllables, n_words, n_sents, a=0.318, b=14.2, c=30.5)
```

<!-- core: stats/readability_stats.md:calc_flesch_kincaid_grade d833b41 -->
Число лет обучения, необходимых для чтения текста, по средней длине предложения в словах и средней длине слова в слогах.

$$
a \cdot \frac{\textrm{Количество слов}}{\textrm{Количество предложений}} + b \cdot \frac{\textrm{Количество слогов}}{\textrm{Количество слов}} - c
$$

Коэффициенты по умолчанию взяты из актуальной версии проекта [Plain Russian Language](https://github.com/infoculture/plainrussian). Другие коэффициенты для русского языка дают [пресеты](#presets): Оборневой (`0.5`, `8.4`, `15.59`) и FKG_SIS Соловьёва, Иванова и Солнышкиной (`0.36`, `5.76`, `11.97`).

| Параметр | Тип | По умолчанию | Описание |
| :------- | :-- | :----------- | :------- |
| `n_syllables` | `int` | - | Количество слогов |
| `n_words` | `int` | - | Количество слов |
| `n_sents` | `int` | - | Количество предложений |
| `a` | `float` | `0.318` | Коэффициент a, при средней длине предложения |
| `b` | `float` | `14.2` | Коэффициент b, при средней длине слова |
| `c` | `float` | `30.5` | Коэффициент c, свободный член |

### Индекс SMOG { #smog_index }

`smog_index` · McLaughlin, 1969
{ .metric-meta }

``` {.python .signature}
calc_smog_index(n_complex, n_sents, a=1.1, b=64.6, c=0.05)
```

<!-- core: stats/readability_stats.md:calc_smog_index 8eac9a0 -->
Число лет обучения, необходимых для чтения текста, по сложным словам на предложение. В исходной формуле сложные слова - от трех слогов, а `b` приводит их количество к выборке из 30 предложений.

$$
a \cdot \sqrt{b \cdot \frac{\textrm{Количество сложных слов}}{\textrm{Количество предложений}}} + c
$$

Количество слов или предложений, которое не целое неотрицательное число, дает `ParameterError`.

Коэффициенты по умолчанию проекта [Plain Russian Language](https://github.com/infoculture/plainrussian) получены для сложных слов от пяти слогов, поэтому класс `ReadabilityStats` передает в функцию количество слов от 5 слогов (`ruts.constants.SMOG_COMPLEX_SYL_FACTOR`), а не атрибут `n_complex_words` базовых статистик.

| Параметр | Тип | По умолчанию | Описание |

| `n_sents` | `int` | - | Количество предложений |

### Legibilidad µ { #mu_index }

`mu_index` · Muñoz Baquedano and Muñoz Urra, 2006
{ .metric-meta }

Средняя длина слова в буквах, деленная на ее выборочную дисперсию и умноженная на 100; подбираемых коэффициентов нет. Слова без букв (числа) не учитываются; меньше чем с двумя словами или без вариативности индекс не определен (`nan`).

$$
100 \cdot \frac{\bar{x}}{s^2}, \quad s^2 = \frac{\sum (x_i - \bar{x})^2}{n - 1}
$$

где $x_i$ - количество букв слова, $n$ - количество слов.

Индекс получен на испанских текстах, поэтому в `get_stats` ruTS не входит, хотя свойство `mu_index` у объекта есть. Его функция - [`calc_mu_index`](https://sergeyshk.github.io/anyTS/stats/readability_stats/#mu_index) ядра anyTS.

</div>

## Методы

<!-- core: stats/readability_stats.md:ReadabilityStats-describe_grade 01276a5 -->
`describe_grade(stat)` возвращает ступень обучения и возраст читателя для сводного класса или формулы класса `stat`, по умолчанию `consensus_grade`; другая метрика дает `ParameterError`.

<!-- core: stats/readability_stats.md:ReadabilityStats-describe_level d50eec4 -->
`describe_level(stat)` возвращает полосу шкалы интерпретации (`level_scale`) метрики `stat`, по умолчанию `flesch_reading_easy`; метрика без шкалы полос и неопределенное значение (nan) дают `ParameterError`.

<!-- core: stats/readability_stats.md:ReadabilityStats-describe 3fed408 -->
`describe(stat)` возвращает прочтение любой метрики по ее шкале: для сводного класса и формулы класса - ступень обучения и возраст читателя (`describe_grade`), для метрики со шкалой полос (`level_scale`) - ее полосу, для другой метрики из `grade_scales` - ступень и возраст по числу лет обучения, которое дает ее шкала, и `None` для метрики без шкалы или с неопределенным значением (nan). Имя, которого нет ни в `stats_desc`, ни среди открытых свойств класса, дает `UnknownStatError`.

<!-- core: stats/readability_stats.md:ReadabilityStats-reading_time_by_speed 02714c8 -->
`reading_time_by_speed(wpm)` возвращает время чтения текста в минутах при скорости `wpm`, слов в минуту; скорость, которая не положительное число, дает `ParameterError`.

<!-- core: stats/readability_stats.md:ReadabilityStats-reading_time_by_norm 8a24e05 -->
`reading_time_by_norm(norm)` возвращает время чтения текста в минутах при скоростях нормы `norm` из `reading_speed_norms` в их порядке; неизвестная норма дает `ParameterError`.

В ruTS нормы - из справочника `ruts.constants.READING_SPEED_NORMS`, и метод возвращает время чтения при верхней и при нижней границе нормы.

`sis_grade_by_stage(stage)` возвращает значение [формулы Соловьёва, Иванова, Солнышкиной](#sis_grade) с коэффициентами ступени обучения `stage`: `2-4`, `5-7` или `8-11`; неизвестная ступень дает `ParameterError`.
{ #sis_grade_by_stage }

`sis_grade_by_freq(mean_ipm, stage=None)` возвращает значение [формулы с частотностью](#calc_sis_grade_freq) при средней частотности знаменательных слов `mean_ipm` - атрибуте [`mean_ipm_content`](lexical_stats.md#frequency) класса `LexicalStats` - с коэффициентами ступени `stage` или, без нее, общей формулы. Отрицательная или бесконечная частотность, частотность, которая не число, и неизвестная ступень дают `ParameterError`, а `nan` дает `nan`.
{ #sis_grade_by_freq }

<!-- core: stats/readability_stats.md:ReadabilityStats-get_stats 0cb58e2 -->
`get_stats()` возвращает справочник метрик удобочитаемости из `stats_desc`.

<!-- core: stats/readability_stats.md:ReadabilityStats-print_stats ac340b3 -->
`print_stats()` выводит таблицу метрик удобочитаемости с их описаниями из `stats_desc` под заголовками из `stats_headers`.

=== "Код"

    ``` python
    from ruts import ReadabilityStats

    text = "Ног нет, а хожу, рта нет, а скажу: когда спать, когда вставать, когда работу начинать"
    rs = ReadabilityStats(text)
    rs.describe_grade(), rs.describe_grade("gunning_fog_index")
    rs.describe("flesch_reading_easy"), rs.describe_level("lix")
    rs.describe("rix"), rs.describe("matskovsky_index")
    rs.reading_time_by_speed(120), rs.reading_time_by_norm("grade_1")
    rs.get_stats()
    ```

## Шкалы { #scales }

Метод `describe_level` читает индекс Флеша, LIX и RIX по шкалам полос из их карточек (`ruts.constants.READABILITY_LEVEL_SCALES`), а `describe` - любую метрику: эти три по тем же шкалам, формулы класса и сводный класс - по ступеням обучения [`grade_to_age`](#grade_to_age); для метрики без шкалы он возвращает `None`.

### Класс и возраст читателя { #grade_to_age }

``` {.python .signature}
grade_to_age(grade, levels=((1, 3, '1-3-й класс', '6-8 лет'), (4, 6, '4-6-й класс', '9-11 лет'), (7, 9, '7-9-й класс', '12-14 лет'), (10, 11, '10-11-й класс', '15-16 лет'), (12, 14, '1-3-й курс вуза', '17-19 лет'), (15, 17, '4-6-й курс вуза', '20-22 года')), above=('аспирантура', 'старше 22 лет'))
```

<!-- core: stats/readability_stats.md:grade_to_age 751554e -->
Ступень обучения и возраст читателя по значению формулы класса: значение округляется арифметически и попадает в первую ступень, последний год которой оно не превышает, значения меньше 1 - в первую ступень; после последней ступени лежит `above`. Класс, который не конечное число, ступени, которые не четверки из двух целых лет и двух строк по возрастанию лет, и `above`, который не пара строк, дают `ParameterError`.

Ступени ruTS по умолчанию взяты из таблицы `GRADE_TEXT` проекта [Plain Russian Language](https://github.com/infoculture/plainrussian) (`ruts.constants.GRADE_AGE_LEVELS` и `POSTGRADUATE_LEVEL`):

| Класс | Ступень | Возраст |
| :---- | :------ | :------ |
| 1-3 | 1-3-й класс | 6-8 лет |
| 4-6 | 4-6-й класс | 9-11 лет |
| 7-9 | 7-9-й класс | 12-14 лет |
| 10-11 | 10-11-й класс | 15-16 лет |
| 12-14 | 1-3-й курс вуза | 17-19 лет |
| 15-17 | 4-6-й курс вуза | 20-22 года |
| больше 17 | аспирантура | старше 22 лет |

| Параметр | Тип | По умолчанию | Описание |
| :------- | :-- | :----------- | :------- |
| `grade` | `float` | - | Значение формулы класса |
| `levels` | `list[tuple[int, int, str, str]]` | `GRADE_AGE_LEVELS` | Ступени - первый и последний год, ступень и возраст - по возрастанию |
| `above` | `tuple[str, str]` | `POSTGRADUATE_LEVEL` | Ступень и возраст после последней ступени |

### Полоса шкалы { #scale_level }

<!-- core: stats/readability_stats.md:scale_level ad443b9 -->
``` {.python .signature}
scale_level(value, scale)
```

Полоса шкалы для значения: шкала задается нижними границами полос по убыванию, значение попадает в первую полосу, границы которой достигает, а нижняя полоса открыта вниз.

| Параметр | Тип | По умолчанию | Описание |
| :------- | :-- | :----------- | :------- |
| `value` | `float` | - | Значение метрики |
| `scale` | `list[tuple[float, Any]]` | - | Нижние границы и их полосы по убыванию |

Значение, которое не конечное число, и шкала, которая пуста, не является списком пар из конечной нижней границы и полосы или с границами не по убыванию, дают `ParameterError`.

Шкалы ruTS - `ruts.constants.READING_EASE_LEVELS`, `LIX_LEVELS` и `RIX_LEVELS`.

=== "Код"

    ``` python
    from ruts.constants import READING_EASE_LEVELS
    from ruts.readability_stats import calc_flesch_reading_easy, scale_level

    flesch = calc_flesch_reading_easy(n_syllables=60, n_words=30, n_sents=2)
    flesch, scale_level(flesch, READING_EASE_LEVELS)
    ```

=== "Результат"

    ```
    (67.135, '8-й и 9-й класс')
    ```

## Нормы ступеней { #level_norms }

Сводный класс говорит, для какой ступени текст, но не каким бывает текст этой ступени. Для этого в справочнике `ruts.constants.LEVEL_NORMS` есть нормы признаков ступеней: обычные диапазоны (квартили) длины предложения в словах, длины слова в буквах, доли слов от пяти слогов и лексического разнообразия MTLD у текстов от 100 слов с меткой ступени из наборов [`SovChLit`](../datasets/sovchlit.md) и [`TextsByGrade`](../datasets/textsbygrade.md). Нормы есть у школьных ступеней, для которых в наборах не меньше 10 таких текстов:

| Ступень | Текстов | Слов в предложении | Букв в слове | Доля слов от пяти слогов | MTLD |
| :------ | :------ | :----------------- | :----------- | :----------------------- | :--- |
| 1-3-й класс | 73 | 8.1-10.7 | 4.56-5.03 | 0.0-0.022 | 104-178 |
| 4-6-й класс | 12 | 10.2-14.6 | 5.16-5.33 | 0.039-0.052 | 220-373 |
| 10-11-й класс | 18 | 15.6-17.9 | 5.11-5.57 | 0.035-0.065 | 277-513 |

Нормы 1-3-го класса сняты почти целиком с текстов 1-го класса (70 из 73), поэтому текст для 2-3-го класса может выйти выше нормы, особенно по длине предложения. У 7-9-го класса в наборах семь текстов, а с метками вуза в `TextsByGrade` - статья Википедии, газетная статья и нормативные документы, написанные не для студентов определенного курса, поэтому у этих ступеней норм нет. Признаки текста короче 100 слов, особенно MTLD, с нормами сравнивать не стоит.

### Признаки текста { #level_features }

``` {.python .signature}
level_features(source)
```

Признаки текста, для которых есть нормы ступеней: слов в предложении, букв в слове (у слов, которые учитывают формулы класса), доля слов от пяти слогов (сложные слова SMOG, индексов Ганнинга и Дейла-Чейла) и лексическое разнообразие MTLD. Признаки считаются так же, как для норм, поэтому их можно сравнивать с нормами; признаки `Doc` считаются по его тексту, а не по границам предложений spaCy. Источник, который не строка и не `Doc`, дает `SourceTypeError`, источник без слов или предложений - `SourceError`.

| Параметр | Тип | По умолчанию | Описание |
| :------- | :-- | :----------- | :------- |
| `source` | `str` / `Doc` | - | Источник данных (строка или объект Doc) |

### Нормы и прочтение признака { #describe_level_norm }

``` {.python .signature}
level_norms(grade)
```

Нормы признаков ступени обучения, к которой относится класс, - обычные диапазоны (квартили) каждого признака `level_features`, или `None` для ступени без норм. Класс относится к ступени, как в [`grade_to_age`](#grade_to_age): округляется арифметически, класс меньше 1 - первая ступень. Класс, который не конечное число, дает `ParameterError`.

| Параметр | Тип | По умолчанию | Описание |
| :------- | :-- | :----------- | :------- |
| `grade` | `float` | - | Класс читателя или сводный класс текста |

``` {.python .signature}
describe_level_norm(stat, value, grade)
```

Прочтение признака текста по нормам ступени, к которой относится класс: «ниже нормы ступени», «в норме ступени» (между квартилями, включая их) или «выше нормы ступени» (`ruts.constants.LEVEL_NORM_BANDS`). Ступень без норм и неопределенное значение (nan) дают `None`, неизвестный признак - `UnknownStatError`, значение, которое не число, и класс, который не конечное число, - `ParameterError`.

| Параметр | Тип | По умолчанию | Описание |
| :------- | :-- | :----------- | :------- |
| `stat` | `str` | - | Название признака из `ruts.constants.LEVEL_NORMS_DESC` |
| `value` | `float` | - | Значение признака |
| `grade` | `float` | - | Класс читателя или сводный класс текста |

=== "Код"

    ``` python
    from ruts.datasets import SovChLit
    from ruts.readability_stats import describe_level_norm, level_features, level_norms

    level_norms(2)["words_per_sent"], level_norms(8)
    text = next(SovChLit().get_texts())
    features = level_features(text)
    {stat: describe_level_norm(stat, value, 1) for stat, value in features.items()}
    ```

=== "Результат"

    ```

    {'words_per_sent': 'выше нормы ступени',
     'letters_per_word': 'выше нормы ступени',
     'p_smog_complex_words': 'выше нормы ступени',
     'mtld': 'в норме ступени'}
    ```
