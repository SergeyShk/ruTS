# Метрики удобочитаемости

!!! info ""
    **ruts.readability_stats.ReadabilityStats**

## Описание

<!-- core: stats/readability_stats.md:ReadabilityStats b38cf74 -->
Метрики [удобочитаемости](https://ru.wikipedia.org/wiki/%D0%A3%D0%B4%D0%BE%D0%B1%D0%BE%D1%87%D0%B8%D1%82%D0%B0%D0%B5%D0%BC%D0%BE%D1%81%D1%82%D1%8C) текста по его базовым статистикам: средней длине предложения в словах, средней длине слова в слогах или буквах, доле сложных и длинных слов и вариативности длины слова. Источник данных - текст, объект `Doc` библиотеки [spaCy](https://github.com/explosion/spaCy) или готовые базовые статистики, которые берутся как есть; экстракторы передаются базовым статистикам текста или `Doc`. Формулы считают только буквы учтенных слов, поэтому экстрактор слов, который отбрасывает слова, не удлиняет среднее слово.

Метрики - свойства, которые вычисляются при каждом обращении, поэтому изменение `coefficients` объекта действует сразу.

Источник, который не строка, не `Doc` и не базовые статистики, базовые статистики не того класса, что у библиотеки, и экстрактор другого типа дают `SourceTypeError`, источник без слов или предложений - `SourceError`, неизвестный пресет или пресет, который не строка, - `ParameterError`.

!!! quote "Определение"

    Удобочитаемость («читабельность») - свойство текстового материала, характеризующее лёгкость восприятия его человеком в процессе чтения.

    Следует различать удобочитаемость текста с точки зрения:

    *   полиграфического исполнения текста;
    *   лингвистических особенностей текстового материала (сложность синтаксических конструкций, трудная для восприятия лексика и т.п.).

Коэффициенты формул, адаптированных для русского языка, задаются пресетом (см. [ниже](#presets)): по умолчанию используются коэффициенты проекта [Plain Russian Language](https://github.com/infoculture/plainrussian), полученные на 68 текстах с метками класса, доступны также коэффициенты Оборневой, полученные на художественных текстах (тест Флеша-Кинкайда по ним выше класса российской школы, см. [ниже](#presets)), и казанской группы (Соловьёв, Иванов, Солнышкина), полученные на учебниках.

Основные презумпции метрик удобочитаемости:

*   короткие предложения читать легче, чем длинные;
*   длинные слова затрудняют чтение;
*   читатель замедляется, встречая низкочастотные и/или незнакомые ему слова.

## Языковые крючки

Класс расширяет `ReadabilityStats` ядра [anyTS](https://sergeyshk.github.io/anyTS/stats/readability_stats/) крючками русского языка: [базовыми статистиками](basic_stats.md) ruTS, которые по умолчанию берут русские [`SentsExtractor`](../extractors/sentences.md) и [`WordsExtractor`](../extractors/words.md), пресетами коэффициентов `ruts.constants.READABILITY_PRESETS`, русскими формулами - Соловьёва, Иванова, Солнышкиной, Мацковского и Дейла-Чейла в адаптации plainrussian, формулами класса для сводного класса `ruts.constants.READABILITY_GRADE_STATS`, сложными словами от пяти слогов в SMOG, индексе Ганнинга и индексе Дейла-Чейла (`ruts.constants.SMOG_COMPLEX_SYL_FACTOR`), классами и возрастами таблицы plainrussian, шкалами индекса Флеша, LIX и RIX с русскими подписями (`ruts.constants.READABILITY_LEVEL_SCALES`), переводом индекса Флеша в класс по полосам его шкалы (`ruts.constants.READING_EASE_GRADES`) и скоростями чтения русских читателей.

Атрибут `mu_index` ядра (Legibilidad µ) не входит в `get_stats`: он получен на испанских текстах.

## Пресеты коэффициентов { #presets }

Пресет задает коэффициенты теста Флеша-Кинкайда и индекса Флеша. Коэффициенты индексов Колман-Лиау, SMOG и ARI во всех пресетах взяты из проекта plainrussian, так как других адаптаций для русского языка не опубликовано. Остальные формулы от пресета не зависят.

| Пресет | Источник | Корпус | Тест Флеша-Кинкайда | Индекс Флеша |
| :----: | :------: | :----: | :-----------------: | :----------: |
| `plainrussian` | [Plain Russian Language](https://github.com/infoculture/plainrussian) (Бегтин) | 68 текстов с метками класса | `0.318·ASL + 14.2·ASW − 30.5` | `206.835 − 1.3·ASL − 60.1·ASW` (Оборнева, вариант А, так как plainrussian индекс Флеша не выводит) |
| `fiction` | Оборнева (2005/2006) | около 6 млн слов художественных текстов | `0.5·ASL + 8.4·ASW − 15.59` | `206.835 − 1.3·ASL − 60.1·ASW` (вариант А) |
| `academic` | Соловьёв, Иванов, Солнышкина (2018); Солнышкина и Кисельников (2015) | 14 учебников обществознания для 5-11 классов | `0.36·ASL + 5.76·ASW − 11.97` (FKG_SIS) | `206.836 − 1.52·ASL − 65.14·ASW` (Оборнева, вариант Б) |

Здесь ASL - среднее число слов в предложении, ASW - среднее число слогов в слове. Справочник всех коэффициентов доступен как `ruts.constants.READABILITY_PRESETS`.

!!! example "Пример"

    ``` python
    from ruts import ReadabilityStats

    text = "Ног нет, а хожу, рта нет, а скажу: когда спать, когда вставать, когда работу начинать"
    ReadabilityStats(text).flesch_kincaid_grade
    # -2.0633333333333326
    ReadabilityStats(text, preset="fiction").flesch_kincaid_grade
    # 5.91
    ReadabilityStats(text, preset="academic").flesch_kincaid_grade
    # 3.0299999999999994
    ```

Пресеты одинаково согласуются с меткой класса, но дают разную шкалу, а порядок текстов у них совпадает не полностью. На наборе [`TextsByGrade`](../datasets/textsbygrade.md) корреляция Спирмена теста Флеша-Кинкайда с меткой класса у всех трех пресетов 0.79, а медианы теста по группам меток различаются:

| Метка | Текстов | `plainrussian` | `fiction` | `academic` |
| :---: | :-----: | :------------: | :-------: | :--------: |
| 1 | 11 | 2.9 | 7.5 | 4.0 |
| 3-4 | 10 | 4.2 | 8.7 | 4.9 |
| 5-9 | 12 | 4.4 | 8.7 | 4.9 |
| 10-11 | 18 | 6.7 | 11.7 | 7.0 |
| 12-17 | 17 | 23.7 | 24.4 | 15.9 |
| 1 ([`SovChLit`](../datasets/sovchlit.md)) | 179 | 1.5 | 6.1 | 3.1 |

На школьных текстах (метки 1-11) тест с пресетом `fiction` выше метки примерно на четыре класса (медиана отклонения +3.9 против −0.9 у `plainrussian` и −0.2 у `academic`), на хрестоматии для 1 класса `SovChLit` - примерно на пять. Поэтому его значение не стоит читать как класс российской школы: для класса читателя подходят `plainrussian` (по умолчанию; его коэффициенты подбирались на `TextsByGrade`) и `academic`, а `fiction` - для сравнения с работами, где использованы коэффициенты Оборневой. Сводный класс от пресета зависит меньше: тест Флеша-Кинкайда в нем лишь одна из формул (медиана на `TextsByGrade` 7.75 у `fiction` против 6.75 у `plainrussian`).

!!! note "Примечание"
    Каждую метрику можно вычислить отдельно, выполнив соответствующую функцию. Подробную информацию о метриках удобочитаемости и функциях, используемых для их вычисления, можно узнать в соответствующем [разделе](readability_stats_funcs.md).

## Интерпретация { #interpretation }

<!-- core: stats/readability_stats.md:ReadabilityStats-consensus c4a6ea5 -->
Атрибут `consensus_grade` - медиана значений формул класса (`grade_stats`), округленных арифметически, вместе с индексом удобочитаемости Флеша, переведенным в число лет обучения (`reading_ease_to_grade`) без округления. Библиотека выравнивает границы `reading_ease_grades` и каждой шкалы `preset_reading_ease_grades` по своей шкале индекса Флеша, чтобы сводный класс и `describe` читали значение одинаково.

Формулы класса в ruTS - тест Флеша-Кинкайда, индексы Колман-Лиау, SMOG, ARI, Дейла-Чейла и Ганнинга и формула Соловьёва, Иванова, Солнышкиной, а индекс Флеша [переводится в класс](readability_stats_funcs.md#flesch_reading_easy_to_grade) по полосам своей шкалы прочтения, так что индекс 45 и в `describe`, и в сводном классе читается как университет. Метод [`describe_grade`](#describe_grade) переводит сводный класс или отдельную формулу в класс школы и возраст читателя по таблице проекта plainrussian:

| Класс | Ступень | Возраст |
| :---: | :-----: | :-----: |
| 1-3 | 1-3-й класс | 6-8 лет |
| 4-6 | 4-6-й класс | 9-11 лет |
| 7-9 | 7-9-й класс | 12-14 лет |
| 10-11 | 10-11-й класс | 15-16 лет |
| 12-14 | 1-3-й курс вуза | 17-19 лет |
| 15-17 | 4-6-й курс вуза | 20-22 года |
| больше 17 | аспирантура | старше 22 лет |

Метод [`describe_level`](#describe_level) читает индекс Флеша, LIX и RIX по их шкалам - таблицам страницы [функций вычисления метрик](readability_stats_funcs.md), а [`describe`](#describe) - любую метрику: формулу класса и сводный класс по таблице выше, индекс Флеша, LIX и RIX по их шкалам; для метрики без шкалы он возвращает `None`.

Атрибут `reading_time` оценивает время чтения про себя при скорости 180 слов в минуту (верхняя граница нормы для взрослого по Кузнецову и Хромову, 1991). Другую скорость принимает метод [`reading_time_by_speed`](#reading_time_by_speed), а метод [`reading_time_by_norm`](#reading_time_by_norm) считает время в границах нормы из справочника `ruts.constants.READING_SPEED_NORMS`, в том числе школьных норм чтения вслух по ФГОС.

## Нормы ступеней { #level_norms }

Сводный класс говорит, для какой ступени текст, но не каким бывает текст этой ступени. Для этого в справочнике `ruts.constants.LEVEL_NORMS` есть нормы признаков ступеней: обычные диапазоны (квартили) длины предложения в словах, длины слова в буквах, доли слов от пяти слогов и лексического разнообразия MTLD у текстов от 100 слов с меткой ступени из наборов [`SovChLit`](../datasets/sovchlit.md) и [`TextsByGrade`](../datasets/textsbygrade.md). Нормы есть у школьных ступеней, для которых в наборах не меньше 10 таких текстов:

| Ступень | Текстов | Слов в предложении | Букв в слове | Доля слов от пяти слогов | MTLD |
| :-----: | :-----: | :----------------: | :----------: | :----------------------: | :--: |
| 1-3-й класс | 73 | 8.1-10.7 | 4.56-5.03 | 0.0-0.022 | 104-178 |
| 4-6-й класс | 12 | 10.2-14.6 | 5.16-5.33 | 0.039-0.052 | 220-373 |
| 10-11-й класс | 18 | 15.6-17.9 | 5.11-5.57 | 0.035-0.065 | 277-513 |

Нормы 1-3-го класса сняты почти целиком с текстов 1-го класса (70 из 73), поэтому текст для 2-3-го класса может выйти выше нормы, особенно по длине предложения. У 7-9-го класса в наборах семь текстов, а с метками вуза в `TextsByGrade` - статья Википедии, газетная статья и нормативные документы, написанные не для студентов определенного курса, поэтому у этих ступеней норм нет. Функция [`level_features`](readability_stats_funcs.md#level_features) считает признаки текста так же, как они считались для норм, [`level_norms`](readability_stats_funcs.md#level_norms) возвращает нормы ступени, к которой относится класс, а [`describe_level_norm`](readability_stats_funcs.md#describe_level_norm) читает признак по ним. Признаки текста короче 100 слов, особенно MTLD, с нормами сравнивать не стоит.

!!! example "Пример"

    ``` python
    from ruts.datasets import SovChLit
    from ruts.readability_stats import describe_level_norm, level_features

    text = next(SovChLit().get_texts())
    features = level_features(text)
    {stat: describe_level_norm(stat, value, 1) for stat, value in features.items()}
    # {'words_per_sent': 'выше нормы ступени',
    #  'letters_per_word': 'выше нормы ступени',
    #  'p_smog_complex_words': 'выше нормы ступени',
    #  'mtld': 'в норме ступени'}
    ```

## Методы

### describe_grade

<!-- core: stats/readability_stats.md:ReadabilityStats-describe_grade af0b5e5 -->
Возвращает ступень обучения и возраст читателя для сводного класса или формулы класса; другая метрика дает `ParameterError`.

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `stat` | str | `consensus_grade` | Название формулы класса |

!!! example "Пример"

    ``` python
    from ruts import ReadabilityStats

    text = "Ног нет, а хожу, рта нет, а скажу: когда спать, когда вставать, когда работу начинать"
    rs = ReadabilityStats(text)
    rs.describe_grade()
    # '1-3-й класс (6-8 лет)'
    rs.describe_grade("gunning_fog_index")
    # '4-6-й класс (9-11 лет)'
    ```

### describe_level

<!-- core: stats/readability_stats.md:ReadabilityStats-describe_level cfbf0cd -->
Возвращает полосу шкалы интерпретации метрики (`level_scale`); метрика без шкалы полос и неопределенное значение (nan) дают `ParameterError`.

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `stat` | str | `flesch_reading_easy` | Название метрики |

### describe

<!-- core: stats/readability_stats.md:ReadabilityStats-describe 6148d1e -->
Возвращает прочтение любой метрики по ее шкале: для сводного класса и формулы класса - ступень обучения и возраст читателя (`describe_grade`), для метрики со шкалой полос (`level_scale`) - ее полосу, для другой метрики из `grade_scales` - ступень и возраст по числу лет обучения, которое дает ее шкала, и `None` для метрики без шкалы или с неопределенным значением (nan). Имя, которого нет ни в `stats_desc`, ни среди открытых свойств класса, дает `UnknownStatError`.

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `stat` | str | `-` | Название метрики |

!!! example "Пример"

    ``` python
    from ruts import ReadabilityStats

    text = "Ног нет, а хожу, рта нет, а скажу: когда спать, когда вставать, когда работу начинать"
    rs = ReadabilityStats(text)
    rs.describe("flesch_reading_easy"), rs.describe_level("lix")
    # ('6-й класс', 'очень простые тексты, детские книги')
    rs.describe("rix"), rs.describe("matskovsky_index")
    # ('6-й класс', None)
    ```

### reading_time_by_speed

<!-- core: stats/readability_stats.md:ReadabilityStats-reading_time_by_speed 7c6fa90 -->
Возвращает время чтения текста в минутах при заданной скорости; скорость, которая не положительное число, дает `ParameterError`.

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `wpm` | float | `-` | Скорость чтения, слов в минуту |

### reading_time_by_norm

<!-- core: stats/readability_stats.md:ReadabilityStats-reading_time_by_norm dcb8ada -->
Возвращает время чтения текста в минутах при скоростях нормы из `reading_speed_norms` в их порядке; неизвестная норма дает `ParameterError`.

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `norm` | str | `-` | Название нормы скорости чтения |

Нормы справочника `ruts.constants.READING_SPEED_NORMS` - `adult_silent`, `grade_1`, `grade_2`, `grade_3` и `grade_4`, у каждой нижняя и верхняя граница, а метод возвращает время чтения при верхней и при нижней границе.

!!! example "Пример"

    ``` python
    from ruts import ReadabilityStats

    text = "Ног нет, а хожу, рта нет, а скажу: когда спать, когда вставать, когда работу начинать"
    rs = ReadabilityStats(text)
    rs.reading_time_by_speed(120)
    # 0.125
    rs.reading_time_by_norm("grade_1")
    # (0.375, 0.6)
    ```

### sis_grade_by_stage

Возвращает значение формулы Соловьёва, Иванова, Солнышкиной (2023) с коэффициентами для заданной ступени обучения. Общая формула доступна через атрибут `sis_grade`, коэффициенты ступеней - в справочнике `ruts.constants.SIS_GRADE_STAGES`.

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `stage` | str | `-` | Ступень обучения (`2-4`, `5-7`, `8-11`) |

### sis_grade_by_freq { #sis_grade_by_freq }

Возвращает значение формулы Соловьёва, Иванова, Солнышкиной (2023) с частотностью слов: `−14.46 + 0.58·ASL + 2.15·AWL − 0.0026·FREQ2`, где FREQ2 - средняя частотность знаменательных слов текста по словарю Ляшевской и Шарова, атрибут [`mean_ipm_content`](lexical_stats.md) класса `LexicalStats`. Коэффициенты ступеней обучения - в справочнике `ruts.constants.SIS_GRADE_FREQ_STAGES`.

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `mean_ipm` | float | `-` | Средняя частотность знаменательных слов (ipm) |
| `stage` | str | `None` | Ступень обучения (`2-4`, `5-7`, `8-11`); без нее - общая формула |

!!! example "Пример"

    ``` python
    from ruts import LexicalStats, ReadabilityStats

    text = "Кот сидел на окне и смотрел на птиц. Птицы улетели, и кот уснул."
    rs = ReadabilityStats(text)
    rs.sis_grade, rs.sis_grade_by_freq(LexicalStats(text).mean_ipm_content)
    # (-4.625384615384615, -3.106298290598293)
    ```
