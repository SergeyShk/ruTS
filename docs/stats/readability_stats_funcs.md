# Функции вычисления метрик

Коэффициенты формул - параметры; значения по умолчанию ниже адаптированы для русского языка. Формула по количествам дает `nan`, если количество слов или предложений, на которое она делит, равно нулю.

## Тест Флеша-Кинкайда

!!! info ""
    **ruts.readability_stats.calc_flesch_kincaid_grade()**

<!-- core: stats/readability_stats_funcs.md:calc_flesch_kincaid_grade 21c7276 -->
Вычисление теста Флеша-Кинкайда (Kincaid et al., 1975).

Число лет обучения, необходимых для чтения текста; чем выше показатель, тем сложнее текст.

Формула:

$$
a \cdot \frac{\textrm{Количество слов}}{\textrm{Количество предложений}} + b \cdot \frac{\textrm{Количество слогов}}{\textrm{Количество слов}} - c
$$

Коэффициенты по умолчанию взяты из актуальной версии проекта [Plain Russian Language](https://github.com/infoculture/plainrussian). Альтернативные коэффициенты для русского языка доступны через [пресеты](readability_stats.md#presets): Оборнева (`0.5`, `8.4`, `15.59`) и FKG_SIS Соловьёва, Иванова и Солнышкиной (`0.36`, `5.76`, `11.97`).

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `n_syllables` | int | `-` | Количество слогов |
| `n_words` | int | `-` | Количество слов |
| `n_sents` | int | `-` | Количество предложений |
| `a` | float | `0.318` | Коэффициент a, при средней длине предложения |
| `b` | float | `14.2` | Коэффициент b, при средней длине слова |
| `c` | float | `30.5` | Коэффициент c, свободный член |

## Индекс удобочитаемости Флеша

!!! info ""
    **ruts.readability_stats.calc_flesch_reading_easy()**

<!-- core: stats/readability_stats_funcs.md:calc_flesch_reading_easy 978f8ef -->
Вычисление индекса удобочитаемости Флеша (Flesch, 1948).

Чем выше показатель, тем легче текст; шкала номинально идет от 0 до 100, хотя простейшие тексты выходят выше 100, а сложнейшие - ниже 0.

Формула:

$$
c - a \cdot \frac{\textrm{Количество слов}}{\textrm{Количество предложений}} - b \cdot \frac{\textrm{Количество слогов}}{\textrm{Количество слов}}
$$

Значения индекса могут интерпретироваться следующим образом:

| Показатель | Уровень сложности |
|----------|----------|
|`100.0-90.0`|	5-й класс|
|`90.0-80.0`|	6-й класс|
|`80.0-70.0`|	7-й класс|
|`70.0-60.0`|	8-й и 9-й класс|
|`60.0-50.0`|	10-й и 11-й класс|
|`50.0-30.0`|	Университет|
|`30.0-0.0`|	Выпускник университета|

Коэффициенты по умолчанию принадлежат Оборневой (2005/2006, вариант А). Вариант Б тех же работ (`1.52`, `65.14`, `206.836`), которым пользуется казанская группа, доступен через пресет `academic`.

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `n_syllables` | int | `-` | Количество слогов |
| `n_words` | int | `-` | Количество слов |
| `n_sents` | int | `-` | Количество предложений |
| `a` | float | `1.3` | Коэффициент a, при средней длине предложения |
| `b` | float | `60.1` | Коэффициент b, при средней длине слова |
| `c` | float | `206.835` | Коэффициент c, свободный член |

## Индекс Колман-Лиау

!!! info ""
    **ruts.readability_stats.calc_coleman_liau_index()**

<!-- core: stats/readability_stats_funcs.md:calc_coleman_liau_index 75795aa -->
Вычисление индекса Колман-Лиау (Coleman, Liau, 1975).

Число лет обучения, необходимых для чтения текста, по буквам и предложениям на 100 слов; чем выше показатель, тем сложнее текст.

Формула:

$$
a \cdot \frac{100 \cdot \textrm{Количество букв}}{\textrm{Количество слов}} - b \cdot \frac{100 \cdot \textrm{Количество предложений}}{\textrm{Количество слов}} - c
$$

Коэффициенты по умолчанию взяты из проекта [Plain Russian Language](https://github.com/infoculture/plainrussian).

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `n_letters` | int | `-` | Количество букв в словах |
| `n_words` | int | `-` | Количество слов |
| `n_sents` | int | `-` | Количество предложений |
| `a` | float | `0.055` | Коэффициент a, при буквах на 100 слов |
| `b` | float | `0.35` | Коэффициент b, при предложениях на 100 слов |
| `c` | float | `20.33` | Коэффициент c, свободный член |

## Индекс SMOG

!!! info ""
    **ruts.readability_stats.calc_smog_index()**

<!-- core: stats/readability_stats_funcs.md:calc_smog_index b721fe1 -->
Вычисление индекса SMOG (McLaughlin, 1969).

Число лет обучения, необходимых для чтения текста, по сложным словам на предложение; чем выше показатель, тем сложнее текст. В исходной формуле сложные слова - от трех слогов, а `b` приводит их количество к выборке из 30 предложений.

Формула:

$$
a \cdot \sqrt{b \cdot \frac{\textrm{Количество сложных слов}}{\textrm{Количество предложений}}} + c
$$

!!! note "Примечание"
    Коэффициенты по умолчанию проекта [Plain Russian Language](https://github.com/infoculture/plainrussian) получены для сложных слов от пяти слогов, поэтому класс [`ReadabilityStats`](readability_stats.md) передает в функцию количество слов с числом слогов не меньше 5 (`ruts.constants.SMOG_COMPLEX_SYL_FACTOR`), а не атрибут `n_complex_words` объекта класса `BasicStats`.

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `n_complex` | int | `-` | Количество сложных слов |
| `n_sents` | int | `-` | Количество предложений |
| `a` | float | `1.1` | Коэффициент a, при квадратном корне |
| `b` | float | `64.6` | Коэффициент b, под квадратным корнем |
| `c` | float | `0.05` | Коэффициент c, свободный член |

|`6`|	11-12 лет|
|`7`|	12-13 лет|
|`8`|	13-14 лет|
|`9`|	14-15 лет|
|`10`|	15-16 лет|
|`11`|	16-17 лет|
|`12`|	17-18 лет|
|`13`|	18-24 года|
|`14`|	24+ года|

Коэффициенты по умолчанию взяты из проекта [Plain Russian Language](https://github.com/infoculture/plainrussian).

Параметры:

| Параметр | Тип | По умолчанию | Описание |

## Индекс удобочитаемости LIX

!!! info ""
    **ruts.readability_stats.calc_lix()**

<!-- core: stats/readability_stats_funcs.md:calc_lix 65d7ed6 -->
Вычисление индекса удобочитаемости LIX (Björnsson, 1968).

Средняя длина предложения плюс процент длинных слов - слов длиннее шести букв; подбираемых коэффициентов нет. Чем выше показатель, тем сложнее текст:

| Показатель | Текст |
| :---: | :--- |
| `0-30` | очень простые тексты, детские книги |
| `30-40` | простые тексты, художественная литература, газетные статьи |
| `40-50` | тексты средней сложности, журнальные статьи |
| `50-60` | сложные тексты, научно-популярная литература, официальные тексты |
| `60-100` | очень сложные тексты, законы и канцелярский язык |

Формула:

$$
\frac{\textrm{Количество слов}}{\textrm{Количество предложений}} + \frac{100 \cdot \textrm{Количество длинных слов}}{\textrm{Количество слов}}
$$

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `n_long_words` | int | `-` | Количество длинных слов |
| `n_words` | int | `-` | Количество слов |
| `n_sents` | int | `-` | Количество предложений |

!!! note "Примечание"
    Атрибут `n_long_words` объекта класса `BasicStats` ruTS считает слова от шести букв, поэтому класс [`ReadabilityStats`](readability_stats.md) передает в функцию количество слов с числом букв не меньше 7.

Вычисление индекса удобочитаемости RIX (Anderson, 1983).

Количество длинных слов, длиннее шести букв, на предложение; подбираемых коэффициентов нет. Чем выше показатель, тем сложнее текст:

| Показатель | Класс |

| `< 0.2` | 1 |
| `0.2-0.5` | 2 |
| `0.5-0.8` | 3 |

| `5.3-6.2` | 11 |
| `6.2-7.2` | 12 |

## Формула Соловьёва, Иванова, Солнышкиной

!!! info ""
    **ruts.readability_stats.calc_sis_grade()**

Вычисление формулы удобочитаемости для русских академических текстов ([Соловьёв, Иванов, Солнышкина, 2023](http://ftp.pdmi.ras.ru/pub/publicat/znsl/v529/p140.pdf)).

Формула получена на корпусе Russian Academic Corpus из 154 учебников для 2-11 классов (5.7 млн токенов). Результатом является класс школы, средняя ошибка около одного класса. В отличие от теста Флеша-Кинкайда использует среднюю длину слова в буквах, а не в слогах.

Коэффициенты по умолчанию соответствуют общей формуле. Для отдельных ступеней обучения авторы приводят собственные коэффициенты, они доступны в справочнике `ruts.constants.SIS_GRADE_STAGES` и через метод [`sis_grade_by_stage`](readability_stats.md#sis_grade_by_stage):

| Ступень | a | b | c |
|---|---|---|---|
| 2-4 классы | `-2.59` | `0.17` | `0.61` |
| 5-7 классы | `-5.29` | `0.20` | `1.34` |
| 8-11 классы | `-3.26` | `0.21` | `1.35` |

!!! note "Примечание"
    Авторы считали среднюю длину предложения по токенам spaCy, куда попадает пунктуация, поэтому расчет по словам ruTS дает класс чуть ниже.

Формула:

$$
a+b\times\frac{\textrm{Количество слов}}{\textrm{Количество предложений}}+c\times\frac{\textrm{Количество букв}}{\textrm{Количество слов}}
$$

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `n_letters` | int | `-` | Количество букв в словах |
| `n_words` | int | `-` | Количество слов |
| `n_sents` | int | `-` | Количество предложений |
| `a` | float | `-17.5` | Коэффициент a (свободный член) |
| `b` | float | `0.56` | Коэффициент b (при средней длине предложения) |
| `c` | float | `2.45` | Коэффициент c (при средней длине слова) |

## Формула Соловьёва, Иванова, Солнышкиной с частотностью { #calc_sis_grade_freq }

!!! info ""
    **ruts.readability_stats.calc_sis_grade_freq()**

Вычисление варианта общей формулы с четвертым признаком FREQ2 - средней частотностью слов текста по словарю Ляшевской и Шарова ([Соловьёв, Иванов, Солнышкина, 2023](http://ftp.pdmi.ras.ru/pub/publicat/znsl/v529/p140.pdf), таблица 7): чем чаще слова, тем ниже класс. В статье значения FREQ2 лежат в пределах 200-1000, что соответствует средней частотности знаменательных слов (`LexicalStats.mean_ipm_content`); среднее по всем словам с учетом союзов и предлогов в разы больше. На наборе [`TextsByGrade`](../datasets/textsbygrade.md) формула с частотностью дает ту же корреляцию с классом, что и формула без нее (ρ Спирмена 0.76 против 0.77), как и в статье.

Коэффициенты по умолчанию соответствуют общей формуле, коэффициенты ступеней обучения из той же таблицы доступны в справочнике `ruts.constants.SIS_GRADE_FREQ_STAGES` и через параметр `stage` метода [`sis_grade_by_freq`](readability_stats.md#sis_grade_by_freq):

| Ступень | a | b | c | d |
|---|---|---|---|---|
| 2-4 классы | `-1.21` | `0.2` | `0.56` | `-0.0025` |
| 5-7 классы | `-5.18` | `0.17` | `1.35` | `-0.00043` |
| 8-11 классы | `1.3` | `0.23` | `0.88` | `-0.0035` |

Формула:

$$
a+b\times\frac{\textrm{Количество слов}}{\textrm{Количество предложений}}+c\times\frac{\textrm{Количество букв}}{\textrm{Количество слов}}+d\times\textrm{FREQ2}
$$

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `n_letters` | int | `-` | Количество букв в словах |
| `n_words` | int | `-` | Количество слов |
| `n_sents` | int | `-` | Количество предложений |
| `mean_ipm` | float | `-` | Средняя частотность знаменательных слов (ipm) |
| `a` | float | `-14.46` | Коэффициент a (свободный член) |
| `b` | float | `0.58` | Коэффициент b (при средней длине предложения) |
| `c` | float | `2.15` | Коэффициент c (при средней длине слова) |
| `d` | float | `-0.0026` | Коэффициент d (при средней частотности) |

## Формула Мацковского

!!! info ""
    **ruts.readability_stats.calc_matskovsky_index()**

Вычисление формулы Мацковского - первой формулы удобочитаемости для русского языка (1976), полученной методом последовательных интервалов.

Чем выше показатель, тем сложнее текст для чтения.

!!! note "Примечание"
    Сложным считается слово с числом слогов больше трех, поэтому класс [`ReadabilityStats`](readability_stats.md) передает в функцию количество слов с числом слогов не меньше 4.

Формула:

$$
a\times\frac{\textrm{Количество слов}}{\textrm{Количество предложений}}+b\times100\times\frac{\textrm{Количество сложных слов}}{\textrm{Количество слов}}+c
$$

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `n_complex` | int | `-` | Количество сложных слов |
| `n_words` | int | `-` | Количество слов |
| `n_sents` | int | `-` | Количество предложений |
| `a` | float | `0.62` | Коэффициент a (при средней длине предложения) |
| `b` | float | `0.123` | Коэффициент b (при доле сложных слов) |
| `c` | float | `0.051` | Коэффициент c (свободный член) |

## Индекс Дейла-Чейла

!!! info ""
    **ruts.readability_stats.calc_dale_chall_index()**

Вычисление [индекса Дейла-Чейла](https://en.wikipedia.org/wiki/Dale–Chall_readability_formula).

Чем выше показатель, тем сложнее текст для чтения. Результатом является число лет обучения в американской системе образования, необходимых для понимания текста.

Оригинальная формула использует список из 3000 знакомых слов, для русского языка такого свободного списка нет, поэтому применяется адаптация проекта [Plain Russian Language](https://github.com/infoculture/plainrussian), где вместо доли незнакомых слов используется доля сложных слов. Оригинальные коэффициенты формулы: `0.1579` и `0.0496`.

!!! note "Примечание"
    Сложным считается слово от пяти слогов, поэтому класс [`ReadabilityStats`](readability_stats.md) передает в функцию количество слов с числом слогов не меньше 5 (`ruts.constants.SMOG_COMPLEX_SYL_FACTOR`).

Формула:

$$
a\times100\times\frac{\textrm{Количество сложных слов}}{\textrm{Количество слов}}+b\times\frac{\textrm{Количество слов}}{\textrm{Количество предложений}}
$$

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `n_complex` | int | `-` | Количество сложных слов |
| `n_words` | int | `-` | Количество слов |
| `n_sents` | int | `-` | Количество предложений |
| `a` | float | `0.552` | Коэффициент a (при доле сложных слов) |
| `b` | float | `0.273` | Коэффициент b (при средней длине предложения) |

Вычисление индекса туманности Ганнинга (Gunning, 1952).

Число лет обучения, необходимых для чтения текста, по средней длине предложения и проценту сложных слов, в исходной формуле - слов от трех слогов; чем выше показатель, тем сложнее текст.

Формула:

$$
a \cdot \left(\frac{\textrm{Количество слов}}{\textrm{Количество предложений}} + \frac{100 \cdot \textrm{Количество сложных слов}}{\textrm{Количество слов}}\right)
$$

Используется в адаптации проекта [Plain Russian Language](https://github.com/infoculture/plainrussian). SEO-сервисы дополнительно умножают результат на `0.78`, обоснование этого множителя не опубликовано.

!!! note "Примечание"
    Сложным считается слово от пяти слогов, поэтому класс [`ReadabilityStats`](readability_stats.md) передает в функцию количество слов с числом слогов не меньше 5 (`ruts.constants.SMOG_COMPLEX_SYL_FACTOR`).

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `n_complex` | int | `-` | Количество сложных слов |
| `n_words` | int | `-` | Количество слов |
| `n_sents` | int | `-` | Количество предложений |
| `a` | float | `0.4` | Коэффициент a |

## Сводный класс { #calc_consensus_grade }

!!! info ""
    **ruts.readability_stats.calc_consensus_grade()**

<!-- core: stats/readability_stats_funcs.md:calc_consensus_grade 80761d1 -->
Вычисление сводного класса: медианы значений формул класса, округлённых арифметически, вместе с индексом удобочитаемости Флеша, переведенным в число лет обучения функцией `to_grade` и добавленным без округления, - поэтому диапазон с классом 8.5 голосует за 8.5. Отсутствие значений и класс, который не конечное число, дают `ParameterError`, `to_grade`, который нельзя вызвать, - `SourceTypeError`.

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `grades` | list[float] | `-` | Значения формул класса |
| `flesch_reading_easy` | float | `None` | Значение индекса удобочитаемости Флеша |
| `to_grade` | Callable | `flesch_reading_easy_to_grade` | Перевод индекса Флеша в число лет обучения |

Аналог `text_standard` библиотеки textstat, где вместо медианы используется мода; медиана устойчивее к выбросам отдельных формул. Класс [`ReadabilityStats`](readability_stats.md#interpretation) передаёт в функцию тест Флеша-Кинкайда, индексы Колман-Лиау, SMOG, ARI, Дейла-Чейла и Ганнинга, формулу Соловьёва, Иванова, Солнышкиной и индекс Флеша.

Вычисление времени чтения текста в минутах: количество слов, деленное на скорость чтения; скорость, которая не положительное число, дает `ParameterError`.

Норма чтения про себя для взрослого - 120-180 слов в минуту (Кузнецов и Хромов, 1991), по умолчанию используется верхняя граница. Нормы чтения вслух для начальной школы по ФГОС доступны в справочнике `ruts.constants.READING_SPEED_NORMS`:

| Норма | Слов в минуту |
|---|---|
| `adult_silent` | 120-180 |
| `grade_1` | 25-40 |
| `grade_2` | 60-80 |
| `grade_3` | 80-100 |
| `grade_4` | 90-110 |

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `n_words` | int | `-` | Количество слов |
| `wpm` | float | `180` | Скорость чтения, слов в минуту |
