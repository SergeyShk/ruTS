## Type-Token Ratio (TTR)

!!! info ""
    **ruts.diversity_stats.calc_ttr()**

<!-- core: stats/diversity_stats_funcs.md:calc_ttr 0ca7ff2 -->
Вычисление метрики Type-Token Ratio (TTR).

Самая простая мера лексического разнообразия, не делающая поправки на длину текста.

Формула:

$$
\frac{\textrm{Количество лексем}}{\textrm{Количество слов}}
$$

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `text` | list[str] | `-` | Список слов |

Вычисление метрики Summer Type-Token Ratio (STTR).

Модификация метрики TTR с использованием логарифмической функции (Summer, 1966).

\frac{\log_{10} {\log_{10} {\textrm{(Количество лексем)}}}}{\log_{10} {\log_{10} {{\textrm{(Количество слов)}}}}}

Вычисление метрики Moving Average Type-Token Ratio (MATTR).

Модификация метрики TTR с использованием скользящей средней (Covington & McFall, 2010). Не зависит от длины текста.

Алгоритм:

## Measure of Textual Lexical Diversity (MTLD)

!!! info ""
    **ruts.diversity_stats.calc_mtld()**

<!-- core: stats/diversity_stats_funcs.md:calc_mtld 0c88867 -->
Вычисление метрики Measure of Textual Lexical Diversity (MTLD).

Модификация метрики MSTTR (McCarthy, 2005). Не зависит от длины текста.

Алгоритм:

1. Текст делится на факторы - отрезки, на которых TTR опускается до порога 0.72 включительно (`TTR <= 0.72`, см. [соглашения](diversity_stats.md#conventions))
2. Незавершенный фактор в конце текста учитывается частично, пропорционально тому, насколько его TTR приблизился к порогу
3. Количество слов делится на количество факторов

Доработанная версия алгоритма предполагает два прохода по тексту - в прямом и обратном порядке, и дальнейшее усреднение значения метрики (McCarthy & Jarvis, 2010).

!!! note "Примечание"
    Минимальная длина фактора нестандартна (lexical-diversity Кайла). Если ни один фактор не завершен и TTR не опускается ниже 1, возвращается бесконечность.

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `text` | list[str] | `-` | Список слов |
| `min_len` | int | `10` | Минимальная длина фактора |
| `threshold` | float | `0.72` | Порог TTR для завершения фактора |

## Moving Average Measure of Textual Lexical Diversity (MA-MTLD)

!!! info ""
    **ruts.diversity_stats.calc_mamtld()**

<!-- core: stats/diversity_stats_funcs.md:calc_mamtld e26f25e -->
Вычисление метрики Moving Average Measure of Textual Lexical Diversity (MA-MTLD).

Модификация метрики MTLD с использованием скользящего окна по образцу MTLD-MA из koRpus: фактор начинается с каждой позиции текста, значение метрики - средняя длина завершенных факторов по двум проходам, в прямом и обратном порядке. Факторы, не завершенные до конца текста, не учитываются. Значения отличаются от значений koRpus, который делает только прямой проход, закрывает фактор при TTR строго ниже порога и отбрасывает факторы короче минимальной длины, а не продлевает их до нее.

!!! warning "Предупреждение"
    Если ни один фактор не завершен, функция возвращает `nan`. Метрика нестабильна на коротких текстах.

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `text` | list[str] | `-` | Список слов |
| `min_len` | int | `10` | Минимальная длина фактора |
| `threshold` | float | `0.72` | Порог TTR для завершения фактора |

## Hypergeometric Distribution D (HD-D)

!!! info ""
    **ruts.diversity_stats.calc_hdd()**

<!-- core: stats/diversity_stats_funcs.md:calc_hdd 6bf82ff -->
Вычисление метрики Hypergeometric Distribution D (HD-D).

Альтернатива vocd-D (McCarthy & Jarvis, 2010): вместо случайного отбора сегментов текста она точно вычисляет ожидаемый TTR случайной выборки из `sample_size` слов. Для каждой лексемы гипергеометрическое распределение дает вероятность того, что лексема попадет в выборку хотя бы раз; сумма этих вероятностей - ожидаемое количество лексем в выборке, а HD-D - это количество, деленное на размер выборки. Случайности в значении нет.

!!! warning "Предупреждение"
    Для текстов короче 50 слов или короче размера выборки метрика не определена, функция возвращает `nan`.

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `text` | list[str] | `-` | Список слов |
| `sample_size` | int | `42` | Размер выборки в словах, в литературе от 35 до 50 |

## Индекс Симпсона (D)

!!! info ""
    **ruts.diversity_stats.calc_simpson_index()**

<!-- core: stats/diversity_stats_funcs.md:calc_simpson_index e0e51fd -->
Вычисление [индекса Симпсона](https://en.wikipedia.org/wiki/Diversity_index#Simpson_index).

Вероятность того, что два слова, случайно извлеченные из текста без возвращения, окажутся одной лексемой. Чем ниже показатель, тем богаче словарь текста.

!!! warning "Предупреждение"
    Для текстов короче двух слов индекс не определен, функция возвращает `nan`. То же относится к обратному индексу Симпсона и индексу Джини-Симпсона.

Формула:

$$
\frac{\sum n\times(n-1)}{\textrm{(Количество слов)}\times(\textrm{Количество слов}-1)}
$$

где $n$ - количество вхождений лексемы в текст.

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `text` | list[str] | `-` | Список слов |

## Обратный индекс Симпсона (1/D) { #inverse_simpson_index }

!!! info ""
    **ruts.diversity_stats.calc_inverse_simpson_index()**

Формула:

## Гапакс-индекс (Honoré's R)

!!! info ""
    **ruts.diversity_stats.calc_hapax_index()**, псевдоним **ruts.diversity_stats.calc_honore_r()**

<!-- core: stats/diversity_stats_funcs.md:calc_hapax_index 4a5bc5c -->
Вычисление [гапакс-индекса](https://ru.wikipedia.org/wiki/Гапакс).

!!! quote "Определение"

    Гапакс (греч. ἅπαξ λεγόμενον - «только раз названное») - слово, встретившееся в некотором корпусе текстов только один раз. Так, *baciyelmo* - словечко Санчо Пансы для цирюльничьего тазика, который Дон Кихот принимает за шлем, - гапакс Сервантеса (оно встречается один раз, в главе 44 первой части «Дон Кихота»).

Метрика совпадает с мерой Оноре (1979) и использует натуральный логарифм.

Формула:

$$
100\times\frac{\ln {\textrm{(Количество слов)}}}{1-\frac{\textrm{Количество гапаксов}}{\textrm{Количество лексем}}}
$$

!!! warning "Предупреждение"
    Если все слова текста являются гапаксами, значение индекса равно бесконечности. Для текстов короче двух слов индекс не определен, функция возвращает `nan`.

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `text` | list[str] | `-` | Список слов |

!!! note "Примечание"
    Русский пример: боливар («шляпа определённого фасона») - гапакс языка Пушкина, оно встречается только в знаменитом месте из «Евгения Онегина».

## Характеристика Юла (Yule's K)

!!! info ""
    **ruts.diversity_stats.calc_yule_k()**

<!-- core: stats/diversity_stats_funcs.md:calc_yule_k c6ce18b -->
Вычисление характеристики Юла (Yule, 1944). Одна из немногих мер, теоретически не зависящих от длины текста (Tweedie & Baayen, 1998), на практике сходится с ростом текста. Чем ниже показатель, тем богаче словарь текста. Пропорциональна индексу Симпсона: $K \approx 10^4 \cdot D$.

Формула:

$$
K = 10^4\times\frac{\sum_i i^2 V_i - N}{N^2}
$$

| :------: | :-: | :----------: | :------: |
| `text` | list[str] | `-` | Список слов |

## Подгонка закона Ципфа-Мандельброта { #fit_zipf_mandelbrot }

!!! info ""
    **ruts.diversity_stats.fit_zipf_mandelbrot()**, **ruts.diversity_stats.ZipfMandelbrot**

<!-- core: stats/diversity_stats_funcs.md:fit_zipf_mandelbrot 56dd01c -->
Подгонка [закона Ципфа-Мандельброта](https://en.wikipedia.org/wiki/Zipf–Mandelbrot_law) $f(r) = C / (r + q)^s$ к распределению частот по рангам. При $q = 0$ закон сводится к закону Ципфа с показателем $s$; сдвиг $q$ описывает выполаживание кривой на самых частых словах, которое закон Ципфа не передает. Параметры подбираются методом наименьших квадратов в логарифмических координатах с ограничениями $q \ge 0$, $s \ge 0$. Возвращает именованный кортеж `ZipfMandelbrot` с полями `c`, `q`, `s` и `r2` - коэффициентом детерминации подгонки в логарифмических координатах.

!!! note "Примечание"
    Для текстов из менее чем трех лексем, при одинаковых частотах всех лексем и при расходящейся подгонке все поля `nan`. На коротких текстах параметры неустойчивы: закон описывает распределение частот больших корпусов.

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `text` | list[str]/Counter | `-` | Список слов или справочник их частот |

Визуализатор [закона Ципфа](../visualizers/zipf.md) строит эту подгонку при `show_fit=True`.

!!! example "Пример"

    ``` python
    from ruts.diversity_stats import fit_zipf_mandelbrot

    # частоты 12, 6, 4, 3 в точности следуют закону f = 12 / r
    words = ["а"] * 12 + ["б"] * 6 + ["в"] * 4 + ["г"] * 3
    fit = fit_zipf_mandelbrot(words)
    round(fit.c, 3), round(fit.q, 3), round(fit.s, 3), round(fit.r2, 3)
    # (12.001, 0.0, 1.0, 1.0)
    ```

## Показатель закона Хипса { #heaps_beta }

!!! info ""
    **ruts.diversity_stats.calc_heaps_beta()**, **ruts.diversity_stats.fit_heaps()**, **ruts.diversity_stats.vocabulary_growth()**

<!-- core: stats/diversity_stats_funcs.md:calc_heaps_beta 1ed3900 -->
Вычисление показателя $\beta$ [закона Хипса](https://en.wikipedia.org/wiki/Heaps'_law) $V(N) = K \cdot N^{\beta}$, описывающего рост словаря с ростом длины текста. Оценивается линейной регрессией логарифма размера словаря по логарифму длины текста вдоль кривой роста словаря. На корпусах в миллионы слов $\beta$ лежит в пределах 0.4-0.6, по кривой роста отдельного текста - выше (0.6-0.9), поэтому значения сравнимы только между текстами близкой длины.

!!! note "Примечание"
    Значение зависит от порядка слов и требует от нескольких сотен слов. Для текстов короче двух слов функция возвращает `nan`.

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `text` | list[str] | `-` | Список слов |

<!-- core: stats/diversity_stats_funcs.md:vocabulary_growth 39c0cb0 -->
`vocabulary_growth` возвращает кривую роста словаря: размер словаря после каждого слова текста.

<!-- core: stats/diversity_stats_funcs.md:fit_heaps 2c0021b -->
`fit_heaps` подгоняет закон по этой кривой и возвращает именованный кортеж `HeapsFit` с параметрами `k`, `beta` и коэффициентом детерминации `r2`.

По `fit_heaps` строится график [закона Хипса](../visualizers/vocabulary.md).

## Оконный расчет { #calc_windowed }

!!! info ""
    **ruts.diversity_stats.calc_windowed()**

<!-- core: stats/diversity_stats_funcs.md:calc_windowed b59de2a -->
Оконный расчет любой метрики: значение по последовательным окнам текста одинаковой длины, среднее, выборочное стандартное отклонение и доверительный интервал среднего по распределению Стьюдента. Стандартный способ сравнения текстов разной длины; стандартизированный TTR Кубата и Милички (не STTR Summer) - оконный расчет TTR с окном 1000 слов и 95% доверительным интервалом. Для текстов короче окна метрика считается по всему тексту как по единственному окну, окна с неопределенным значением метрики (`nan`) не учитываются. Если хотя бы в одном окне метрика бесконечна (например, обратный индекс Симпсона на окне из уникальных слов), среднее равно бесконечности, а стандартное отклонение и доверительный интервал не определены. Возвращает именованный кортеж `WindowStats` с полями `mean`, `std`, `lower`, `upper` и `n_windows`.

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `text` | list[str] | `-` | Список слов |
| `func` | callable | `-` | Функция вычисления метрики по списку слов |
| `window_len` | int | `100` | Размер окна |
| `step` | int | `None` | Шаг окна, по умолчанию равен размеру окна |
| `confidence` | float | `0.95` | Уровень доверия |
