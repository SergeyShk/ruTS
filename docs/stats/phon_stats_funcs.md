# Функции вычисления статистик

## CV-шаблон { #cv_pattern }

!!! info ""
    **ruts.phon_stats.cv_pattern()**

Получение CV-шаблона слова или слога: гласные обозначаются буквой `V`, согласные - `C`, ь и ъ пропускаются, остальные символы не учитываются.

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `word` | str | `-` | Слово или слог |

## Открытый слог { #is_open_syllable }

!!! info ""
    **ruts.phon_stats.is_open_syllable()**

Проверка, является ли слог открытым - оканчивается на гласную; ь и ъ после гласной слог не закрывают.

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `syllable` | str | `-` | Слог |

## Консонантные кластеры { #calc_consonant_clusters }

!!! info ""
    **ruts.phon_stats.calc_consonant_clusters()**

Вычисление распределения консонантных кластеров по длине. Кластер - последовательность согласных внутри слова, ь и ъ не прерывают кластер; кластеры длиной 1 - одиночные согласные между гласными или на краях слова. Класс `PhonStats` считает по распределению долю кластеров из 3 и более согласных (`p_heavy_clusters`).

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `text` | list[str] | `-` | Список слов |

## Зияния гласных { #calc_hiatus }

!!! info ""
    **ruts.phon_stats.calc_hiatus()**

Вычисление количества зияний гласных - двух и более гласных подряд внутри слова: аэропорт, аист, поэзия (о-э). Йотированные е, ё, ю, я после гласной обозначают [j] и гласный и зияния не образуют: заяц, моя, красивая, читает - иначе окончания прилагательных и глаголов давали бы четыре пятых всех зияний. Класс `PhonStats` делит количество зияний на количество слов (`p_hiatus`).

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `text` | list[str] | `-` | Список слов |

## Энтропия CV-шаблонов { #calc_cv_entropy }

!!! info ""
    **ruts.phon_stats.calc_cv_entropy()**

Вычисление энтропии Шеннона распределения слов по CV-шаблону в битах: чем выше значение, тем разнообразнее фонетическая форма слов текста. Слова без гласных и согласных (числа, латиница) не учитываются; если таких слов нет вовсе, функция возвращает `nan`.

Формула:

$$
H = -\sum_k p_k \log_2 p_k
$$

где $p_k$ - доля слов с шаблоном $k$.

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `text` | list[str] | `-` | Список слов |

## Жёсткость { #hardness }

Атрибут `hardness` класса `PhonStats` - отношение количества глухих шумных согласных к количеству гласных и сонорных. Чем выше значение, тем «жёстче» звучание текста. Не определено для текстов без гласных и сонорных.

Формула:

$$
\frac{\textrm{Глухие шумные}}{\textrm{Гласные}+\textrm{Сонорные}}
$$

## Индекс аллитерации { #calc_alliteration }

!!! info ""
    **ruts.phon_stats.calc_alliteration()**

Индекс - `calc_repetition_index` ядра [anyTS](https://sergeyshk.github.io/anyTS/stats/phonetics/) по согласным буквам слов:

<!-- core: stats/phonetics.md:calc_repetition_index 8d65261 -->
Индекс повторов: отношение числа окон из `window_len` соседних слов, в которых признак - буква или звук, как выберет библиотека, - встречается минимум в двух словах, в сумме по признакам, к числу, ожидаемому при случайном порядке слов. Окно перемешанных слов - выборка из них без возвращения, поэтому для признака, который есть в \(K\) из \(N\) слов текста, окно из \(w\) слов содержит его минимум в двух словах с гипергеометрической вероятностью

$$
P = 1 - \frac{\binom{N-K}{w} + K \binom{N-K}{w-1}}{\binom{N}{w}}
$$

а ожидаемое число - сумма этих вероятностей по признакам, умноженная на \(N - w + 1\) окон. Ожидаемое берется из самого текста, поэтому индекс показывает, собираются ли повторы в соседних словах, а не насколько частотен признак: в среднем по порядкам слов он равен 1 и заметно больше 1, когда повторы стоят ближе, чем при случайном порядке. Слово учитывает признак один раз, сколько бы раз он в нем ни встречался; `nan` для текста короче окна и для текста, где ни один признак не встречается в двух словах.

Сравниваются буквы, а не звуки: оглушение не учитывается.

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `text` | list[str] | `-` | Список слов |
| `window_len` | int | `3` | Размер окна в словах |
