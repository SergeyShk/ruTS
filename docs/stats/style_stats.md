# SEO-метрики стиля

``` {.python .signature}
StyleStats(source, words_extractor=None, stopwords=None, top_n=10, cliches=None, nausea_stopwords=None)
```

<!-- core: stats/style_stats.md:StyleStats 145407f -->
Метрики стиля текста: SEO-метрики Advego и Text.ru и маркеры канцелярита. Формулы сервисов не опубликованы, поэтому взяты общепринятые определения. Источник данных - текст или объект `Doc` библиотеки [spaCy](https://github.com/explosion/spaCy).

SEO-метрики считаются по словам экстрактора слов, по умолчанию в нижнем регистре, или по токенам `Doc`; явно переданный экстрактор применяется к тексту `Doc`. Маркеры считаются по словоформам в нижнем регистре (`forms`) независимо от экстрактора.

Исключения:

- `SourceTypeError` - источник, который не строка и не `Doc`, экстрактор другого типа, список, который не список строк;
- `SourceError` - источник без слов;
- `ParameterError` - `top_n`, который не целое число не меньше единицы.

Класс расширяет `StyleStats` ядра [anyTS](https://sergeyshk.github.io/anyTS/stats/style_stats/) крючками русского языка, о которых говорят карточки метрик. Слова строки извлекает русский [`WordsExtractor`](../extractors/words.md) и не лемматизирует, поэтому формы одного слова считаются разными словами, как в Advego; для расчета по леммам передайте `WordsExtractor` с параметрами `use_lexemes=True` и `lowercase=True`. Переданные списки слов и словосочетания сравниваются без буквы ё (`normalize_yo`). Слова `Doc` берутся без знаков ударения, а части дефисного слова, разрезанного spaCy, склеиваются (`во-первых` - одно слово). Таблица `print_stats` и сообщения об ошибках - по-русски (`STYLE_STATS_DESC` и `CORE_MESSAGES` из `ruts.constants`).

=== "Код"

    ``` python
    from ruts import StyleStats

    text = "Ног нет, а хожу, рта нет, а скажу: когда спать, когда вставать, когда работу начинать"
    StyleStats(text).print_stats()
    ```

| :------ | :----------- | :------- | :-------------- |

Карточки дают полосы, по которым читает метод [`describe`](#methods), - нормы [Advego](https://advego.com/text/seo/), [Text.ru](https://text.ru/seo), pr-cy и megaindex (`STYLE_NORMS`). Нормы - ориентиры сервисов для текстов сайтов в несколько сотен слов: на коротких текстах значения тошноты и заспамленности неинформативны, к художественной прозе нормы неприменимы. У маркеров канцелярита норм нет.

### Естественность по Ципфу { #zipf_naturalness }

`zipf_naturalness` · pr-cy, megaindex
{ .metric-meta }

``` {.python .signature}
calc_zipf_naturalness(text, top_n=10)
```

Согласие частот самых частых слов с идеальным распределением [закона Ципфа](https://en.wikipedia.org/wiki/Zipf's_law) $f_r = f_1 / r$, где $f_1$ - частота самого частого слова, $r$ - ранг. Ранги берутся от 2 до $R = \min(\textrm{top}_n, V, f_1)$, где $V$ - количество лексем. Отрицательные значения обрезаются до 0. Без рангов для сравнения - все слова гапаксы, одна лексема или `top_n` меньше 2 - значение равно `nan`.

$$
100 \cdot \left(1 - \frac{1}{R - 1} \sum_{r=2}^{R} \frac{|r \cdot f_r - f_1|}{f_1}\right)
$$

| Параметр | Тип | По умолчанию | Описание |
| :------- | :-- | :----------- | :------- |
| `text` | `list[str]` | - | Список слов |
| `top_n` | `int` | `10` | Количество самых частых слов |

`top_n`, который не целое число не меньше единицы, дает `ParameterError`.

| Значение | Прочтение |
| :------- | :-------- |
| `[0; 50)` | ниже нормы pr-cy и megaindex |
| `[50; 100]` | норма pr-cy и megaindex |

</div>

`verbal_nouns`
{ .metric-meta }


### Производные предлоги и штампы { #phrase_density }

`compound_prepositions` · `cliches`
{ .metric-meta }

``` {.python .signature}
calc_phrase_density(text, phrases)
```

Число вхождений словосочетаний из списка на 100 слов. Словосочетания сравниваются без учета регистра и буквы ё, а словосочетание, начинающееся с инфинитива, в том числе после «не», находится в любой форме своего глагола, включая причастия и деепричастия («имело место», «доведено до сведения»). Эти варианты из текста, каждый со своим словосочетанием, дает `expand_phrases(text, phrases)`. Так `StyleStats` считает по словоформам (`forms`) производные предлоги из `COMPOUND_PREPOSITIONS` (в целях, в связи с, в рамках, за счет) и штампы из `OFFICIALESE_CLICHES` (на сегодняшний день, в настоящее время, иметь место) или из параметра `cliches`.

| Параметр | Тип | По умолчанию | Описание |
| :------- | :-- | :----------- | :------- |
| `text` | `list[str]` | - | Список слов |
| `phrases` | `list[str]` | - | Словосочетания через пробел |

### Плотность ключевых слов { #keyword_density }

`keyword_density(*keywords)` · [Text.ru](https://text.ru/seo)
{ .metric-meta }


Число вхождений каждого ключевого слова на 100 слов. Ключевое слово из нескольких слов через пробел - последовательность слов, вхождения которой могут пересекаться. ## Методы { #methods }

<!-- core: stats/style_stats.md:StyleStats-keyword_density 5d9b0bc -->
`keyword_density(*keywords)` дает плотность ключевых слов и фраз в процентах (`calc_keyword_density` с `normalize` класса), `nausea_words()` - самые частые значимые слова академической тошноты с числом вхождений (`find_nausea_words`).

<!-- core: stats/style_stats.md:StyleStats-markers 18537e6 -->
`markers()` возвращает найденные маркеры канцелярита по метрикам - `verbal_nouns`, `compound_prepositions`, `parentheticals`, `cliches` - так, как они записаны в словоформах, в порядке текста.

=== "Код"

    ``` python
    from ruts import StyleStats

    text = "В целях повышения качества в кратчайшие сроки, как правило, проводится проверка"
    StyleStats(text).markers()
    StyleStats(text, top_n=2).nausea_words()
    ```

=== "Результат"

Остальные методы - `get_stats`, `to_dataframe`, `print_stats` и `describe` - из [интерфейса статистик](https://sergeyshk.github.io/anyTS/stats/stats/) ядра anyTS; `describe` читает SEO-метрики по полосам норм из их карточек, а для маркеров канцелярита возвращает `None`.

=== "Код"

    ``` python

    text = "Ног нет, а хожу, рта нет, а скажу: когда спать, когда вставать, когда работу начинать"

    ss.keyword_density("когда", "нет а")
    ss.describe("water"), ss.describe("cliches")
    ss.get_stats()
    ```
