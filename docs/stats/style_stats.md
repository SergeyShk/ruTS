# SEO-метрики стиля

!!! info ""
    **ruts.style_stats.StyleStats**

## Описание

Модуль для вычисления SEO-метрик стиля и качества текста, повторяющих показатели сервисов [Advego](https://advego.com/text/seo/) и [Text.ru](https://text.ru/seo): тошнота, водность, заспамленность, естественность распределения слов по закону Ципфа и плотность ключевых слов. В качестве источника данных может использоваться как непосредственно текст, так и объект класса `Doc` библиотеки [spaCy](https://github.com/explosion/spaCy).

Точные формулы сервисов не опубликованы, поэтому реализованы общепринятые определения; они описаны в разделе [функций](style_stats_funcs.md). Слова по умолчанию извлекаются в нижнем регистре без лемматизации, поэтому формы одного слова считаются разными словами, как в Advego. Для расчета по леммам передайте объект [`WordsExtractor`](../extractors/words.md) с параметрами `use_lexemes=True` и `lowercase=True`.

Лексические маркеры канцелярита: отглагольные существительные, производные предлоги, вводные слова, штампы - по спискам `COMPOUND_PREPOSITIONS`, `PARENTHETICALS` и `OFFICIALESE_CLICHES` из `ruts.constants`. Считаются по словоформам без фильтрации (`forms`) независимо от переданного экстрактора.

!!! note "Примечание"
    Вычисление метрик происходит посредством вызова соответствующего атрибута или метода `get_stats` объекта класса `StyleStats`.

## Параметры

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `source` | str/Doc | `-` | Источник данных (строка или объект Doc) |
| `words_extractor` | WordsExtractor | `None` | Инструмент для извлечения слов; если задан, применяется и к тексту Doc |
| `stopwords` | list[str] | `None` | Список стоп-слов для водности; если не задан, стоп-слова определяются по части речи с помощью pymorphy3 |
| `top_n` | int | `10` | Количество самых частых слов для академической тошноты и естественности по Ципфу |
| `cliches` | list[str] | `None` | Список штампов; если не задан, используется `OFFICIALESE_CLICHES` |

## Атрибуты

| Атрибут | Тип | Описание |
| :-----: | :-: | :------: |
| `words` | tuple[str] | Кортеж извлеченных слов |
| `forms` | tuple[str] | Кортеж словоформ в нижнем регистре без фильтрации, по ним считаются маркеры канцелярита |
| `classic_nausea` | float | Классическая тошнота |
| `academic_nausea` | float | Академическая тошнота в процентах |
| `water` | float | Водность в процентах |
| `spam` | float | Заспамленность в процентах |
| `zipf_naturalness` | float | Естественность по Ципфу в процентах |
| `verbal_nouns` | float | Доля отглагольных существительных среди существительных в процентах |
| `compound_prepositions` | float | Производных предлогов на 100 слов |
| `parentheticals` | float | Вводных слов на 100 слов |
| `cliches` | float | Штампов на 100 слов |

## Нормы сервисов { #norms }

Метод [`describe`](#describe) читает метрику по полосам норм сервисов - `ruts.constants.STYLE_NORMS`; у маркеров канцелярита норм нет. Нормы - ориентиры сервисов для текстов сайтов в несколько сотен слов: на коротких текстах значения тошноты и заспамленности неинформативны, к художественной прозе нормы неприменимы.

| Метрика | Значение | Прочтение |
| :-----: | :------: | :-------: |
| `classic_nausea` | `(7; ∞)` | выше нормы Advego |
| `classic_nausea` | `(5; 7]` | у верхней границы нормы Advego |
| `classic_nausea` | `[0; 5]` | норма Advego |
| `academic_nausea` | `(15; 100]` | выше нормы Advego |
| `academic_nausea` | `[5; 15]` | норма Advego |
| `academic_nausea` | `[0; 5)` | ниже нормы Advego |
| `water` | `(30; 100]` | высокая водность по Text.ru |
| `water` | `[15; 30]` | избыточная водность по Text.ru |
| `water` | `[0; 15)` | естественная водность по Text.ru |
| `spam` | `(60; 100]` | заспамленный текст по Text.ru |
| `spam` | `[30; 60]` | SEO-оптимизированный текст по Text.ru |
| `spam` | `[0; 30)` | естественный текст по Text.ru |
| `zipf_naturalness` | `[50; 100]` | норма pr-cy и megaindex |
| `zipf_naturalness` | `[0; 50)` | ниже нормы pr-cy и megaindex |

## Методы

### keyword_density

Возвращает плотность ключевых слов и фраз - частоту каждого из них на 100 слов текста. Фраза из нескольких слов через пробел ищется как последовательность слов, регистр не учитывается.

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `keywords` | tuple[str] | `-` | Ключевые слова или фразы |

!!! example "Пример"

    ``` python
    from ruts import StyleStats

    text = "Ног нет, а хожу, рта нет, а скажу: когда спать, когда вставать, когда работу начинать"
    ss = StyleStats(text)
    ss.keyword_density("когда", "нет а")
    # {'когда': 20.0, 'нет а': 13.333333333333334}
    ```

### markers

Возвращает найденные маркеры канцелярита: для каждой из метрик `verbal_nouns`, `compound_prepositions`, `parentheticals` и `cliches` - слова и словосочетания, по которым она посчитана, в порядке текста и как они записаны в `forms`. Словосочетания ищутся, как в [`calc_phrase_density`](style_stats_funcs.md#calc_phrase_density).

!!! example "Пример"

    ``` python
    from ruts import StyleStats

    text = "В целях повышения качества в кратчайшие сроки, как правило, проводится проверка"
    StyleStats(text).markers()
    # {'verbal_nouns': ('повышения',),
    #  'compound_prepositions': ('в целях',),
    #  'parentheticals': ('как правило',),
    #  'cliches': ('в кратчайшие сроки',)}
    ```

### describe

Возвращает полосу [нормы сервиса](#norms) для метрики; метрика без нормы и неопределенное значение (nan) дают `None`, имя не из `STYLE_STATS_DESC` - `UnknownStatError`.

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `stat` | str | `-` | Название метрики |

!!! example "Пример"

    ``` python
    from ruts import StyleStats

    text = "Ног нет, а хожу, рта нет, а скажу: когда спать, когда вставать, когда работу начинать"
    ss = StyleStats(text)
    ss.describe("water")
    # 'высокая водность по Text.ru'
    ss.describe("cliches")
    # None
    ```

### get_stats

Возвращает справочник с вычисленными метриками стиля текста.

!!! example "Пример"

    _Код_:

    ``` python
    # Загрузка библиотек
    from ruts import StyleStats

    # Подготовка данных
    text = "Ног нет, а хожу, рта нет, а скажу: когда спать, когда вставать, когда работу начинать"

    # Вычисление метрик
    ss = StyleStats(text)
    ss.get_stats()
    ```

    _Результат_:

    ``` bash
    {'classic_nausea': 1.7320508075688772,
    'academic_nausea': 93.33333333333333,
    'water': 46.666666666666664,
    'spam': 26.666666666666668,
    'zipf_naturalness': 33.333333333333336,
    'verbal_nouns': 0.0,
    'compound_prepositions': 0.0,
    'parentheticals': 0.0,
    'cliches': 0.0}
    ```

### print_stats

Выводит на экран таблицу с вычисленными метриками стиля текста.

!!! example "Пример"

    _Код_:

    ``` python
    ...

    # Отображение таблицы вычисленных метрик
    ss.print_stats()
    ```

    _Результат_:

    ``` bash

    ------------------------------------------------------------

    Академическая тошнота (%)                         |  93.33
    Водность (%)                                      |  46.67
    Заспамленность (%)                                |  26.67
    Естественность по Ципфу (%)                       |  33.33
    Отглагольные существительные (% существительных)  |   0.00
    Производные предлоги (на 100 слов)                |   0.00
    Вводные слова (на 100 слов)                       |   0.00
    Штампы (на 100 слов)                              |   0.00
    ```
