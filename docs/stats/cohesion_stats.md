# Статистики связности

!!! info ""
    **ruts.cohesion_stats.CohesionStats**

## Описание

Статистики связности текста по образцу [Coh-Metrix](https://doi.org/10.1017/CBO9780511894664) и [TAACO](https://doi.org/10.3758/s13428-015-0651-7): повторы существительных, аргументов (существительных и местоимений) и знаменательных слов между соседними предложениями и всеми парами предложений; данность - доля местоимений, отношение местоимений к существительным, доля указательных и доля знаменательных слов, уже встречавшихся в тексте; темпоральная связность - повтор времени и вида глаголов в соседних предложениях; плотность коннекторов по классам и типам на 1000 слов. Предложения сравниваются по леммам. В качестве источника данных может использоваться как непосредственно текст, так и объект класса `Doc` библиотеки [spaCy](https://github.com/explosion/spaCy).

Слова классифицируются по разметке [pymorphy3](https://github.com/no-plagiarism/pymorphy3) или по разметке Universal Dependencies объекта `Doc`:

| Понятие | pymorphy3 | Universal Dependencies (`Doc`) |
| :------ | :-------- | :----------------------------- |
| Существительные | `NOUN` | `NOUN`, `PROPN` |
| Местоимения | `NPRO`, `Apro`, леммы из `DEMONSTRATIVE_LEMMAS` | `PRON`, `DET`, леммы из `DEMONSTRATIVE_LEMMAS` |
| Аргументы | `NOUN`, `NPRO` | `NOUN`, `PROPN`, `PRON` |
| Знаменательные слова | `CONTENT_POS` без `STOPWORD_GRAMMEMES` и указательных | `CONTENT_UD_POS` без указательных |
| Указательные | леммы из `DEMONSTRATIVE_LEMMAS`: этот, это, тот, такой, таковой, столько, сей, оный | те же леммы |
| Время и вид | граммемы `past`, `pres`, `futr` и `perf`, `impf` глагольных форм, время бытийных «нет» и «нету» | признаки `Tense` и `Aspect` |

Коннекторы ищутся в каждом предложении по словарю `ruts/resources/connectors.tsv` (317 единиц, см. [`find_connectors`](cohesion_stats_funcs.md#find_connectors)); свой словарь передается параметром `connectors`. Однословный коннектор засчитывается только при части речи из `CONNECTOR_POS` (союз, частица, наречие, предлог, междометие) или из `CONNECTOR_POS_EXTRA` для отдельных слов (словом, главное, допустим, точнее): «раз» как существительное не считается. Контекстные правила отсеивают предлоги и омонимы коннекторов: *после обеда*, *пока что*, *не правда ли*, *ещё раз*, *это значит*. Часть речи берется из разметки `Doc`; без разметки слово проходит, если подходящая часть речи есть хотя бы в одном разборе pymorphy3. Классы по Криони, Никину и Филипповой (2008):

| Класс | Ключ | Примеры |
| :---- | :--- | :------ |
| Причинные (включая следственные и целевые) | `causal` | потому что, поэтому, в результате, чтобы, таким образом |
| Противительные | `adversative` | но, однако, зато, с другой стороны, в то же время |
| Уступительные | `concessive` | хотя, несмотря на, тем не менее, и всё же, в любом случае |
| Временные | `temporal` | когда, затем, после того как, тем временем, в дальнейшем |
| Аддитивные | `additive` | и, также, кроме того, более того, например, во-первых |
| Условные | `conditional` | если, в случае если, при условии что, в противном случае |
| Переформулирующие | `reformulative` | то есть, иными словами, в общем, подводя итог |

Тип коннектора: первичные - союзы, наречия и частицы (потому что, однако, затем), вторичные - лексикализованные обороты с существительными и глаголами (в результате этого, с другой стороны, иными словами).

!!! note "Примечание"
    Вычисление статистик происходит в момент инициализации объекта класса `CohesionStats`.

## Языковые крючки

Класс расширяет `CohesionStats` ядра [anyTS](https://sergeyshk.github.io/anyTS/stats/cohesion_stats/) русским слоем. `analyze` читает и строку, и `Doc`: для `Doc` с разметкой частей речи часть речи, время и вид берутся из `token.pos_` и `token.morph`, а лемма - из разбора pymorphy3 с частью речи токена ([`unit_info`](cohesion_stats_funcs.md#word_info)); для строки, `Doc` без разметки и `Doc` с заданным экстрактором слов - из первого разбора pymorphy3 ([`words_info`](cohesion_stats_funcs.md#word_info)), где ответное «нет» - частица. Части дефисного слова, разрезанного spaCy, склеиваются (`join_hyphens = True`, `во-первых` - одно слово). Строка и `Doc` без границ предложений разбиваются на предложения русским [`SentsExtractor`](../extractors/sentences.md) (`sents_extractor_class`); слова строки дает русский [`WordsExtractor`](../extractors/words.md) или заданный `words_extractor` - параметр, которого у ядра нет. Коннекторы берутся из словаря `load_connectors` и ищутся сопоставителем `RussianConnectorMatcher` ([`find_connectors`](cohesion_stats_funcs.md#find_connectors)) - `ConnectorMatcher` ядра с русской нормализацией слов и частями речи. Таблица `print_stats` выводится с русскими заголовками и описаниями из `ruts.constants.COHESION_STATS_DESC`, сообщения об ошибках - по-русски (`CORE_MESSAGES`).

## Параметры

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `source` | str/Doc | `-` | Источник данных (строка или объект Doc) |
| `sents_extractor` | SentsExtractor | `None` | Инструмент для извлечения предложений; если задан, применяется и к тексту Doc |
| `words_extractor` | WordsExtractor | `None` | Инструмент для извлечения слов; если задан, применяется и к тексту Doc |
| `connectors` | dict[str, tuple[str, str]] | `None` | Словарь коннекторов - класс и тип по коннектору; если не задан, используется словарь из `resources` |

Источник, который не строка и не `Doc`, экстрактор другого типа и коннекторы, которые не словарь словосочетаний и пар строк, дают `SourceTypeError`; источник без слов - `SourceError`, неизвестный класс или тип коннектора - `ParameterError`.

## Атрибуты

| Атрибут | Тип | Описание |
| :-----: | :-: | :------: |
| `words`, `lemmas` | tuple[tuple[str]] | Слова и леммы каждого предложения, в котором есть слова |
| `n_sents`, `n_words` | int | Количество предложений со словами и количество слов |
| `n_nouns`, `n_pronouns`, `n_demonstratives`, `n_content_words` | int | Количество слов по видам |
| `n_given` | int | Количество знаменательных слов, лемма которых встречалась раньше |
| `n_connectors`, `connector_spans`, `c_connectors` | int, tuple[Connector], dict[str, int] | Количество коннекторов, их вхождения и количество вхождений по коннекторам |
| `n_inter_connectors` | int | Количество межпредложенческих коннекторов |
| `noun_overlap_adjacent`, `noun_overlap_all` | float | Доли соседних и всех пар предложений с общим существительным |
| `argument_overlap_adjacent`, `argument_overlap_all` | float | То же для существительного или местоимения |
| `content_overlap_adjacent`, `content_overlap_all` | float | То же для знаменательного слова |
| `content_overlap_prop_adjacent`, `content_overlap_prop_all` | float | Средняя доля общих знаменательных слов (коэффициент Дайса) в соседних и во всех парах |
| `p_pronouns`, `p_demonstratives` | float | Доли местоимений и указательных среди слов |
| `pronoun_noun_ratio` | float | Отношение числа местоимений к числу существительных |
| `p_given` | float | Доля знаменательных слов, лемма которых встречалась раньше в тексте |
| `tense_repetition`, `mood_repetition`, `aspect_repetition` | float | Доли соседних пар предложений с одинаковым преобладающим временем, наклонением и видом |
| `temporal_cohesion` | float | Среднее повторов признаков `temporal_features` |
| `connectors` | float | Коннекторов на 1000 слов |
| `connectors_inter`, `connectors_intra` | float | Межпредложенческих коннекторов на 1000 слов, которые связывают предложение с предыдущими: открывающих предложение, если сопоставитель не считает их подчинительным союзом (`is_subordinator`: один из его `subordinators` или однословный коннектор с частью речи `SCONJ`, *когда он пришел, ...*), чья клауза принадлежит тому же предложению; и внутрипредложенческих - остальных |
| `connectors_<class>`, `connectors_<kind>` | float | Коннекторов каждого класса и типа сопоставителя на 1000 слов: по умолчанию `connectors_causal`, `connectors_adversative`, `connectors_concessive`, `connectors_temporal`, `connectors_additive`, `connectors_conditional`, `connectors_reformulative`, `connectors_primary` и `connectors_secondary` |

Повторы слов в тексте из одного предложения, повтор признака без двух соседних предложений с ним и доля, которой не на что делить, равны `nan`.

Наклонение `CohesionStats` в ruTS не сравнивает: `mood_repetition` всегда равен `nan` и в `get_stats` не входит, а `temporal_cohesion` - среднее `tense_repetition` и `aspect_repetition`. Заданные экстракторы хранятся в атрибутах:

| Атрибут | Тип | Описание |
| :-----: | :-: | :------: |
| `sents_extractor` | SentsExtractor | Заданный инструмент для извлечения предложений, `None` без него |
| `words_extractor` | WordsExtractor | Заданный инструмент для извлечения слов, `None` без него |

!!! note "Примечание"
    Каждую статистику можно вычислить отдельно, выполнив соответствующую функцию. Подробную информацию о статистиках связности и функциях, используемых для их вычисления, можно узнать в соответствующем [разделе](cohesion_stats_funcs.md).

## Методы

### get_stats

Возвращает справочник с вычисленными статистиками связности текста.

!!! example "Пример"

    _Код_:

    ``` python
    # Загрузка библиотек
    from ruts import CohesionStats

    # Подготовка данных
    text = "Кот сидел на окне. Он смотрел на птиц. Птицы улетели, и кот уснул. Завтра он снова будет сидеть на этом окне."

    # Вычисление статистик
    cs = CohesionStats(text)
    cs.get_stats()
    ```

### to_dataframe, describe

Метод `to_dataframe` (статистики в `pandas.DataFrame` из одной строки) и метод `describe` - из [интерфейса статистик](https://sergeyshk.github.io/anyTS/stats/stats/) ядра anyTS; шкал у статистик связности нет, поэтому `describe` всегда возвращает `None`.
