# Статистики лексической сложности

``` {.python .signature}
LexicalStats(source, words_extractor=None, freq_dict=None)
```

<!-- core: stats/lexical_stats.md:LexicalStats baa1034 -->
Лексическая сложность (lexical sophistication) по образцу TAALES (Kyle, Crossley и Berger, 2018) - насколько редки слова текста: статистики по частотному словарю и его униграммной модели, доли частотных полос списка самых частых лемм и лексическая плотность. Статистики по словарю вычисляются при первом обращении, поэтому полосам и лексической плотности данные словаря не нужны.

Исключения:

- `SourceTypeError` - словарь другого класса, чем у библиотеки, или, без `freq_dict_class`, словарь без `lookup` и `ipm` или его отсутствие; `analyze`, который дает не объекты `LexicalWord`;
- `SourceError` - источник без слов.

В ruTS `SourceTypeError` дают также источник, который не строка и не `Doc`, и экстрактор другого типа, а метрики по словарю без загруженного словаря - `DatasetNotFoundError`.

В отличие от [метрик лексического разнообразия](diversity_stats.md), которые сравнивают слова текста между собой, здесь слова сравниваются с частотами языка ([TAALES](https://doi.org/10.3758/s13428-017-0924-4)). Источник данных - текст или объект `Doc` библиотеки [spaCy](https://github.com/explosion/spaCy).

Класс расширяет `LexicalStats` ядра [anyTS](https://sergeyshk.github.io/anyTS/stats/lexical_stats/) русским слоем: словарь - [`FreqDict`](../datasets/freq2011.md) Ляшевской и Шарова (`freq_dict_class`), ранги лемм и размер списка (`rank`, `top_size`) - из вшитого списка лемм Шарова ([`get_rank`](#bands)). Слова строки извлекает русский [`WordsExtractor`](../extractors/words.md) или заданный экстрактор, который для `Doc` применяется к его тексту; без экстрактора слова `Doc` берутся из его токенов, а части дефисного слова, разрезанного spaCy, склеиваются. Числа (2020, 5.5, 3-й) словами не считаются. Леммы дает pymorphy3: для `Doc` с разметкой частей речи - по части речи токена (`ruts.utils.lemmatize`), иначе по первому разбору. Ключи слов в словаре (`keys`, `dictionary_keys`) - леммы, приведенные к его соглашениям функцией `dictionary_lemma`: должна - должен, денег - деньги, ночью - ночь. Таблица `print_stats` и сообщения об ошибках - по-русски (`LEXICAL_STATS_DESC` и `CORE_MESSAGES` из `ruts.constants`).

=== "Код"

    ``` python
    from ruts import LexicalStats
    from ruts.datasets import FreqDict

    FreqDict().download()
    ls = LexicalStats("Кот сидел на окне и смотрел на птиц")
    ls.print_stats()
    ```

## Параметры

| Параметр | Тип | По умолчанию | Описание |
| :------- | :-- | :----------- | :------- |
| `source` | `str` / `Doc` | - | Источник данных |
| `words_extractor` | `WordsExtractor` | `None` | Инструмент для извлечения слов; применяется и к `Doc`, к его тексту |
| `freq_dict` | `FreqDict` | `None` | Частотный словарь; по умолчанию `FreqDict()` из директории по умолчанию |

## Атрибуты

<!-- core: stats/lexical_stats.md:LexicalStats-attributes 40e73ab -->
| Атрибут | Тип | Описание |
| :------ | :-- | :------- |
| `freq_dict` | `FrequencyDictionary` | Частотный словарь |
| `words`, `lemmas` | `tuple[str]` | Слова и их леммы; полосы считаются по леммам |
| `keys` | `tuple[str]` | Ключи слов в словаре |
| `entries` | `tuple[FrequencyEntry / None]` | Статьи словаря, `None` для слова вне его |
| `ranks` | `tuple[int / None]` | Ранги лемм, `None` вне списка |
| `n_words`, `n_content_words`, `n_found` | `int` | Количество слов, знаменательных слов и слов, найденных в словаре |

В ruTS словарь - `FreqDict`, а его статьи - именованные кортежи `Entry`.

## Метрики

<!-- core: stats/lexical_stats.md:LexicalStats-metrics aa10b9c -->
Каждая метрика - атрибут или свойство объекта, а `get_stats` дает их все. Среднее берется по словам, найденным в словаре, а без них равно `nan`.

| Метрика | Что измеряет | Диапазон | Чем больше, тем |
| :------ | :----------- | :------- | :-------------- |
| `coverage` | Доля слов, найденных в словаре | 0-1 | больше слов знакомо словарю |
| `mean_ipm`, `mean_ipm_content` | Средняя частотность на миллион слов найденных слов, найденных знаменательных слов | больше 0 | частотнее слова |
| `mean_log_ipm`, `mean_log_ipm_content` | Средний десятичный логарифм частотности найденных слов, найденных знаменательных слов | до 6 | частотнее слова |
| `mean_range` | Средний диапазон найденных слов | от 0 | в большем числе частей корпуса встречаются слова |
| `mean_dispersion` | Средняя дисперсия найденных слов | как у словаря | по мере словаря |
| [`surprisal`](#surprisal) | Средний сюрпризал слов по униграммной модели словаря в битах | от 0 | реже слова |
| [`perplexity`](#surprisal) | 2 в степени сюрпризала | от 1 | реже слова |
| [`p_top1000`](#bands), [`p_top2000`](#bands), [`p_top5000`](#bands), [`p_top10000`](#bands) | Доля слов с леммой из топ-1000, 2000, 5000 и 10000 списка | 0-1, `nan` для полосы больше `top_size` | частотнее слова |
| [`p_beyond_top10000`](#bands) | Доля слов с леммой вне топ-10000 | 0-1, `nan` для списка короче 10000 | реже слова |
| `lexical_density` | Доля знаменательных слов | 0-1 | больше знаменательных слов |

Метрики считаются по двум ресурсам; рядом со средними по словарю всегда смотрите `coverage`.

| Ресурс | Метрики | Доступность |
| :----- | :------ | :---------- |
| [`FreqDict`](../datasets/freq2011.md) - словарь Ляшевской и Шарова, 52 138 лемм с ipm, R, D | `coverage`, `mean_ipm*`, `mean_log_ipm*`, `mean_range`, `mean_dispersion`, `surprisal`, `perplexity` | загружается один раз командой `FreqDict().download()` |
| Вшитый список 10 000 самых частых лемм интернет-корпуса Лидского университета (С. А. Шаров, зеркало [hingston/russian](https://github.com/hingston/russian), CC BY 2.5) | `p_top1000`, `p_top2000`, `p_top5000`, `p_top10000`, `p_beyond_top10000`, `band_coverage` | всегда |

### Частотность по словарю { #frequency }

`coverage` · `mean_ipm` · `mean_ipm_content` · `mean_log_ipm` · `mean_log_ipm_content` · `mean_range` · `mean_dispersion` · [Ляшевская, Шаров](http://dict.ruslang.ru/freq.php)
{ .metric-meta }

Метрики считаются по статьям `FreqDict` для ключей слов (`keys`, `entries`): средние берутся по словам, найденным в словаре, по всем или только по знаменательным. Средняя частотность в ipm чувствительна к служебным словам (и - 35 000 ipm, в - 31 000), поэтому для сравнения текстов удобнее логарифм частотности или средняя по знаменательным словам. Средняя частотность знаменательных слов `mean_ipm_content` - признак FREQ2 формулы Соловьёва, Иванова, Солнышкиной 2023 года, значения которого в статье лежат в пределах 200-1000 ([`sis_grade_by_freq`](readability_stats.md#sis_grade_by_freq)).

Редкие слова опускают покрытие и логарифм частотности и поднимают сюрпризал и долю вне топ-10000:

=== "Код"

    ``` python
    from ruts import LexicalStats

    ls = LexicalStats("Фелинолог пребывал на подоконнике")
    ls.coverage, ls.mean_log_ipm, ls.surprisal, ls.p_beyond_top10000
    ```

=== "Результат"

    ```
    (0.75, 2.3063585317426494, 14.515882690436708, 0.25)
    ```

### Сюрпризал и перплексия { #surprisal }

`surprisal` · `perplexity`
{ .metric-meta }

<!-- core: stats/lexical_stats.md:calc_surprisal 0ce80d8 -->
``` {.python .signature}
calc_surprisal(lemmas, freq_dict)
```

Средний сюрпризал слов по униграммной модели частотного словаря в битах; слово вне словаря получает его наименьшую частоту `min_ipm`. Перплексия - 2 в его степени.

$$
\frac{1}{N} \sum_{w} -\log_2 \frac{\max(\textrm{ipm}_w, \textrm{min\_ipm})}{10^6}
$$

| Параметр | Тип | По умолчанию | Описание |
| :------- | :-- | :----------- | :------- |
| `lemmas` | `list[str]` | - | Ключи слов в словаре |
| `freq_dict` | `FrequencyDictionary` | - | Частотный словарь |

Без слов результат - `nan`; ключи, которые не список строк, и словарь без `ipm` и `min_ipm` дают `SourceTypeError`, наименьшая частота не больше нуля - `ParameterError`.

В ruTS словарь - `FreqDict` с наименьшей частотой 0.4 ipm: словарь другого класса дает `SourceTypeError`.

=== "Код"

    ``` python
    from ruts.datasets import FreqDict
    from ruts.lexical_stats import calc_surprisal

    calc_surprisal(["кот", "сидеть", "фелинолог"], FreqDict())
    ```

=== "Результат"

    ```
    15.570731790883956
    ```

### Частотные полосы { #bands }

`p_top1000` · `p_top2000` · `p_top5000` · `p_top10000` · `p_beyond_top10000` · `band_coverage(bands, unique)`
{ .metric-meta }

<!-- core: stats/lexical_stats.md:LexicalStats-bands 9a6c3b6 -->
Доля слов, лемма которых имеет ранг (`rank`) в пределах топ-$N$ списка, для границ 1000, 2000, 5000 и 10000 из `FREQUENCY_BANDS`; доля вне топ-10000 - остаток, включая слова вне списка. Полоса больше размера списка (`top_size`) равна `nan`, как и доля вне топ-10000 для списка короче 10000.

$$
\frac{\textrm{Количество слов с рангом до } N}{\textrm{Количество слов}}
$$

Так строится профиль частотных полос по образцу Lexical Frequency Profile.

``` {.python .signature}
get_rank(lemma)
```

Ранг леммы по вшитому списку Шарова, `None` для леммы вне списка; лемма берется в любом регистре, с ё или без.

| Параметр | Тип | По умолчанию | Описание |
| :------- | :-- | :----------- | :------- |
| `lemma` | `str` | - | Лемма |

``` {.python .signature}
load_top_lemmas()
```

Весь список из файла `ruts/resources/sharoff_top10000.txt`: ранг каждой леммы в нижнем регистре без буквы ё, начиная с 1; у дублей остается меньший ранг.

=== "Код"

    ``` python
    from ruts.lexical_stats import get_rank, load_top_lemmas

    get_rank("и"), get_rank("кот"), get_rank("фелинолог")
    len(load_top_lemmas())
    ```

=== "Результат"

    ```
    (1, 2009, None)
    9989
    ```

### Лексическая плотность { #lexical_density }

`lexical_density`
{ .metric-meta }

Доля знаменательных слов (существительные, прилагательные, глаголы, наречия без местоименных и вводных слов) среди всех слов; знаменательное слово определяет [`is_content_word`](cohesion_stats.md#is_content_word) для строки и `CONTENT_UD_POS` для `Doc` с разметкой.

$$
\frac{\textrm{Количество знаменательных слов}}{\textrm{Количество слов}}
$$

</div>

## Методы

<!-- core: stats/lexical_stats.md:LexicalStats-band_coverage 065e9e9 -->
`band_coverage(bands, unique)` возвращает долю слов с леммой из топ-N списка для каждой границы N из `bands` (по умолчанию `FREQUENCY_BANDS`), а с `unique=True` - долю различных лемм. Границы, которые не список целых чисел, и граница вне промежутка от 1 до `top_size()` дают `ParameterError`.

=== "Код"

    ``` python
    from ruts import LexicalStats

    ls = LexicalStats("Кот сидел на окне и смотрел на птиц")
    ls.band_coverage(unique=True)
    ls.band_coverage(bands=(100, 500))
    ```

=== "Результат"

    ```
    {1000: 0.7142857142857143, 2000: 0.8571428571428571, 5000: 1.0, 10000: 1.0}
    {100: 0.375, 500: 0.75}
    ```

Остальные методы - `get_stats`, `to_dataframe`, `print_stats` и `describe` - из [интерфейса статистик](https://sergeyshk.github.io/anyTS/stats/stats/) ядра anyTS: метрики справочником, таблицей `pandas.DataFrame` из одной строки и таблицей на экране. Шкал у статистик лексической сложности нет, поэтому `describe` всегда возвращает `None`.
