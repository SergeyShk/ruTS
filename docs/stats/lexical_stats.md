# Статистики лексической сложности

!!! info ""
    **ruts.lexical_stats.LexicalStats**

## Описание

<!-- core: stats/lexical_stats.md:LexicalStats 460aef7 -->
Лексическая сложность (lexical sophistication) по образцу TAALES (Kyle, Crossley и Berger, 2018) - насколько редки слова текста: средняя частотность, диапазон и дисперсия слов по частотному словарю, сюрпризал и перплексия по его униграммной модели, доли частотных полос списка самых частых лемм и лексическая плотность - доля знаменательных слов. Статистики по словарю вычисляются при первом обращении, поэтому полосам и лексической плотности данные словаря не нужны.

Словарь другого класса, чем у библиотеки, дает `SourceTypeError`, источник без слов - `SourceError`.

В отличие от [метрик лексического разнообразия](diversity_stats.md), которые сравнивают слова текста между собой, здесь слова сравниваются с частотами языка ([TAALES](https://doi.org/10.3758/s13428-017-0924-4)). В качестве источника данных может использоваться как непосредственно текст, так и объект класса `Doc` библиотеки [spaCy](https://github.com/explosion/spaCy).

Ресурсы:

| Ресурс | Метрики | Доступность |
| :----- | :------ | :---------- |
| [`FreqDict`](../datasets/freq2011.md) - словарь Ляшевской и Шарова, 52 138 лемм с ipm, R, D | `coverage`, `mean_ipm*`, `mean_log_ipm*`, `mean_range`, `mean_dispersion`, `surprisal`, `perplexity` | загружается один раз командой `FreqDict().download()`; без словаря обращение к этим метрикам и `get_stats` вызывает `DatasetNotFoundError` |
| Вшитый список 10 000 самых частых лемм интернет-корпуса Лидского университета (С. А. Шаров, зеркало [hingston/russian](https://github.com/hingston/russian), CC BY 2.5) | `p_top1000`, `p_top2000`, `p_top5000`, `p_top10000`, `p_beyond_top10000`, `band_coverage` | всегда |

`mean_ipm_content` - признак FREQ2 формулы Соловьёва, Иванова, Солнышкиной 2023 года с частотностью, см. [`sis_grade_by_freq`](readability_stats.md#sis_grade_by_freq).

## Языковые крючки

Класс расширяет `LexicalStats` ядра [anyTS](https://sergeyshk.github.io/anyTS/stats/lexical_stats/) русским слоем: словарь - [`FreqDict`](../datasets/freq2011.md) Ляшевской и Шарова (`freq_dict_class`), а ранги лемм и размер списка (`rank`, `top_size`) берутся из вшитого списка 10 000 лемм Шарова ([`get_rank`](lexical_stats_funcs.md#get_rank)). `analyze` берет слова строки из русского [`WordsExtractor`](../extractors/words.md) или заданного экстрактора, который для `Doc` применяется к его тексту; без экстрактора слова `Doc` берутся из его токенов, а части дефисного слова, разрезанного spaCy, склеиваются. Числа (2020, 5.5, 3-й) словами не считаются. Леммы дает pymorphy3: для `Doc` с разметкой частей речи - по части речи токена (`ruts.utils.lemmatize`), иначе по первому разбору; знаменательные слова определяются как в [`CohesionStats`](cohesion_stats.md). Ключи слов в словаре (`keys`, `dictionary_keys`) - леммы, приведенные к его соглашениям функцией `dictionary_lemma`: должна - должен, денег - деньги, ночью - ночь. Таблица `print_stats` и сообщения об ошибках - по-русски (`LEXICAL_STATS_DESC` и `CORE_MESSAGES` из `ruts.constants`).

## Параметры

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `source` | str/Doc | `-` | Источник данных (строка или объект Doc) |
| `words_extractor` | WordsExtractor | `None` | Инструмент для извлечения слов; если задан, применяется и к тексту Doc |
| `freq_dict` | FreqDict | `None` | Частотный словарь; если не задан, используется `FreqDict()` из директории по умолчанию |

Источник, который не строка и не `Doc`, и экстрактор другого типа дают `SourceTypeError`.

## Атрибуты

<!-- core: stats/lexical_stats.md:LexicalStats-attributes 903c3fe -->
| Атрибут | Тип | Описание |
| :-----: | :-: | :------: |
| `words`, `lemmas` | tuple[str] | Слова и их леммы; полосы считаются по леммам |
| `keys` | tuple[str] | Ключи слов в словаре |
| `entries` | tuple[FrequencyEntry или None] | Статьи словаря, `None` для слова вне его |
| `ranks` | tuple[int или None] | Ранги лемм, `None` вне списка |
| `n_words`, `n_content_words`, `n_found` | int | Количество слов, знаменательных слов и слов, найденных в словаре |
| `coverage` | float | Доля слов, найденных в словаре |
| `mean_ipm`, `mean_ipm_content` | float | Средняя частотность найденных слов, найденных знаменательных слов |
| `mean_log_ipm`, `mean_log_ipm_content` | float | Средний десятичный логарифм частотности найденных слов и найденных знаменательных слов |
| `mean_range`, `mean_dispersion` | float | Средние диапазон и дисперсия найденных слов |
| `surprisal`, `perplexity` | float | Средний сюрпризал в битах (`calc_surprisal`), 2 в его степени |
| `p_top1000`, `p_top2000`, `p_top5000`, `p_top10000`, `p_beyond_top10000` | float | Доли слов с леммой из топ-1000, 2000, 5000 и 10000 списка и вне его |
| `lexical_density` | float | Доля знаменательных слов |

Среднее без найденных слов - `nan`, как и полоса больше размера списка (`top_size`).

Рядом со средними по словарю всегда смотрите `coverage`.

!!! note "Примечание"
    Каждую статистику можно вычислить отдельно, выполнив соответствующую функцию. Подробную информацию о статистиках и функциях, используемых для их вычисления, можно узнать в соответствующем [разделе](lexical_stats_funcs.md).

## Методы

### band_coverage

<!-- core: stats/lexical_stats.md:LexicalStats-band_coverage 065e9e9 -->
`band_coverage(bands, unique)` возвращает долю слов с леммой из топ-N списка для каждой границы N из `bands` (по умолчанию `FREQUENCY_BANDS`), а с `unique=True` - долю различных лемм. Границы, которые не список целых чисел, и граница вне промежутка от 1 до `top_size()` дают `ParameterError`.

!!! example "Пример"

    ``` python
    from ruts import LexicalStats

    ls = LexicalStats("Кот сидел на окне и смотрел на птиц")
    ls.band_coverage(unique=True)
    # {1000: 0.7142857142857143, 2000: 0.8571428571428571, 5000: 1.0, 10000: 1.0}
    ls.band_coverage(bands=(100, 500))
    # {100: 0.375, 500: 0.75}
    ```

### get_stats

Возвращает справочник с вычисленными статистиками лексической сложности текста.

!!! example "Пример"

    _Код_:

    ``` python
    # Загрузка библиотек
    from ruts import LexicalStats
    from ruts.datasets import FreqDict

    # Загрузка словаря (один раз)
    FreqDict().download()

    # Вычисление статистик
    ls = LexicalStats("Кот сидел на окне и смотрел на птиц")
    ls.get_stats()
    ```

    _Результат_:

    ``` bash
    {'coverage': 1.0,
    'mean_ipm': 8645.5375,
    'mean_ipm_content': 324.18,
    'mean_log_ipm': 3.0674194359404705,
    'mean_log_ipm_content': 2.316850597556863,
    'mean_range': 99.75,
    'mean_dispersion': 95.125,
    'surprisal': 9.74182176626998,
    'perplexity': 856.2105288389297,
    'p_top1000': 0.75,
    'p_top2000': 0.875,
    'p_top5000': 1.0,
    'p_top10000': 1.0,
    'p_beyond_top10000': 0.0,
    'lexical_density': 0.625}
    ```

Редкие слова поднимают сюрпризал и опускают покрытие и полосы:

!!! example "Пример"

    ``` python
    ls = LexicalStats("Фелинолог пребывал на подоконнике")
    ls.coverage, ls.p_top1000, ls.p_beyond_top10000, ls.surprisal
    # (0.75, 0.25, 0.25, 14.515882690436708)
    ```

### print_stats

Выводит на экран таблицу с вычисленными статистиками лексической сложности текста.

!!! example "Пример"

    _Код_:

    ``` python
    # Создание объекта для вычисления статистик
    ls = LexicalStats("Кот сидел на окне и смотрел на птиц")

    # Отображение таблицы вычисленных статистик
    ls.print_stats()
    ```

    _Результат_:

### to_dataframe, describe

Метод `to_dataframe` (статистики в `pandas.DataFrame` из одной строки) и метод `describe` - из [интерфейса статистик](https://sergeyshk.github.io/anyTS/stats/stats/) ядра anyTS; шкал у статистик лексической сложности нет, поэтому `describe` всегда возвращает `None`.
