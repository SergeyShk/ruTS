# Фоностатистики

!!! info ""
    **ruts.phon_stats.PhonStats**

## Описание

<!-- core: stats/phon_stats.md:PhonStats 08da258 -->
Фоностатистики текста: доли гласных, сонорных, звонких и глухих шумных согласных, отношение согласных к гласным, консонантные кластеры, зияния, энтропия CV-шаблонов слов, жесткость, аллитерация и ассонанс, открытые слоги и средняя длина слога. Звук - по умолчанию буква слова, а если библиотека дает транскрипцию, звук транскрипции. Источник данных - текст или объект `Doc` библиотеки [spaCy](https://github.com/explosion/spaCy); слова берутся в нижнем регистре, а явно переданный экстрактор применяется к тексту `Doc`.

Источник, который не строка и не `Doc`, и экстрактор другого типа дают `SourceTypeError`, источник без слов - `SourceError`, окно, которое не целое число не меньше 2, - `ParameterError`.

Время вычисления растет линейно с длиной текста.

!!! note "Примечание"
    Вычисление статистик происходит в момент инициализации объекта класса `PhonStats`.

## Языковые крючки

Класс расширяет `PhonStats` ядра [anyTS](https://sergeyshk.github.io/anyTS/stats/phon_stats/) крючками русского языка: звуки - буквы слова по классам из таблицы ниже, без учета оглушения, редукции и ударения; йотированные е, ё, ю, я после гласной не дают зияния, а слова делятся на слоги по правилу восходящей звучности (Аванесов) функцией [`syllabify`](../syllables.md#syllabify). Из слов текста и `Doc` убираются знаки ударения, а части дефисного слова, разрезанного spaCy, склеиваются (`во-первых` - одно слово). Таблица `print_stats` выводится с русскими заголовками и русскими описаниями статистик из `ruts.constants.PHON_STATS_DESC`, сообщения об ошибках - по-русски, из `ruts.constants.CORE_MESSAGES`.

| Класс | Буквы | Константа |
| :---: | :---: | :-------: |
| Гласные | а, е, и, о, у, ы, э, ю, я, ё | `RU_VOWELS` |
| Сонорные согласные | л, м, н, р, й | `RU_CONSONANTS_SONOR`, `RU_CONSONANTS_YET` |
| Звонкие шумные согласные | б, в, г, д, ж, з | `RU_CONSONANTS_HIGH` |
| Глухие шумные согласные | к, п, с, т, ф, х, ц, ч, ш, щ | `RU_CONSONANTS_LOW` |
| Знаки | ь, ъ - не звуки: не учитываются в долях и не разрывают консонантный кластер | `RU_MARKS` |

## Параметры

<!-- core: stats/phon_stats.md:PhonStats-parameters ae805cb -->
| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `source` | str/Doc | `-` | Источник данных |
| `words_extractor` | WordsExtractor | `None` | Инструмент для извлечения слов; для `Doc` применяется к его тексту |
| `window_len` | int | `3` | Размер окна в словах для аллитерации и ассонанса (`PHON_WINDOW_LEN`) |

Отдельно окно проверяет функция `ruts.phon_stats.check_params(window_len)`.

## Атрибуты

<!-- core: stats/phon_stats.md:PhonStats-attributes bcd9e17 -->
| Атрибут | Тип | Описание |
| :-----: | :-: | :------: |
| `words` | tuple[str] | Слова в нижнем регистре |
| `window_len` | int | Размер окна аллитерации и ассонанса |
| `syllables`, `sounds` | tuple | Слоги (`syllabify`) и звуки (`transcribe`) каждого слова |
| `n_vowels`, `n_sonorants`, `n_voiced`, `n_voiceless`, `n_consonants` | int | Количество звуков по классам |
| `c_clusters` | dict[int, int] | Количество консонантных кластеров по длине (`consonant_clusters`) |
| `c_syllable_patterns` | dict[str, int] | Количество слогов по CV-шаблону; слог без звука из классов (число) слогом не считается |
| `p_vowels`, `p_sonorants`, `p_voiced`, `p_voiceless` | float | Доли звуков по классам |
| `consonant_vowel_ratio` | float | Отношение согласных к гласным |
| `p_heavy_clusters` | float | Доля кластеров из трех и более согласных |
| `p_hiatus` | float | Зияний на слово |
| `cv_entropy` | float | Энтропия Шеннона CV-шаблонов слов в битах |
| `hardness` | float | Отношение глухих шумных согласных к гласным и сонорным |
| `alliteration`, `assonance` | float | Индекс повторов согласных и гласных (`calc_repetition_index`) |
| `p_open_syllables` | float | Доля слогов, оканчивающихся на гласную |
| `mean_syllable_len` | float | Средняя длина слога в звуках |

Доля или отношение, у которых в знаменателе нет звуков, кластеров или слогов, равны `nan`, как и зияния на слово и энтропия текста без звуков.

В ruTS `mean_syllable_len` считается в буквах слога вместе с ь и ъ, а атрибут `n_marks` (int) - количество ь и ъ.

!!! note "Примечание"
    Каждую статистику можно вычислить отдельно, выполнив соответствующую функцию. Подробную информацию о фоностатистиках и функциях, используемых для их вычисления, можно узнать в соответствующем [разделе](phon_stats_funcs.md).

## Методы

### get_stats

Возвращает справочник с вычисленными фоностатистиками текста.

!!! example "Пример"

    _Код_:

    ``` python
    # Загрузка библиотек
    from ruts import PhonStats

    # Подготовка данных
    text = "Ног нет, а хожу, рта нет, а скажу: когда спать, когда вставать, когда работу начинать"

    # Вычисление статистик
    ps = PhonStats(text)
    ps.get_stats()
    ```

    _Результат_:

    ``` bash
    {'p_vowels': 0.4032258064516129,
    'p_sonorants': 0.11290322580645161,
    'p_voiced': 0.1935483870967742,
    'p_voiceless': 0.2903225806451613,
    'consonant_vowel_ratio': 1.48,
    'p_heavy_clusters': 0.034482758620689655,
    'p_hiatus': 0.0,
    'cv_entropy': 3.1395722619867223,
    'hardness': 0.5625,
    'alliteration': 1.0916179337231968,
    'assonance': 0.8305084745762712,
    'p_open_syllables': 0.76,
    'mean_syllable_len': 2.6}
    ```

Слоги и распределения доступны как атрибуты:

!!! example "Пример"

    ``` python
    ps.syllables[:4]
    # (('ног',), ('нет',), ('а',), ('хо', 'жу'))
    ps.c_clusters
    # {1: 22, 2: 6, 3: 1}
    ps.c_syllable_patterns
    # {'CCCV': 1, 'CCV': 5, 'CCVC': 1, 'CV': 11, 'CVC': 5, 'V': 2}
    ```

`to_dataframe` возвращает те же статистики строкой `pandas.DataFrame`, а `describe` для каждой из них возвращает `None`: шкал интерпретации у фоностатистик нет.

### print_stats

<!-- core: stats/stats.md:Stats-print_stats d798c21 -->
Выводит таблицу со статистиками из `stats_desc` и их описаниями под заголовками из `stats_headers`, дробные числа - с двумя знаками после запятой; ширина каждой колонки - по самому длинному тексту в ней.

!!! example "Пример"

    _Код_:

    ``` python
    ...

    # Отображение таблицы вычисленных статистик
    ps.print_stats()
    ```

    _Результат_:

    ``` bash
                  Статистика              | Значение
    -------------------------------------------------
    Доля гласных                          |   0.40
    Доля сонорных согласных               |   0.11
    Доля звонких шумных согласных         |   0.19
    Доля глухих шумных согласных          |   0.29
    Отношение согласных к гласным         |   1.48
    Доля кластеров из 3 и более согласных |   0.03
    Зияний гласных на слово               |   0.00
    Энтропия CV-шаблонов слов (бит)       |   3.14
    Жёсткость                             |   0.56
    Индекс аллитерации                    |   1.09
    Индекс ассонанса                      |   0.83
    Доля открытых слогов                  |   0.76
    Средняя длина слога (букв)            |   2.60
    ```
