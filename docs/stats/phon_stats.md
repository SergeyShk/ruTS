# Фоностатистики

``` {.python .signature}
PhonStats(source, words_extractor=None, window_len=3)
```

<!-- core: stats/phon_stats.md:PhonStats 408ded2 -->
Фоностатистики текста: его звуки по классам, их кластеры, последовательности и повторы, его слоги. Звук - по умолчанию буква слова, а если библиотека дает транскрипцию, звук транскрипции. Источник данных - текст или объект `Doc` библиотеки [spaCy](https://github.com/explosion/spaCy); слова берутся в нижнем регистре, а явно переданный экстрактор применяется к тексту `Doc`.

Исключения:

- `SourceTypeError` - источник, который не строка и не `Doc`, экстрактор другого типа;
- `SourceError` - источник без слов;
- `ParameterError` - окно, которое не целое число не меньше 2.

Класс расширяет `PhonStats` ядра [anyTS](https://sergeyshk.github.io/anyTS/stats/phon_stats/) крючками русского языка: звуки - буквы слова по классам из таблицы ниже, без учета оглушения, редукции и ударения; йотированные е, ё, ю, я после гласной не дают зияния, а слова делятся на слоги по правилу восходящей звучности (Аванесов) функцией [`syllabify`](../syllables.md#syllabify). Из слов текста и `Doc` убираются знаки ударения, а части дефисного слова, разрезанного spaCy, склеиваются (`во-первых` - одно слово). Таблица `print_stats` и сообщения об ошибках - по-русски (`PHON_STATS_DESC` и `CORE_MESSAGES` из `ruts.constants`). Время вычисления растет линейно с длиной текста.

| Класс | Буквы | Константа |
| :---- | :---- | :-------- |
| Гласные | а, е, и, о, у, ы, э, ю, я, ё | `RU_VOWELS` |
| Сонорные согласные | л, м, н, р, й | `RU_CONSONANTS_SONOR`, `RU_CONSONANTS_YET` |
| Звонкие шумные согласные | б, в, г, д, ж, з | `RU_CONSONANTS_HIGH` |
| Глухие шумные согласные | к, п, с, т, ф, х, ц, ч, ш, щ | `RU_CONSONANTS_LOW` |
| Знаки | ь, ъ - не звуки: не учитываются в долях и не разрывают консонантный кластер | `RU_MARKS` |

=== "Код"

    ``` python
    from ruts import PhonStats

    text = "Ног нет, а хожу, рта нет, а скажу: когда спать, когда вставать, когда работу начинать"
    ps = PhonStats(text)
    ps.print_stats()
    ```

### Энтропия CV-шаблонов { #cv_entropy }

`cv_entropy`
{ .metric-meta }

<!-- core: stats/phon_stats.md:PhonStats-cv_entropy 8ca17ec -->
Энтропия Шеннона CV-шаблонов слов (`cv_pattern`) в битах, где $P(p)$ - доля слов с шаблоном $p$ среди слов, у которых шаблон есть.

$$
-\sum_{p} P(p) \log_2 P(p)
$$

``` {.python .signature}
calc_cv_entropy(text)
```

Энтропия CV-шаблонов списка слов: чем выше значение, тем разнообразнее фонетическая форма слов. Слова без гласных и согласных (числа, латиница) не учитываются, а без других слов значение - `nan`.

``` {.python .signature}
cv_pattern(word)
```

CV-шаблон слова или слога: гласные обозначаются буквой `V`, согласные - `C`, ь, ъ и остальные символы пропускаются.

| Параметр | Тип | По умолчанию | Описание |
| :------- | :-- | :----------- | :------- |
| `text` | `list[str]` | - | Список слов (`calc_cv_entropy`) |
| `word` | `str` | - | Слово или слог (`cv_pattern`) |

</div>

### Аллитерация и ассонанс { #repetition_index }

`alliteration` · `assonance`
{ .metric-meta }

``` {.python .signature}
calc_alliteration(text, window_len=3)
```

``` {.python .signature}
calc_assonance(text, window_len=3)
```

Индексы аллитерации и ассонанса списка слов - индекс повторов `calc_repetition_index` по согласным и по гласным буквам слов. Сравниваются буквы, а не звуки: оглушение, ударение и редукция не учитываются.

| Параметр | Тип | По умолчанию | Описание |
| :------- | :-- | :----------- | :------- |
| `text` | `list[str]` | - | Список слов |
| `window_len` | `int` | `3` | Окно в словах (`PHON_WINDOW_LEN`) |

<!-- core: stats/phon_stats.md:calc_repetition_index ea6ed82 -->
``` {.python .signature}
calc_repetition_index(words, window_len, features=None)
```

Индекс повторов: число окон из `window_len` соседних слов, в которых признак (буква или звук) встречается минимум в двух словах, в сумме по признакам, деленное на число, ожидаемое при случайном порядке слов. Окно перемешанных слов - выборка без возвращения, поэтому для признака, который есть в \(K\) из \(N\) слов, окно из \(w\) слов содержит его минимум в двух словах с гипергеометрической вероятностью

$$
P = 1 - \frac{\binom{N-K}{w} + K \binom{N-K}{w-1}}{\binom{N}{w}}
$$

а ожидаемое число - сумма этих вероятностей по признакам, умноженная на \(N - w + 1\) окон. Ожидаемое берется из самого текста, поэтому индекс показывает, собираются ли повторы в соседних словах, а не насколько частотен признак: в среднем по порядкам слов он равен 1 и заметно больше 1, когда повторы стоят ближе, чем при случайном порядке. Слово учитывает признак один раз; индекс равен `nan` для текста короче окна или без признака, общего для двух слов.

<!-- core: stats/phon_stats.md:calc_repetition_index-parameters 9e9f02b -->
| Параметр | Тип | По умолчанию | Описание |
| :------- | :-- | :----------- | :------- |
| `words` | `list[str]` / `list[list[str]]` | - | Признаки каждого слова: строка его букв или коллекция его звуков |
| `window_len` | `int` | - | Окно в словах, не меньше 2 |
| `features` | `Collection[str]` | `None` | Признаки для подсчета, по умолчанию все |

Слова, которые не список строк или коллекций строк, и признаки, которые не коллекция строк, дают `SourceTypeError`, а `window_len`, который не целое число не меньше 2, - `ParameterError`.

### Слоги { #syllables }

`p_open_syllables` · `mean_syllable_len`
{ .metric-meta }

<!-- core: stats/phon_stats.md:PhonStats-syllables 005a7e8 -->
Слоги - звуки каждого слога слова по `syllable_sounds`; слог без звука из классов (число) слогом не считается, в том числе в `c_syllable_patterns`. Открытый слог оканчивается на гласную по своему CV-шаблону (`cv_pattern`), а длина слога - число его звуков.

В ruTS длина слога - число его букв вместе с ь и ъ.

``` {.python .signature}
is_open_syllable(syllable)
```

Проверяет, является ли слог открытым - оканчивается на гласную; ь и ъ после гласной слог не закрывают.

| Параметр | Тип | По умолчанию | Описание |
| :------- | :-- | :----------- | :------- |
| `syllable` | `str` | - | Слог |

</div>

Функции ruTS принимают слова строками и считают по русским классам букв из таблицы выше. Функции `calc_*` проверяют аргументы: слова, которые не список строк, дают `SourceTypeError`, а окно, которое не целое число не меньше 2, - `ParameterError`.

=== "Код"

    ``` python
    from ruts.phon_stats import (
        calc_alliteration,
        calc_consonant_clusters,
        calc_cv_entropy,
        calc_hiatus,
        cv_pattern,
        is_open_syllable,
    )

    words = ["слышно", "бесшумно", "шуршат", "камыши", "у", "поэта"]
    cv_pattern("всплеск"), is_open_syllable("съе")
    calc_consonant_clusters(words)
    calc_hiatus(words), calc_cv_entropy(words)
    calc_alliteration(words, window_len=2)
    ```

=== "Результат"

    ```
    ('CCCCVCC', True)
    {1: 8, 2: 5}
    (1, 2.584962500721156)
    1.4999999999999998
    ```

## Методы

<!-- core: stats/stats.md:Stats-get_stats d388cfa -->
`get_stats(flat=False)` возвращает копию статистик из `stat_names`: ее изменение не меняет объект. С `flat=True` значения статистики-словаря становятся отдельными ключами, присоединенными к ее имени через подчеркивание: распределение `{3: 5}` статистики `c_lengths` дает ключ `c_lengths_3`.

<!-- core: stats/stats.md:Stats-to_dataframe fb70c9b -->
`to_dataframe()` возвращает плоские статистики, `get_stats(flat=True)`, таблицей `DataFrame` библиотеки [pandas](https://pandas.pydata.org/) из одной строки со столбцом на каждый ключ. Статистика-словарь дает столбцы только для ключей, которые есть в тексте, поэтому в таблицах нескольких текстов, объединенных `pandas.concat`, отсутствующее у текста количество равно `NaN`. Только такие столбцы можно заполнять нулями: в остальных `NaN` - неопределенное значение.

<!-- core: stats/stats.md:Stats-print_stats b37b79d -->
`print_stats()` выводит таблицу статистик из `stats_desc` с их описаниями под заголовками из `stats_headers`, дробные числа - с двумя знаками после запятой; каждый столбец шириной в свой самый длинный текст.

<!-- core: stats/stats.md:Stats-describe d0ce257 -->
`describe(stat)` возвращает полосу шкалы статистики `stat` (`level_scale`) и `None` для статистики без шкалы, с неопределенным значением (nan) или для ключа плоских статистик (`get_stats(flat=True)`). Имя, которого нет ни в `stat_names`, ни среди открытых свойств класса, дает `UnknownStatError`.

Шкал у фоностатистик нет, поэтому `describe` всегда возвращает `None`.
