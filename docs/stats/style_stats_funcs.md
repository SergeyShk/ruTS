# Функции вычисления метрик

Нормы сервисов для метрик приведены в разделе [норм сервисов](style_stats.md#norms).

## Классическая тошнота { #calc_classic_nausea }

!!! info ""
    **ruts.style_stats.calc_classic_nausea()**

<!-- core: stats/style_stats_funcs.md:calc_classic_nausea b61d075 -->
Вычисление классической тошноты (Advego): насколько навязчиво повторяется одно слово. Без поправки на длину текста она растет вместе с текстом; пустой список слов дает 0.

Формула:

$$
\sqrt{f_1}
$$

где $f_1$ - количество вхождений самого частого слова.

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `text` | list[str] | `-` | Список слов |

## Академическая тошнота { #calc_academic_nausea }

!!! info ""
    **ruts.style_stats.calc_academic_nausea()**

Вычисление академической тошноты (Advego): доли вхождений самых частых значимых слов ([`find_nausea_words`](#find_nausea_words)) среди всех слов в процентах.

Формула:

$$
100 \cdot \frac{\sum_{w \in \textrm{top}_n} f_w}{\textrm{Количество слов}}
$$

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `text` | list[str] | `-` | Список слов |
| `top_n` | int | `10` | Количество самых частых слов |
| `stopwords` | list[str] | `None` | Стоп-слова; без них решает [`is_stopword`](#is_stopword) |

## Слова академической тошноты { #find_nausea_words }

!!! info ""
    **ruts.style_stats.find_nausea_words()**

`top_n` самых частых слов без стоп-слов с числом вхождений, начиная с самого частого. Стоп-слово - слово из `stopwords` без учета регистра и буквы ё или, без списка, слово [`is_stopword`](#is_stopword).

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `text` | list[str] | `-` | Список слов |
| `top_n` | int | `10` | Количество самых частых слов |
| `stopwords` | list[str] | `None` | Стоп-слова |

!!! example "Пример"

    ``` python
    from ruts.style_stats import find_nausea_words

    find_nausea_words(["кот", "и", "кот", "и", "пес"], top_n=1)
    # {'кот': 2}
    ```

## Водность { #calc_water }

!!! info ""
    **ruts.style_stats.calc_water()**

Вычисление водности (Text.ru): доли слов без содержания в процентах - слов из `stopwords` без учета регистра и буквы ё или, без списка, слов [`is_water_word`](#is_water_word). «Вода» Advego - другой показатель, здесь он не реализован.

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `text` | list[str] | `-` | Список слов |

## Слово воды { #is_water_word }

!!! info ""
    **ruts.style_stats.is_water_word()**

Проверка, является ли слово «водой» по части речи, - для [водности](#calc_water) и слоя `stopwords` подсветки: союзы, частицы, местоимения-существительные и междометия по разметке pymorphy3 (`CONJ`, `PRCL`, `NPRO`, `INTJ`; набор `ruts.constants.WATER_POS`). Вводные слова «конечно» и «например» pymorphy3 относит к союзам, поэтому они тоже «вода». Предлоги, местоименные прилагательные и предикативы, в отличие от [`is_stopword`](#is_stopword), водой не считаются.

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `word` | str | `-` | Слово |

## Стоп-слово { #is_stopword }

!!! info ""
    **ruts.style_stats.is_stopword()**

Проверка, является ли слово стоп-словом по части речи - незначимым для [академической тошноты](#calc_academic_nausea): союзы, частицы, предлоги, местоимения-существительные, междометия и предикативы (`CONJ`, `PRCL`, `PREP`, `NPRO`, `INTJ`, `PRED`) и слова с граммемами `Apro`, `Prnt`, `Dmns`, `Ques` - местоименные прилагательные, вводные слова, указательные и вопросительные наречия - по разметке pymorphy3; наборы - `ruts.constants.STOPWORD_POS` и `ruts.constants.STOPWORD_GRAMMEMES`.

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `word` | str | `-` | Слово |

## Заспамленность { #calc_spam }

!!! info ""
    **ruts.style_stats.calc_spam()**

<!-- core: stats/style_stats_funcs.md:calc_spam 03399fe -->
Вычисление заспамленности (Text.ru): доли повторов слов в процентах - каждого вхождения слова после первого.

Формула:

$$
100 \cdot \left(1 - \frac{\textrm{Количество лексем}}{\textrm{Количество слов}}\right)
$$

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `text` | list[str] | `-` | Список слов |

## Естественность по Ципфу { #calc_zipf_naturalness }

!!! info ""
    **ruts.style_stats.calc_zipf_naturalness()**

Вычисление естественности по [закону Ципфа](https://en.wikipedia.org/wiki/Zipf's_law) (pr-cy, megaindex): согласия частот самых частых слов с идеальным распределением $f_r = f_1 / r$, где $f_1$ - частота самого частого слова, $r$ - ранг. Ранги берутся от 2 до $R = \min(\textrm{top}_n, V, f_1)$, где $V$ - количество лексем; отрицательные значения обрезаются до 0, а без рангов для сравнения - все слова гапаксы, одна лексема или `top_n` меньше 2 - значение равно `nan`.

Формула:

$$
100 \cdot \left(1 - \frac{1}{R - 1} \sum_{r=2}^{R} \frac{|r \cdot f_r - f_1|}{f_1}\right)
$$

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `text` | list[str] | `-` | Список слов |
| `top_n` | int | `10` | Количество самых частых слов |

## Плотность ключевых слов { #calc_keyword_density }

!!! info ""
    **ruts.style_stats.calc_keyword_density()**

Вычисление плотности ключевых слов (Text.ru): количества вхождений каждого ключевого слова на 100 слов. Ключевое слово из нескольких слов через пробел - последовательность слов, вхождения которой могут пересекаться; слова и ключевые слова сравниваются в нижнем регистре без буквы ё, как стоп-слова и словосочетания, ключевые слова из множества идут в отсортированном порядке. Так же считает метод `keyword_density` класса `StyleStats`.

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `text` | list[str] | `-` | Список слов |
| `keywords` | list[str] | `-` | Ключевые слова или фразы |

## Отглагольные существительные { #calc_verbal_nouns }

!!! info ""
    **ruts.style_stats.calc_verbal_nouns()**, **ruts.style_stats.find_verbal_nouns()**

Вычисление доли отглагольных существительных среди существительных (по первому разбору pymorphy3) в процентах; `nan` для текста без существительных. Существительное отглагольное, если его лемма оканчивается на суффикс из `VERBAL_NOUN_SUFFIXES` (-ние, -нье, -тие, -тье, -ствие, -ция) или входит в `VERBAL_NOUN_LEMMAS` (производство, руководство, строительство) - функция `ruts.utils.is_verbal_noun`; эвристика захватывает и неотглагольные слова с теми же суффиксами (здание). Функция `find_verbal_nouns` возвращает границы найденных слов как срезы списка.

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `text` | list[str] | `-` | Список слов |

## Плотность словосочетаний { #calc_phrase_density }

!!! info ""
    **ruts.style_stats.calc_phrase_density()**, **ruts.style_stats.expand_phrases()**

Вычисление числа вхождений словосочетаний из списка на 100 слов. Словосочетания сравниваются без учета регистра и буквы ё, а словосочетание, начинающееся с инфинитива, в том числе после «не», находится в любой форме своего глагола, включая причастия и деепричастия («имело место», «доведено до сведения»): эти варианты из текста, каждый со своим словосочетанием, добавляет функция `expand_phrases`. Так `StyleStats` считает по словоформам (`forms`) производные предлоги из `COMPOUND_PREPOSITIONS` (в целях, в связи с, в рамках, за счет) и штампы из `OFFICIALESE_CLICHES` (на сегодняшний день, в настоящее время, иметь место) или из параметра `cliches`.

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `text` | list[str] | `-` | Список слов |
| `phrases` | list[str] | `-` | Словосочетания через пробел |

## Вводные слова { #calc_parentheticals }

!!! info ""
    **ruts.style_stats.calc_parentheticals()**, **ruts.style_stats.find_parentheticals()**, **ruts.style_stats.is_parenthetical()**

Вычисление числа вводных слов на 100 слов: словосочетания из `PARENTHETICALS` (таким образом, как правило, в частности, кроме того) и вне их одиночные слова с граммемой `Prnt` pymorphy3 (конечно, например, впрочем; функция `is_parenthetical`). Функция `find_parentheticals` возвращает границы найденных слов и словосочетаний как срезы списка.

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `text` | list[str] | `-` | Список слов |
