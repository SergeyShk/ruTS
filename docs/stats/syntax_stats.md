# Синтаксические статистики

``` {.python .signature}
SyntaxStats(source)
```

<!-- core: stats/syntax_stats.md:SyntaxStats 7110140 -->
Синтаксические статистики текста по его дереву зависимостей ([Иванов, Солнышкина и Соловьёв 2018](https://dialogue-conf.org/media/4302/ivanovvv.pdf)): показатели дерева и синтаксических конструкций. Источник данных - объект `Doc` библиотеки [spaCy](https://github.com/explosion/spaCy) с разбором зависимостей и частями речи. Знаки препинания, символы и пробелы узлами дерева не являются, а длины считаются в позициях слов. Единицы L2SCA, предложные цепочки и схожесть предложений вычисляются при первом обращении, поэтому подкласс, в `stats_desc` которого их нет, не тратит на них время.

Исключения:

- `SourceTypeError` - источник, который не `Doc`;
- `SourceError` - источник без разбора зависимостей (отношений и границ предложений), без частей речи, без лемм, если класс их требует, или без слов.

Класс расширяет `SyntaxStats` ядра [anyTS](https://sergeyshk.github.io/anyTS/stats/syntax_stats/) русским слоем. Отношения и признаки берутся из разметки [Universal Dependencies](https://universaldependencies.org/u/dep/) моделей `ru_core_news_sm`, `ru_core_news_md` и `ru_core_news_lg`; качество статистик ограничено качеством разбора: маленькая модель `ru_core_news_sm` ошибается в частях речи и связях заметно чаще, чем `ru_core_news_lg`. Части дефисного слова, разрезанного spaCy, склеиваются (`во-первых` - одно слово), а клаузы, причастные обороты, отрицания и расщепленные сказуемые определяются по правилам русского языка из карточек метрик. ruTS добавляет свои метрики цепочек родительных падежей и деепричастных оборотов. Синтаксические маркеры канцелярита - пассив, причастные обороты, цепочки родительных падежей, расщепленные сказуемые и отношение существительных к глаголам. Таблица `print_stats` и сообщения об ошибках - по-русски (`SYNTAX_STATS_DESC` и `CORE_MESSAGES` из `ruts.constants`).

Иванов, Солнышкина и Соловьёв проверили признаки на корпусе школьных учебников: число сочинительных цепочек, причастных оборотов и модификаторов именной группы коррелирует с классом учебника на уровне 0.88-0.93. Карточки метрик называют исходные признаки работы и их коэффициенты корреляции с классом учебника.

=== "Код"

    ``` python
    import spacy
    from ruts import SyntaxStats

    nlp = spacy.load("ru_core_news_sm")
    text = "Дом, построенный рабочими в прошлом году, был продан. Хлопнув дверью, он ушел и сказал, что не придет."
    ss = SyntaxStats(nlp(text))
    ss.print_stats()
    ```

## Метрики

<!-- core: stats/syntax_stats.md:SyntaxStats-metrics 16994fb -->
Каждая метрика - атрибут объекта, который вычисляется при его создании (единицы L2SCA, предложные цепочки и схожесть предложений - при первом обращении), а `get_stats` дает их все. Показатели предложения (наибольшая длина зависимости, глубина, число слов на лист) усредняются по предложениям, конструкции даются на предложение.

### Длина зависимости { #dependency_distances }

`mean_dependency_distance` · `std_dependency_distance` · `max_dependency_distance` · `p_adjacent_dependencies`
{ .metric-meta }

<!-- core: stats/syntax_stats.md:calc_dependency_distances ccf4d91 -->
``` {.python .signature}
calc_dependency_distances(tokens, join_hyphens=False)
```

Длины зависимостей (Liu 2008): расстояние между словом и его вершиной в позициях слов без учета знаков препинания, в порядке слов. Вершина предложения и слово, вершина которого лежит вне последовательности, пропускаются.

| Параметр | Тип | По умолчанию | Описание |
| :------- | :-- | :----------- | :------- |
| `tokens` | `Doc` / `Span` / `list[Token]` | - | Последовательность токенов |
| `join_hyphens` | `bool` | `False` | Считать дефисное слово одной позицией |

Средняя длина зависимости растет с длиной предложения, а наибольшая - лучший из древесных признаков на уровне отдельного предложения. Предложения из одного слова в метрики длин не входят.

=== "Код"

    ``` python
    import spacy
    from ruts.syntax_stats import calc_dependency_distances

    nlp = spacy.load("ru_core_news_sm")
    doc = nlp("Повышение эффективности использования ресурсов предприятия обсуждалось на совещании.")
    calc_dependency_distances(doc)
    ```

=== "Результат"

    ```
    [5, 1, 1, 1, 1, 1, 2]
    ```

### Глубина дерева { #tree_depth }

`tree_depth`
{ .metric-meta }

<!-- core: stats/syntax_stats.md:calc_tree_depth 8fdd05e -->
``` {.python .signature}
calc_tree_depth(tokens, join_hyphens=False)
```

Глубина дерева зависимостей: самый длинный путь от вершины предложения до листа в связях между словами; для нескольких предложений - максимум, для предложения из одного слова - 0. С `join_hyphens` дефисное слово - одно слово, а слова, которые висят на любой из его частей, - на уровень ниже него.

| `join_hyphens` | `bool` | `False` | Считать дефисное слово одним словом |

Глубина - признак `LONGEST_PATH` работы Иванова и др. (r = 0.84).

### Листья и поддеревья { #leaves }

`leaves_per_sent` · `subtrees_per_sent` · `nodes_per_leaf`
{ .metric-meta }

<!-- core: stats/syntax_stats.md:SyntaxStats-leaves 0162a04 -->
Лист - слово без зависимых слов (`count_children`), поддерево - слово с ними. Число узлов на лист - количество слов предложения, деленное на количество его листьев, в среднем по $S$ предложениям.

$$
\frac{1}{S} \sum_{s=1}^{S} \frac{\textrm{Количество слов } s}{\textrm{Количество листьев } s}
$$

Признаки работы: `LEAVES_NUMBER` (r = 0.84), `PATH_NUMBER` (r = 0.87) и `AVERAGE_PATH` (r = 0.84). Распределение слов по числу зависимых - профиль ветвления - дает атрибут `c_children`.

### Сочинительные цепочки { #coordination_chains }

`coordination_chains_per_sent` · `mean_coordination_chain_len`
{ .metric-meta }

<!-- core: stats/syntax_stats.md:calc_coordination_chains 1f94356 -->
``` {.python .signature}
calc_coordination_chains(tokens, join_hyphens=False)
```

Длины сочинительных цепочек в порядке их первых слов. Цепочка - группа слов, связанных `conj`, к какому бы слову ни присоединялся каждый однородный член: Universal Dependencies вешает каждый однородный член на первый (`груши → яблоки`, `сливы → яблоки`), ClearNLP - на предыдущий (`груши → яблоки`, `сливы → груши`); в обоих случаях `яблоки, груши и сливы` - одна цепочка из трех слов. Вложенное сочинение (`кошки и собаки, или птицы`) и перечисление, разбитое между несколькими вершинами, - тоже одна цепочка. С `join_hyphens` дефисное слово - один однородный член, связанный отношением `conj` любой своей части (`членом совета и вице-губернатором` - цепочка из двух слов).

| `join_hyphens` | `bool` | `False` | Считать дефисное слово одним словом |

Число цепочек на предложение (`SOCHIN_NUMBER`, r = 0.93) и их средняя длина (`AVERAGE_SOCHIN_LENGTH`, r = 0.87) - сильнейшие синтаксические предикторы сложности учебника.

### Клаузы { #clauses }

`clauses_per_sent` · `mean_clause_len`
{ .metric-meta }

``` {.python .signature}
is_clause_head(token)
```

Проверяет, возглавляет ли слово клаузу: вершина предложения или слово со связью `ccomp`, `advcl`, `acl`, `csubj`, `parataxis` и их подтипами (`anyts.constants.CLAUSE_DEPS`), кроме полных причастий, деепричастий и инфинитивов при существительном («желание уйти»): причастные и деепричастные обороты считаются отдельно, а краткое причастие («дом построен») - сказуемое своей клаузы. Со связью `xcomp` клаузу возглавляет только инфинитив `is_infinitive_clause`: личная форма со связью `xcomp` у русских моделей - ошибка разбора. Вставная конструкция (`parataxis`) и однородное сказуемое (связь `conj` от вершины клаузы) образуют свою клаузу, только если могут быть сказуемым ([`is_predicate`](#is_predicate)): «Он сказал: „Уходи“» и «думала, что он умен» - клаузы, а вводные слова «например», «конечно», «во-первых», на которые модели spaCy тоже вешают `parataxis`, - нет.

``` {.python .signature}
is_infinitive_clause(token)
```


Проверяет, образует ли инфинитив одну предикацию со своей вершиной: модальным или фазовым глаголом или модальным словом из `INFINITIVE_PERIPHRASES` («может уйти», «должен прийти», «начал читать», «взялся читать», «перестал курить», «пришлось уйти», «стоит отметить», «нужно уйти», «можно войти», «невозможно описать», «пора идти»), краткой формой модального прилагательного из `MODAL_SHORT_ADJECTIVES` («готов уйти», «рад помочь») или побудительным «давай», «давайте» из `HORTATIVE_WORDS` без отрицания («давайте играть», но не «не давайте детям играть»).

### Единицы L2SCA { #l2sca }

`t_units_per_sent` · `mean_t_unit_len` · `clauses_per_t_unit` · `p_complex_t_units` · `verb_phrases_per_t_unit` · `coordinate_phrases_per_clause` · `complex_nominals_per_clause` · [Lu 2010](https://doi.org/10.1075/ijcl.15.4.02lu)
{ .metric-meta }

<!-- core: stats/syntax_stats.md:SyntaxStats-l2sca 74e1d24 -->
Индексы L2 Syntactic Complexity Analyzer (L2SCA), которых нет среди других метрик, по разметке Universal Dependencies. MLC и C/S - это `mean_clause_len` и `clauses_per_sent`; MLS и DC/C получаются из счетчиков: `n_words / n_sents` и `n_subordinate_clauses / n_clauses`.

- T-единица - главная клауза с зависящими от нее клаузами: вершина предложения и каждая вершина клаузы, присоединенная к ней через `conj` или `parataxis` (`anyts.constants.MAIN_CLAUSE_DEPS`), поэтому в *я пришел, а он ушел* их две; однородный член придаточной клаузы T-единицей не является. Однородный член без собственного подлежащего (*я пришел и ушел*) - сказуемое, которое делит T-единицу с клаузой, с которой оно сочинено, как в L2SCA, если только его лицо, число или род - его вспомогательного глагола или связки, а без них собственные - не отличаются от лица, числа или рода этой клаузы: в языке, опускающем подлежащее, окончание называет другое подлежащее (*llegamos al puerto y nos esperabas*). Экзистенциальное *there* (`expl` ClearNLP) - подлежащее. Однородный член или вставная конструкция с подчинительным союзом (`subordinating_marks`) возглавляет придаточную или инфинитивную клаузу, которая T-единицей не является, как и клауза под ней. T-единица сложная, если в ней есть придаточная клауза (`is_subordinate_clause_head`), для которой она - ближайшая T-единица сверху.
- Глагольная группа - сказуемое (`is_predicate`), которое не является вспомогательным глаголом или связкой: глагол, вспомогательный глагол в роли сказуемого (*there **is** trouble*), слово с подлежащим или со связкой; инфинитив, который образует одно сказуемое со своей вершиной (`is_infinitive_periphrasis`), и однородный ему инфинитив входят в глагольную группу вершины. Причастие или другая неличная форма со связью `amod` или `acl` либо однородная ей, без вспомогательного глагола, связки и собственного подлежащего, - определение своего существительного (*дом, построенный рабочими*), как в L2SCA, а не глагольная группа.
- Сочиненная группа - сочинение с однородным членом, который не является вершиной клаузы (*мужчина и женщина*, *был большим и красивым*) или является сказуемым без собственного подлежащего (*пришел и ушел*); она считается один раз, по первому однородному члену, а сочинение клауз с собственными подлежащими считается клаузами.
- Клаузы C/T, CP/C и CN/C - клаузы L2SCA (`n_l2sca_clauses`): клаузы `is_clause_head` без сказуемых с общим подлежащим (*пришел и ушел*) и без инфинитивных клауз, поскольку L2SCA считает финитные клаузы с подлежащим. C/S и MLC считаются по клаузам других метрик, поэтому C/S выше, а MLC ниже, чем в L2SCA.
- Сложная именная группа - существительное с модификатором из `anyts.constants.COMPLEX_NOMINAL_DEPS` (прилагательным, дополнением, определительной придаточной клаузой или причастным оборотом, приложением, притяжательным словом) или именная клауза - вершина клаузы из `anyts.constants.NOMINAL_CLAUSE_DEPS` или однородный ей член.

$$
\textrm{MLT} = \frac{\textrm{Слова}}{\textrm{T-единицы}}, \quad
\textrm{C/T} = \frac{\textrm{Клаузы L2SCA}}{\textrm{T-единицы}}, \quad
\textrm{CT/T} = \frac{\textrm{Сложные T-единицы}}{\textrm{T-единицы}}, \quad
\textrm{CN/C} = \frac{\textrm{Сложные именные группы}}{\textrm{Клаузы L2SCA}}
$$

Проверяет, есть ли у слова агенс: зависимое `obl:agent` или `agent` ClearNLP (`AGENT_DEPS`). Аргументы и ошибка - те же, что у `is_passive`.

<!-- core: stats/syntax_stats.md:is_agentless 2194d44 -->
``` {.python .signature}
is_agentless(token, join_hyphens=False)
```

Проверяет, является ли слово пассивной формой (`is_passive`) без агенса (`has_agent`), с теми же аргументами и ошибкой.

В русском языке пассив - страдательные причастия и возвратный пассив («обсуждалось»), форма без агенса - «дом построен», но не «дом построен рабочими».

### Инфинитивы, отрицания и расщепленные сказуемые { #constructions }

`infinitives_per_sent` · `negations_per_sent` · `split_predicates_per_sent`
{ .metric-meta }

<!-- core: stats/syntax_stats.md:SyntaxStats-constructions 4d8a10f -->
Инфинитивы (`is_infinitive` из `anyts.utils`), слова отрицания крючка `is_negation` и расщепленные сказуемые крючка `find_split_predicates` на предложение.

``` {.python .signature}
is_negation(token)
```

Проверяет, является ли слово отрицательной частицей - частицей (`PART`) с признаком `Polarity=Neg` или частицей «не», «ни» (`NEGATION_PARTICLES`); союз «ни» в конструкции «ни… ни» отрицанием не считается. Отрицания - признак `NEG` работы (r = 0.70).

``` {.python .signature}

```

``` {.python .signature}
is_light_verb(token)
```

``` {.python .signature}
is_reflexive(token)
```

``` {.python .signature}
is_split_predicate_noun(token, verb=None)
```

Расщепленные сказуемые - маркер канцелярита - пары глагола и существительного в порядке слов: легкий глагол (`is_light_verb`) с леммой из `LIGHT_VERBS` (например: осуществлять, производить, проводить, вести, обеспечивать, оказывать, принимать, иметь и их возвратный пассив проводиться, приниматься, вестись) с именной частью (`is_split_predicate_noun`) - существительным с отглагольной леммой (`ruts.utils.is_verbal_noun`) или леммой из `SPLIT_PREDICATE_NOUNS` (например: роль, работа, помощь, мера) при глаголе своего оборота `verb` (оказать помощь, принять меры, но не получить работу): осуществлять проверку, оказать помощь, принято решение, проверка проводится. У глагола берется не больше одной именной части в порядке предпочтения `obj`, `nsubj:pass`, `nsubj` (только у возвратного или пассивного глагола, `is_reflexive`), `iobj`, `nmod`, `obl`; предложные обстоятельства и агенс пассива (`obl:agent`, творительный `obl`) не учитываются. Лемма глагола берется из разбора pymorphy3 дважды: с частью речи токена ([`get_lemma`](#helpers)) и как глагола (`ruts.utils.lemmatize`).

| :------- | :-- | :----------- | :------- |
| `token` | `Token` | - | Токен |
| `tokens` | `Doc` / `Span` / `list[Token]` | - | Последовательность токенов (`find_split_predicates`) |
| `verb` | `Token` | `None` | Легкий глагол (`is_split_predicate_noun`); без него оборот не проверяется |

    ``` python
    find_split_predicates(doc)
    [token.text for token in doc if is_negation(token)]
    ```

### Схожесть соседних предложений { #similarity }

`pos_edit_distance` · `syntax_similarity` · [Coh-Metrix](https://doi.org/10.1017/CBO9780511894664)
{ .metric-meta }

<!-- core: stats/syntax_stats.md:SyntaxStats-similarity 1dc6e39 -->
Насколько схожи структуры двух соседних предложений, в среднем по $S - 1$ парам. `pos_edit_distance` - редакционное расстояние частей речи $P_s$ слов предложений (SYNMEDpos Coh-Metrix), деленное на длину $n$ более длинного предложения пары, `calc_edit_distance`. `syntax_similarity` - схожесть мультимножеств троек зависимостей $T$ двух предложений (`dependency_triples`, `calc_multiset_similarity`) по образцу SYNSTRUT Coh-Metrix, который сравнивает узлы деревьев составляющих. Ни та, ни другая мера не видит порядка слов, а схожесть троек растет с длиной предложений.

$$
\frac{1}{S - 1} \sum_{s=1}^{S-1} \frac{\textrm{lev}(P_s, P_{s+1})}{\max(n_s, n_{s+1})}, \quad
\frac{1}{S - 1} \sum_{s=1}^{S-1} \frac{|T_s \cap T_{s+1}|}{|T_s \cup T_{s+1}|}
$$

## Дефисные слова { #hyphenated-words }

<!-- core: stats/syntax_stats.md:hyphenated_words 2598bfe -->
Токенизатор может разрезать слово по дефисам (`во-первых` на `во`, `-`, `первых`), и тогда парсер вешает каждую часть на свою вершину. С `join_hyphens=True` функции дерева считают одним словом вместе с дефисами слово, части которого склеивает `anyts.utils.joins_previous`. У слова, которое держит вершину предложения, вершины нет; вершина другого слова - вершина его части, которая висит вне слова и ближе всех к корню (при равенстве - слова, а не дефиса). Зависимые слова - слова, чья часть, висящая вне слова, висит на одном из его токенов; каждое представлено этой частью (или своей первой частью, если наружу висит дефис). Поддерево слова - само слово и слова, которые висят на нем прямо или через знаки препинания. Так у каждого слова одна зависимость, и зависит оно от одного слова.

`SyntaxStats` и функции русских конструкций всегда склеивают дефисные слова. Функции ядра, в том числе `is_predicate`, `count_noun_modifiers`, `is_passive`, `has_agent` и `is_agentless`, по умолчанию принимают `join_hyphens=False`: значения `SyntaxStats` они дают с `join_hyphens=True`.

## Цепочки модификаторов { #calc_modifier_chains }

<!-- core: stats/syntax_stats.md:calc_modifier_chains f16f96d -->

``` {.python .signature}
calc_multiset_similarity(sents)
```

Средняя схожесть мультимножеств элементов соседних предложений: взвешенный коэффициент Жаккара каждых двух - общие элементы, каждый столько раз, сколько он встречается в предложении, где его меньше, деленные на элементы обоих, каждый столько раз, сколько он встречается в предложении, где его больше, - 1 для одинаковых мультимножеств и для двух пустых, 0 для непересекающихся; `nan`, если предложений меньше двух. Отображение читается по ключам, как множество.

| Параметр | Тип | По умолчанию | Описание |
| :------- | :-- | :----------- | :------- |
| `sents` | `list[list]` | - | Элементы каждого предложения, например его тройки зависимостей |

Предложения, которые не список коллекций, или элементы, которые нельзя хешировать, дают `SourceTypeError`.
