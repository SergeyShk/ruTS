# Функции вычисления статистик

Функции повторов принимают множества или списки лемм каждого предложения в порядке текста; какие леммы попадают в множества (существительные, аргументы, знаменательные слова), решает класс `CohesionStats` по признакам слова [`WordInfo`](#word_info): для строки их дает `word_info` по разбору pymorphy3 с функциями [`is_pronoun`](#is_pronoun) и [`is_content_word`](#is_content_word), для `Doc` с разметкой - `token_info` по частям речи UD. В скобках указаны названия соответствующих индексов [Coh-Metrix](https://doi.org/10.1017/CBO9780511894664).

## Бинарный повтор { #calc_overlap }

!!! info ""
    **ruts.cohesion_stats.calc_overlap()**

Вычисление доли пар предложений с общим элементом. Пара предложений считается связанной, если у них есть хотя бы один общий элемент - лемма существительного (`CRFNO1`, `CRFNOa`), аргумента (`CRFAO1`, `CRFAOa`) или знаменательного слова (`CRFSO1`, `CRFSOa`). По умолчанию считаются пары соседних предложений (локальная связность), при `adjacent=False` - все пары предложений текста (глобальная связность). Для текста короче двух предложений возвращается `nan`. Класс `CohesionStats` считает по этой функции `noun_overlap_*`, `argument_overlap_*` и `content_overlap_*`.

Формула:

$$
\frac{|\{(i, j): S_i \cap S_j \neq \varnothing\}|}{|\{(i, j)\}|}
$$

где $S_i$ - множество лемм предложения $i$, пары $(i, j)$ - соседние или все.

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `sets` | list[set[str]] | `-` | Множества элементов каждого предложения |
| `adjacent` | bool | `True` | Считать только соседние пары, иначе все пары |

!!! example "Пример"

    ``` python
    from ruts.cohesion_stats import calc_overlap

    sets = [{"кот", "окно"}, {"птица"}, {"птица", "кот"}, {"окно"}]
    calc_overlap(sets)
    # 0.3333333333333333
    calc_overlap(sets, adjacent=False)
    # 0.5
    ```

## Пропорциональный повтор { #calc_proportional_overlap }

!!! info ""
    **ruts.cohesion_stats.calc_proportional_overlap()**

Вычисление средней доли общих элементов в парах предложений (`CRFCWO1`, `CRFCWOa`). Для пары предложений считается коэффициент Дайса множеств лемм, пара без элементов получает 0; результат усредняется по соседним или всем парам. В отличие от бинарного повтора учитывает, какая часть слов предложений повторяется: два общих слова в коротких предложениях дают больше, чем в длинных. Класс `CohesionStats` считает по этой функции `content_overlap_prop_adjacent` и `content_overlap_prop_all`.

Формула:

$$
\frac{1}{|\{(i, j)\}|} \sum_{(i, j)} \frac{2 \cdot |S_i \cap S_j|}{|S_i| + |S_j|}
$$

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `sets` | list[set[str]] | `-` | Множества элементов каждого предложения |
| `adjacent` | bool | `True` | Считать только соседние пары, иначе все пары |

## Все повторы за один расчет { #calc_overlaps }

!!! info ""
    **ruts.cohesion_stats.calc_overlaps()**, **ruts.cohesion_stats.dice()**, **ruts.cohesion_stats.Overlap**

Вычисление бинарного и пропорционального повторов по соседним и всем парам предложений сразу; возвращает именованный кортеж `Overlap(adjacent, all, prop_adjacent, prop_all)` с теми же значениями, что дают [`calc_overlap`](#calc_overlap) и [`calc_proportional_overlap`](#calc_proportional_overlap). Класс `CohesionStats` считает все повторы этой функцией. Соседние пары обходятся напрямую; число всех пар с общим элементом считается по битовым маскам вхождений элементов в предложения (блоками по 4096 предложений, чтобы ограничить память), а сумма коэффициентов Дайса по всем парам - по гистограммам длин предложений для каждого элемента: пара предложений длин $k$ и $l$ дает $2/(k+l)$ за каждый общий элемент, и сумма по парам внутри элемента равна $(h W h - h \cdot \mathrm{diag}(W)) / 2$, где $h$ - гистограмма длин, $W_{kl} = 2/(k+l)$. Время растет линейно с числом вхождений, а не квадратично с числом предложений: 6000 предложений считаются за доли секунды. Функция `dice` считает коэффициент Дайса двух множеств.

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `sets` | list[set[str]] | `-` | Множества элементов каждого предложения |

## Данность { #count_given }

!!! info ""
    **ruts.cohesion_stats.count_given()**

Вычисление количества данных элементов - уже встречавшихся ранее в тексте. Элемент считается данным (given), если та же лемма встречалась раньше в любом предложении, включая текущее; первое вхождение - новое. Класс `CohesionStats` делит количество данных знаменательных слов на их общее число (`p_given`): чем выше доля, тем больше текст опирается на уже введенные понятия. Другие показатели данности - доля местоимений `p_pronouns`, отношение местоимений к существительным `pronoun_noun_ratio` и доля указательных `p_demonstratives` - считаются по счетчикам класса.

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `sents` | list[list[str]] | `-` | Леммы каждого предложения в порядке текста |

## Повтор времени и вида { #calc_repetition }

!!! info ""
    **ruts.cohesion_stats.calc_repetition()**, **ruts.cohesion_stats.dominant()**

Вычисление доли пар соседних предложений с одинаковым преобладающим значением признака глаголов - времени (`past`, `pres`, `futr`) или вида (`perf`, `impf`) по разметке pymorphy3. Для каждого предложения функция `dominant` берет самое частое значение (при равенстве - встретившееся первым), пара соседних предложений считается согласованной при совпадении; пары, где хотя бы у одного предложения нет глаголов с признаком, пропускаются, при отсутствии таких пар возвращается `nan`. Класс `CohesionStats` считает `tense_repetition` и `aspect_repetition`, а их среднее выдает как темпоральную связность `temporal_cohesion` (`SMTEMP`).

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `sents` | list[list[str]] | `-` | Значения признака глаголов каждого предложения |

## Признаки слова { #word_info }

!!! info ""
    **ruts.cohesion_stats.word_info()**, **ruts.cohesion_stats.token_info()**, **ruts.cohesion_stats.WordInfo**

Получение признаков слова, нужных для статистик связности: лемма в нижнем регистре, является ли слово существительным, местоимением, аргументом (существительным или местоимением-существительным) и знаменательным словом, время и вид глагольной формы. `word_info` берет их из первого разбора pymorphy3 (лемма `normal_form`, части речи OpenCorpora, граммемы времени и вида), `token_info` - из разметки spaCy (`token.lemma_`, `token.pos_`, признаки `Tense` и `Aspect`): существительные - `NOUN` и `PROPN`, местоимения - `PRON` и `DET`, знаменательные слова - `CONTENT_UD_POS`. Слова с леммой из `DEMONSTRATIVE_LEMMAS` в обоих случаях считаются указательными местоимениями и не считаются знаменательными. Если у токена нет леммы (пайплайн без лемматизатора), она берется из разбора pymorphy3 с той же частью речи - `ruts.utils.lemmatize`. Результат - именованный кортеж `WordInfo`.

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `word` / `token` | str / Token | `-` | Слово или токен spaCy |

## Местоимение { #is_pronoun }

!!! info ""
    **ruts.cohesion_stats.is_pronoun()**

Проверка, является ли слово местоимением: местоимения-существительные (`NPRO`: он, себя, кто, это) и местоименные прилагательные (`Apro`: этот, который, мой, весь, каждый) по разметке pymorphy3.

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `word` | str | `-` | Слово |

## Знаменательное слово { #is_content_word }

!!! info ""
    **ruts.cohesion_stats.is_content_word()**

Проверка, является ли слово знаменательным: существительные, прилагательные, глаголы во всех формах (включая инфинитивы, причастия и деепричастия) и наречия по разметке pymorphy3 (`CONTENT_POS`), кроме местоименных (этот, такой, там, тогда) и вводных (конечно, например) слов (`STOPWORD_GRAMMEMES`). Числительные, числа и латиница знаменательными не считаются.

Параметры:

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `word` | str | `-` | Слово |
