# Командная строка

Команда `ruts` считает статистики текстов без кода на Python: выводит их таблицей, JSON или CSV, целиком или по частям текста, пишет HTML-отчет и загружает словари. Она ставится вместе с библиотекой; `python -m ruts` - то же самое.

``` bash
ruts stats текст.txt
ruts stats -f json глава1.txt глава2.txt
ruts stats -s basic,readability -p sentences -f csv -o предложения.csv текст.txt
cat текст.txt | ruts stats -f json
ruts report текст.txt -t "Мой текст" -o отчет.html
ruts download
```

## Команда { #Command }

<!-- core: cli.md:Command dad88e1 -->
``` {.python .signature}
Command()
```

Командная строка статистик языковой библиотеки. Ее команда `stats` читает тексты из файлов, а без них или для `-` - из стандартного ввода, разбирает каждый текст один раз (`parse`) и выводит статистики классов `stats_classes`:

| Параметр | По умолчанию | Описание |
| :------- | :----------- | :------- |
| `files` | стандартный ввод | Файлы текстов |
| `-s`, `--stats` | классы `default_stats` | Классы статистик по именам через запятую; с `-p` по умолчанию - те из `default_stats`, что считают такие части |
| `-p`, `--parts` | - | `sentences`, `lines` или `paragraphs`: строка на каждую часть ([`by_parts`](https://sergeyshk.github.io/anyTS/stats/stats/#by_parts)); класс из `-s`, который таких частей не считает, - ошибка |
| `-f`, `--format` | `table` | `table` - таблица `print_stats` каждого класса или частей; `json` - плоские статистики каждого класса по текстам, `get_stats(flat=True)`, или записи частей, `nan` и бесконечности - `null`; `csv` - строка на текст или часть текста со столбцом `<класс>.<статистика>` на каждую статистику и 0 для количества распределения, которого у текста нет ([`stats_dataframe`](https://sergeyshk.github.io/anyTS/stats/stats/#stats_dataframe)) |
| `-o`, `--output` | стандартный вывод | Файл вывода; для `-` - стандартный вывод |
| `-e`, `--encoding` | `utf-8-sig` | Кодировка файлов: по умолчанию UTF-8, метка порядка байтов отбрасывается; вывод - в UTF-8 |

Стандартный ввод читается как файл: переводы строки и метка порядка байтов - так же, а таблица выводится по мере подсчета каждого текста.

Ее команда `download` у библиотеки с `datasets` загружает наборы данных, которые нужны ее классам, - названные или все, с `--force` - заново, - и называет каждый на стандартном выводе; набор, который не удалось загрузить, уходит в стандартный поток ошибок с кодом выхода 1, а остальные загружаются.

Ее команда `report` записывает [HTML-отчет](https://sergeyshk.github.io/anyTS/report/) о тексте из файла или стандартного ввода в `-o` или на стандартный вывод, с классами `-s` и заголовком `-t`, `--title`. `-e` - кодировка файла, а отчет - в UTF-8, которую он и объявляет; статистики отчета и его таблицы предложений считаются, как в `stats`. Класс, который не может посчитать текст, в отчет не входит, а его ошибка уходит в стандартный поток ошибок с кодом выхода 1.

`run(argv=None)` запускает команду с аргументами, по умолчанию - командной строки, и возвращает код выхода: 0; 1, если файл не удалось прочитать или записать или класс не смог посчитать текст - его ошибка уходит в стандартный поток ошибок, а остальные тексты и классы считаются, - и если читатель вывода, как `head`, остановился, без сообщения; 2 для неверных аргументов, среди них неизвестной кодировки, со справкой `argparse`; 130 при прерывании.

Дает `ParameterError`, когда подкласс определен с текстами, которые `check_messages` отвергает по `CLI_TEXTS`, или с `default_stats`, где назван класс не из `stats_classes`.

В ruTS текст делит anySeg (`get_document`), а классы `-s` такие:

| Имя | Класс |
| :-- | :---- |
| `basic` | [`BasicStats`](stats/basic_stats.md) |
| `readability` | [`ReadabilityStats`](stats/readability_stats.md) |
| `unadapted_readability` | [`UnadaptedReadabilityStats`](stats/unadapted_readability_stats.md) |
| `diversity` | [`DiversityStats`](stats/diversity_stats.md) |
| `morph` | [`MorphStats`](stats/morph_stats.md) |
| `lexical` | [`LexicalStats`](stats/lexical_stats.md) |
| `style` | [`StyleStats`](stats/style_stats.md) |
| `phon` | [`PhonStats`](stats/phon_stats.md) |
| `cohesion` | [`CohesionStats`](stats/cohesion_stats.md) |
| `verse` | [`VerseStats`](stats/verse_stats.md), только по имени в `-s` |

Синтаксических статистик в команде нет: `SyntaxStats` нужен `Doc` с разбором зависимостей. `ruts download` загружает [частотный словарь](datasets/freq2011.md) `freq2011` для `lexical` и [словарь ударений](datasets/stressdict.md) `stress_dict` для `verse`; без словаря класс не считается, а его ошибка называет эту команду.

## Отчет { #Report }

<!-- core: report.md:Report 11b473b -->
``` {.python .signature}
Report(source, title=None, stats_classes=None, *, skip_errors=False)
```

HTML-отчет о статистиках текста. Текст разбирается один раз (`parse`), каждый класс считает его и его предложения методом `compute`, а разделы идут по `sections`, каждый - метод `section_<name>`, который дает фрагмент HTML:

| Раздел | Содержание |
| :----- | :--------- |
| `statistics` | Таблица на каждый класс `stats_classes` под его заголовком (`titles`): описание каждой статистики `stats_desc`, как у `print_stats`, ее значение - дробное с двумя знаками после запятой, меньшее 0.1 - с двумя значащими цифрами, распределение - парами от самого частого, значения описаны `value_desc`, неопределенное значение - текстом `undefined`, - и ее прочтение (`describe`); классы, пропущенные с `skip_errors`, названы над таблицами |
| `sentences` | Текст каждого предложения со словами, с номером, как на графике их длин, и статистиками `sentence_columns` ([`by_parts`](https://sergeyshk.github.io/anyTS/stats/stats/#by_parts)); без них раздела нет. У текста больше чем из `max_sentences` таких предложений - те, у которых больше всего значение первой статистики, в их порядке |
| `highlight` | Текст, подсвеченный `highlight_class` с его слоями по умолчанию, стили - в заголовке страницы; без него раздела нет |
| `plots` | Графики `plots` в SVG с подписями: по умолчанию длины предложений (`sentence_lengths_plot`), без отметки на каждом предложении у текста больше чем из 300 предложений; у текста без предложений раздела нет |

Стиль - в самой странице, а графики рисуют текст контурами, так что шрифт им не нужен; строятся они без `pyplot`, поэтому команда не открывает окон. Для одного текста страница одна и та же, а идентификаторы ее графиков различаются. Каждый текст источника и статистик проходит через `escape`, так что никогда не становится разметкой.

| Параметр | Тип | По умолчанию | Описание |
| :------- | :-- | :----------- | :------- |
| `source` | `str` / `Doc` / `Document` | - | Источник данных |
| `title` | `str` | `None` | Заголовок отчета; по умолчанию текст `title` |
| `stats_classes` | `dict[str, type[Stats]]` | `None` | Классы статистик по именам; по умолчанию - классы самого класса |
| `skip_errors` | `bool` | `False` | Пропустить класс, который не может посчитать источник, с его ошибкой в `errors`, вместо исключения |

Объект хранит `document`, `title`, статистики каждого класса по имени, `stats`, и ошибки пропущенных классов, `errors`. `to_html()` возвращает страницу, а `save(path)` записывает ее в файл в UTF-8 - кодировке, которую страница объявляет. Источник, который класс не может посчитать, дает ошибку класса, если нет `skip_errors`; `skip_errors`, который не `bool`, дает `ParameterError`.

В ruTS `Report` лежит в `ruts.report`: его классы - `STATS_CLASSES` того же модуля, классы команды без `verse`; столбцы предложений - символы, слова, слоги, индекс удобочитаемости Флеша и водность; подсветка - [`HighlightedText`](visualizers/highlight.md) со слоями по умолчанию.

=== "Код"

    ``` python
    from ruts.report import Report

    report = Report(
        "Кот спит на окне. Пёс громко лает во дворе.", title="Два предложения", skip_errors=True
    )
    report.save("отчет.html")
    report.stats["basic"].n_words, len(report.document.sentences)
    ```

=== "Результат"

    ```
    (9, 2)
    ```
