# Извлечение слов

!!! info ""
    **ruts.extractors.WordsExtractor**

## Описание

<!-- core: extractors/words.md:WordsExtractor 912c6ba -->
Класс для извлечения слов из текста. Позволяет использовать различные токенизаторы, фильтровать стоп-слова, числа и знаки препинания, проводить лемматизацию, формировать N-граммы, а также настраивать минимальную и максимальную длину извлекаемых слов.

## Языковые крючки

Класс расширяет `WordsExtractor` ядра [anyTS](https://sergeyshk.github.io/anyTS/extractors/words/) крючками русского языка: токенизатор `tokenize(text)` - функция `tokenize` библиотеки [razdel](https://github.com/natasha/razdel) с отделением приклеенных к словам тире реплик и без знаков ударения и мягких переносов в словах (`ruts.utils.iter_tokens`), лемма `lemmatize(word)` - первый разбор `MorphAnalyzer` библиотеки [pymorphy3](https://github.com/no-plagiarism/pymorphy3), а шаблон чисел `number_pattern` подходит и к диапазонам, дробям и порядковым числительным: `2020-2021`, `5.5`, `1,5`, `3-й`, `90-х`.

## Параметры

<!-- core: extractors/words.md:WordsExtractor-parameters a447ca0 -->
| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `tokenizer` | Pattern/Callable | `None` | Токенизатор или регулярное выражение; по умолчанию метод `tokenize` |
| `filter_punct` | bool | `True` | Фильтровать знаки препинания |
| `filter_nums` | bool | `False` | Фильтровать числа, подходящие под `number_pattern` |
| `use_lexemes` | bool | `False` | Использовать леммы слов метода `lemmatize` |
| `stopwords` | Collection[str] | `None` | Стоп-слова, сравниваются без учета регистра |
| `lowercase` | bool | `False` | Конвертировать слова в нижний регистр |
| `ngram_range` | Tuple[int, int] | `(1, 1)` | Нижняя и верхняя граница размера N-грамм |
| `min_len` | int | `0` | Минимальная длина извлекаемого слова в символах, `0` - без ограничения |
| `max_len` | int | `0` | Максимальная длина извлекаемого слова в символах, `0` - без ограничения |

!!! note "Примечание"
    Регулярное выражение в роли токенизатора - разделитель: текст режется через `re.split`. Фильтры применяются по порядку: знаки препинания, числа, лемматизация, нижний регистр, стоп-слова, длина слова. Список стоп-слов в нижнем регистре отбрасывает и слово с заглавной буквы в начале предложения. Знак препинания - токен целиком из знаков и символов, в том числе многосимвольный: `?!`, `--`, `…`, `€` (см. `anyts.utils.is_punctuation`). Пустые и пробельные токены отбрасываются до фильтров. N-граммы соединяют слова через `_`.

## Методы

### extract

<!-- core: extractors/words.md:WordsExtractor-extract 67c60e1 -->
Выполняет извлечение слов из текста.

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `text` | str | `-` | Строка текста |

Рассмотрим пример извлечения слов, используя в качестве токенов биграммы, а также выполнив предварительную фильтрацию стоп-слов и чисел и лемматизацию:

!!! example "Пример"

    _Код_:

    ``` python
    # Загрузка библиотеки
    from ruts import WordsExtractor

    # Подготовка данных
    text = "Не имей 100 рублей, а имей 100 друзей"

    # Извлечение слов
    we = WordsExtractor(
        use_lexemes=True, stopwords=["не", "а"], filter_nums=True, ngram_range=(1, 2)
    )
    we.extract(text)
    ```

    _Результат_:

    ``` bash
    ('иметь', 'рубль', 'иметь', 'друг', 'иметь_рубль', 'рубль_иметь', 'иметь_друг')
    ```

### get_most_common

<!-- core: extractors/words.md:WordsExtractor-get_most_common a834177 -->
Возвращает топ-слова текста списком пар (слово, частота), начиная с самого частого.

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `n` | int | `10` | Количество топ-слов |

!!! warning "Предупреждение"
    Метод должен вызываться после извлечения слов методом `extract`.

Для иллюстрации работы метода воспользуемся кодом из предыдущего примера:

!!! example "Пример"

    _Код_:

    ``` python
    ...

    # Вывод топ-слов
    we.get_most_common(3)
    ```

    _Результат_:

    ``` bash
    [('иметь', 2), ('рубль', 1), ('друг', 1)]
    ```
