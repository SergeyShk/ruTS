# Извлечение слов

!!! info ""
    **ruts.extractors.WordsExtractor**

## Описание

<!-- core: extractors/words.md:WordsExtractor 912c6ba -->
Класс для извлечения слов из текста. Позволяет использовать различные токенизаторы, фильтровать стоп-слова, числа и знаки препинания, проводить лемматизацию, формировать N-граммы, а также настраивать минимальную и максимальную длину извлекаемых слов.

## Языковые крючки

Класс расширяет `WordsExtractor` ядра [anyTS](https://sergeyshk.github.io/anyTS/extractors/words/) крючками русского языка: токенизатор `tokenize(text)` - функция `tokenize` библиотеки [razdel](https://github.com/natasha/razdel) с отделением приклеенных к словам тире реплик (`ruts.utils.iter_tokens`), лемма `lemmatize(word)` - первый разбор `MorphAnalyzer` библиотеки [pymorphy3](https://github.com/no-plagiarism/pymorphy3) (`ruts.utils.parse_all`: «её» разбирается как «ее» - у pymorphy3 нет разбора «её» как личного местоимения, «нем» - как «нём», «есть» - как «быть»), а шаблон чисел `number_pattern` подходит и к диапазонам, дробям и порядковым числительным: `2020-2021`, `5.5`, `1,5`, `3-й`, `90-х`. До любого токенизатора из текста снимаются знаки ударения и мягкие переносы, а й и ё из двух символов собираются в одну букву (`ruts.utils.strip_marks`).

## Параметры

<!-- core: extractors/words.md:WordsExtractor-parameters bb58d08 -->
| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `tokenizer` | Pattern/Callable | `None` | Токенизатор или регулярное выражение; по умолчанию метод `tokenize` |
| `filter_punct` | bool | `True` | Фильтровать знаки препинания |
| `filter_nums` | bool | `False` | Фильтровать числа, подходящие под `number_pattern` |
| `use_lexemes` | bool | `False` | Использовать леммы слов метода `lemmatize` |
| `stopwords` | Collection[str] | `None` | Стоп-слова, сравниваются без учета регистра |
| `lowercase` | bool | `False` | Конвертировать слова в нижний регистр |
| `ngram_range` | Tuple[int, int] | `(1, 1)` | Нижняя и верхняя граница размера N-грамм |
| `min_len` | int | `0` | Минимальная длина извлекаемого слова в символах, `0` - без ограничения |
| `max_len` | int | `0` | Максимальная длина извлекаемого слова в символах, `0` - без ограничения |

!!! note "Примечание"
    Регулярное выражение в роли токенизатора - разделитель для `re.split`. Фильтры применяются по порядку: знаки препинания, числа, лемматизация, нижний регистр, стоп-слова, длина слова. Знак препинания - токен только из знаков и символов, в том числе многосимвольный: `?!`, `--`, `…`, `€` (`anyts.utils.is_punctuation`). Пустые и пробельные токены отбрасываются до фильтров. N-граммы соединяют слова через `_`.

`ngram_range`, который не пара целых чисел или чья нижняя граница меньше единицы или больше верхней, дает `ParameterError`, как и граница длины, которая не целое число, отрицательная граница и минимум больше максимума. Стоп-слова, которые не набор строк, дают `SourceTypeError`.

## Методы

### extract

<!-- core: extractors/words.md:WordsExtractor-extract 0455709 -->
Выполняет извлечение слов из текста.

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `text` | str | `-` | Строка текста |

Текст, который не строка, и токенизатор, который нельзя вызвать или который возвращает не строки, дают `SourceTypeError`.

Рассмотрим пример извлечения слов, используя в качестве токенов биграммы, а также выполнив предварительную фильтрацию стоп-слов и чисел и лемматизацию:

!!! example "Пример"

    _Код_:

    ``` python
    # Загрузка библиотеки
    from ruts import WordsExtractor

    # Подготовка данных
    text = "Не имей 100 рублей, а имей 100 друзей"

    # Извлечение слов
    we = WordsExtractor(use_lexemes=True, stopwords=["не", "а"], filter_nums=True, ngram_range=(1, 2))
    we.extract(text)
    ```

    _Результат_:

    ``` bash
    ('иметь', 'рубль', 'иметь', 'друг', 'иметь_рубль', 'рубль_иметь', 'иметь_друг')
    ```

### get_most_common

<!-- core: extractors/words.md:WordsExtractor-get_most_common f1156d0 -->
Возвращает топ-слова текста списком пар (слово, частота), начиная с самого частого; количество, которое не целое число не меньше единицы, дает `ParameterError`.

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `n` | int | `10` | Количество топ-слов |

!!! warning "Предупреждение"
    Метод должен вызываться после извлечения слов методом `extract`.

Для иллюстрации работы метода воспользуемся кодом из предыдущего примера:

!!! example "Пример"

    _Код_:

    ``` python
    ...

    # Вывод топ-слов
    we.get_most_common(3)
    ```

    _Результат_:

    ``` bash
    [('иметь', 2), ('рубль', 1), ('друг', 1)]
    ```
