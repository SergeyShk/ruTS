# Извлечение предложений

!!! info ""
    **ruts.extractors.SentsExtractor**

## Описание

<!-- core: extractors/sentences.md:SentsExtractor 491dff1 -->
Класс для извлечения предложений из текста. Позволяет использовать различные токенизаторы, а также настраивать минимальную и максимальную длину извлекаемых предложений.

## Языковые крючки

Класс расширяет `SentsExtractor` ядра [anyTS](https://sergeyshk.github.io/anyTS/extractors/sentences/) крючком русского языка: его токенизатор по умолчанию, метод `sentenize(text)`, - функция `sentenize` библиотеки [razdel](https://github.com/natasha/razdel).

<!-- core: extractors/sentences.md:SentsExtractor-pipeline 13ed66c -->
!!! note "Примечание"
    В качестве токенизатора можно передать пайплайн spaCy: `tokenizer=lambda text: (sent.text for sent in nlp(text).sents)`.

## Параметры

<!-- core: extractors/sentences.md:SentsExtractor-parameters 9bac08f -->
| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `tokenizer` | Pattern/Callable | `None` | Токенизатор или регулярное выражение; по умолчанию метод `sentenize` |
| `min_len` | int | `0` | Минимальная длина извлекаемого предложения в символах, `0` - без ограничения |
| `max_len` | int | `0` | Максимальная длина извлекаемого предложения в символах, `0` - без ограничения |

!!! note "Примечание"
    Регулярное выражение в роли токенизатора - разделитель для `re.split`. Пустая строка - перевод строки, необязательные пробельные символы и еще один перевод строки - завершает предложение любого токенизатора: текст сначала режется по пустым строкам и каждая часть отдается токенизатору, поэтому заголовок или абзац без конечного знака - отдельное предложение, как и часть без слов, например строка звездочек, которую статистики не считают. С краев предложений до проверки границ длины срезаются пробельные символы, а пустые предложения отбрасываются.

Граница длины, которая не целое число, отрицательная граница и минимум больше максимума дают `ParameterError`.

## Методы

### extract

<!-- core: extractors/sentences.md:SentsExtractor-extract 571604e -->
Выполняет извлечение предложений из текста.

| Параметр | Тип | По умолчанию | Описание |
| :------: | :-: | :----------: | :------: |
| `text` | str | `-` | Строка текста |

Текст, который не строка, и токенизатор, который нельзя вызвать или который возвращает не строки, дают `SourceTypeError`.

Рассмотрим пример извлечения предложений токенизатором по умолчанию:

!!! example "Пример"

    _Код_:

    ``` python
    # Загрузка библиотеки
    from ruts import SentsExtractor

    # Подготовка данных
    text = "Не имей 100 рублей, а имей 100 друзей. Так говорил проф. Иванов... А вы?"

    # Извлечение предложений
    se = SentsExtractor()
    se.extract(text)
    ```

    _Результат_:

    ``` bash
    ('Не имей 100 рублей, а имей 100 друзей.', 'Так говорил проф. Иванов...', 'А вы?')
    ```

Рассмотрим пример извлечения предложений, используя в качестве токенизатора регулярное выражение:

!!! example "Пример"

    _Код_:

    ``` python
    # Загрузка библиотек
    import re
    from ruts import SentsExtractor

    # Подготовка данных
    text = "Не имей 100 рублей, а имей 100 друзей"

    # Извлечение предложений
    se = SentsExtractor(tokenizer=re.compile(r", "))
    se.extract(text)
    ```

    _Результат_:

    ``` bash
    ('Не имей 100 рублей', 'а имей 100 друзей')
    ```
