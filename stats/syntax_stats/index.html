    Синтаксические статистики¶

    SyntaxStats(source)

    Синтаксические статистики текста по его дереву зависимостей (Иванов, Солнышкина и Соловьёв 2018): показатели дерева и синтаксических конструкций. Источник данных - объект Doc библиотеки spaCy с разбором зависимостей и частями речи. Знаки препинания, символы и пробелы узлами дерева не являются, а длины считаются в позициях слов. Единицы L2SCA, предложные цепочки и схожесть предложений вычисляются при первом обращении, поэтому подкласс, в stats_desc которого их нет, не тратит на них время.

    Исключения:

    • SourceTypeError - источник, который не Doc;
    • SourceError - источник без разбора зависимостей (отношений и границ предложений), без частей речи, без лемм, если класс их требует, или без слов.

    Класс расширяет SyntaxStats ядра anyTS русским слоем. Отношения и признаки берутся из разметки Universal Dependencies моделей ru_core_news_sm, ru_core_news_md и ru_core_news_lg; качество статистик ограничено качеством разбора: маленькая модель ru_core_news_sm ошибается в частях речи и связях заметно чаще, чем ru_core_news_lg. Части дефисного слова, разрезанного spaCy, склеиваются (во-первых - одно слово), а клаузы, причастные обороты, отрицания и расщепленные сказуемые определяются по правилам русского языка из карточек метрик. ruTS добавляет свои метрики цепочек родительных падежей и деепричастных оборотов. Синтаксические маркеры канцелярита - пассив, причастные обороты, цепочки родительных падежей, расщепленные сказуемые и отношение существительных к глаголам. Таблица print_stats и сообщения об ошибках - по-русски (SYNTAX_STATS_DESC и CORE_MESSAGES из ruts.constants).

    Иванов, Солнышкина и Соловьёв проверили признаки на корпусе школьных учебников: число сочинительных цепочек, причастных оборотов и модификаторов именной группы коррелирует с классом учебника на уровне 0.88-0.93. Карточки метрик называют исходные признаки работы и их коэффициенты корреляции с классом учебника.

    import spacy
from ruts import SyntaxStats

nlp = spacy.load("ru_core_news_sm")
text = "Дом, построенный рабочими в прошлом году, был продан. Он сказал, что не придёт, и ушёл, хлопнув дверью."
ss = SyntaxStats(nlp(text))
ss.print_stats()

    Метрики¶

    Каждая метрика - атрибут объекта, который вычисляется при его создании (единицы L2SCA, предложные цепочки и схожесть предложений - при первом обращении), а get_stats дает их все. Показатели предложения (наибольшая длина зависимости, глубина, число слов на лист) усредняются по предложениям, конструкции даются на предложение.

    Метрика Что измеряет Диапазон Чем больше, тем
    mean_dependency_distance Среднее расстояние между словом и его вершиной от 1, nan без зависимостей труднее восприятие
    std_dependency_distance Стандартное отклонение длины зависимости от 0, nan без зависимостей неравномернее длины
    max_dependency_distance Среднее наибольших длин зависимости предложений, в которых есть зависимости от 1, nan без зависимостей длиннее самые длинные зависимости
    p_adjacent_dependencies Доля зависимостей длины 1 0-1, nan без зависимостей больше связей между соседями
    tree_depth Средняя глубина дерева предложения от 0 глубже вложенность
    leaves_per_sent Листьев на предложение от 0 длиннее или площе предложения
    subtrees_per_sent Поддеревьев на предложение от 0 больше групп в предложении
    nodes_per_leaf Среднее по предложениям число слов на лист от 1, nan для предложения без листьев длиннее ветви
    words_before_root Среднее число слов до вершины предложения от 0, nan без вершины среди слов позже главное сказуемое
    verb_valency Среднее число зависимых у финитного глагола от 0, nan без финитных глаголов больше зависимых у глагола
    coordination_chains_per_sent Сочинительных цепочек на предложение от 0 больше сочинения
    mean_coordination_chain_len Средняя длина сочинительной цепочки в словах от 2, nan без цепочек длиннее перечисления
    clauses_per_sent Клауз на предложение от 0 больше клауз в предложении
    mean_clause_len Средняя длина клаузы в словах от 1, nan без клауз длиннее клаузы
    subordinate_clauses_per_sent Придаточных клауз на предложение от 0 больше подчинения
    p_complex_sents Доля предложений с придаточной клаузой 0-1 больше сложных предложений
    infinitive_clauses_per_sent Инфинитивных клауз при глаголе на предложение (хочет уйти), которые не придаточные от 0 больше инфинитивных дополнений
    t_units_per_sent T-единиц на предложение (T/S) от 0 больше главных клауз в предложении
    mean_t_unit_len Средняя длина T-единицы в словах (MLT) от 1, nan без T-единиц длиннее T-единицы
    clauses_per_t_unit Клауз на T-единицу (C/T) от 1, nan без T-единиц больше подчинения
    p_complex_t_units Доля T-единиц с придаточной клаузой (CT/T) 0-1, nan без T-единиц больше сложных T-единиц
    verb_phrases_per_t_unit Глагольных групп на T-единицу (VP/T) от 0, nan без T-единиц больше глагольных групп
    coordinate_phrases_per_clause Сочиненных групп на клаузу (CP/C) от 0, nan без клауз больше сочинения групп
    complex_nominals_per_clause Сложных именных групп на клаузу (CN/C) от 0, nan без клауз плотнее именные группы
    modifiers_per_noun Среднее число модификаторов существительного от 0, nan без существительных тяжелее именные группы
    prep_chains_per_sent Цепочек вложенных дополнений с предлогом на предложение от 0 больше вложенных дополнений
    max_prep_chain_len Длина самой длинной предложной цепочки 0 или от 2 длиннее цепочки
    participle_clauses_per_sent Причастных оборотов на предложение от 0 больше причастных оборотов
    mean_participle_clause_len Средняя длина причастного оборота в словах от 1, nan без причастных оборотов длиннее причастные обороты
    p_passive Доля пассивных форм среди глагольных форм 0-1, nan без глагольных форм больше пассива
    p_agentless_passive Доля форм без агенса среди пассивных 0-1, nan без пассивных форм больше пассива без агенса
    infinitives_per_sent Инфинитивов на предложение от 0 больше инфинитивов
    negations_per_sent Слов отрицания на предложение от 0 больше отрицания
    split_predicates_per_sent Расщепленных сказуемых на предложение от 0 больше расщепленных сказуемых
    p_preverbal_subjects Доля именных подлежащих перед вершиной 0-1, nan без именных подлежащих меньше инверсии подлежащих
    p_preverbal_objects Доля именных прямых дополнений перед вершиной 0-1, nan без именных дополнений больше дополнений, вынесенных вперед
    pos_edit_distance Среднее редакционное расстояние частей речи соседних предложений, деленное на длину более длинного 0-1, nan для одного предложения менее схожи предложения
    syntax_similarity Средняя схожесть троек зависимостей соседних предложений 0-1, nan для одного предложения более схожи предложения
    noun_verb_ratio Отношение существительных к глагольным формам от 0, nan без глагольных форм номинативнее стиль

    Метрики конструкций ruTS:

    Метрика Что измеряет Диапазон Чем больше, тем
    genitive_chains_per_sent Цепочек родительных падежей на предложение от 0 больше цепочек

    converb_clauses_per_sent Деепричастных оборотов на предложение от 0 больше деепричастных оборотов
    mean_converb_clause_len Средняя длина деепричастного оборота в словах от 2, nan без деепричастных оборотов длиннее деепричастные обороты

    Длина зависимости¶

    mean_dependency_distance · std_dependency_distance · max_dependency_distance · p_adjacent_dependencies

    calc_dependency_distances(tokens, join_hyphens=False)

    Длины зависимостей (Liu 2008): расстояние между словом и его вершиной в позициях слов без учета знаков препинания, в порядке слов. Вершина предложения и слово, вершина которого лежит вне последовательности, пропускаются.

    Параметр Тип По умолчанию Описание
    tokens Doc / Span / list[Token] - Последовательность токенов
    join_hyphens bool False Считать дефисное слово одной позицией

    Средняя длина зависимости растет с длиной предложения, а наибольшая - лучший из древесных признаков на уровне отдельного предложения. Предложения из одного слова в метрики длин не входят.

    import spacy
from ruts.syntax_stats import calc_dependency_distances

nlp = spacy.load("ru_core_news_sm")
doc = nlp("Повышение эффективности использования ресурсов предприятия обсуждалось на совещании.")
calc_dependency_distances(doc)

    calc_tree_depth(tokens, join_hyphens=False)

    Глубина дерева зависимостей: самый длинный путь от вершины предложения до листа в связях между словами; для нескольких предложений - максимум, для предложения из одного слова - 0. С join_hyphens дефисное слово - одно слово, а слова, которые висят на любой из его частей, - на уровень ниже него.

    Параметр Тип По умолчанию Описание
    tokens Doc / Span / list[Token] - Последовательность токенов
    join_hyphens bool False Считать дефисное слово одним словом

    Глубина - признак LONGEST_PATH работы Иванова и др. (r = 0.84).

    Листья и поддеревья¶

    leaves_per_sent · subtrees_per_sent · nodes_per_leaf

    Лист - слово без зависимых слов (count_children), поддерево - слово с ними. Число узлов на лист - количество слов предложения, деленное на количество его листьев, в среднем по \(S\) предложениям.

    \[ \frac{1}{S} \sum_{s=1}^{S} \frac{\textrm{Количество слов } s}{\textrm{Количество листьев } s} \]

    Признаки работы: LEAVES_NUMBER (r = 0.84), PATH_NUMBER (r = 0.87) и AVERAGE_PATH (r = 0.84). Распределение слов по числу зависимых - профиль ветвления - дает атрибут c_children.

    Слова до вершины предложения¶

    words_before_root · Coh-Metrix

    Левая вложенность Coh-Metrix (SYNLE): число слов предложения до его вершины - главного сказуемого, в среднем по предложениям, вершина которых - слово. Вершина предложения со связкой - его именная часть (она была врачом), как в Universal Dependencies. В языке со свободным порядком слов мера говорит о порядке не меньше, чем о сложности.

    Валентность финитных глаголов¶

    verb_valency

    calc_valency(token, join_hyphens=False)

    Параметр Тип По умолчанию Описание
    token Token - Токен
    join_hyphens bool False Считать дефисное слово одним словом

    Финитный глагол - is_finite_verb; валентность - признак VERBS_DEP работы (r = 0.43).

    Сочинительные цепочки¶

    coordination_chains_per_sent · mean_coordination_chain_len

    calc_coordination_chains(tokens, join_hyphens=False)

    Длины сочинительных цепочек в порядке их первых слов. Цепочка - группа слов, связанных conj, к какому бы слову ни присоединялся каждый однородный член: Universal Dependencies вешает каждый однородный член на первый (груши → яблоки, сливы → яблоки), ClearNLP - на предыдущий (груши → яблоки, сливы → груши); в обоих случаях яблоки, груши и сливы - одна цепочка из трех слов. Вложенное сочинение (кошки и собаки, или птицы) и перечисление, разбитое между несколькими вершинами, - тоже одна цепочка. Длина цепочки - число ее слов; однородный член, вершина которого лежит вне последовательности, с ней не связывается. С join_hyphens дефисное слово - один однородный член, связанный отношением conj любой своей части (членом совета и вице-губернатором - цепочка из двух слов).

    Параметр Тип По умолчанию Описание
    tokens Doc / Span / list[Token] - Последовательность токенов
    join_hyphens bool False Считать дефисное слово одним словом

    Число цепочек на предложение (SOCHIN_NUMBER, r = 0.93) и их средняя длина (AVERAGE_SOCHIN_LENGTH, r = 0.87) - сильнейшие синтаксические предикторы сложности учебника.

    Клаузы¶

    clauses_per_sent · mean_clause_len

    is_clause_head(token)

    Проверяет, возглавляет ли слово клаузу: вершина предложения или слово со связью ccomp, advcl, acl, csubj, parataxis и их подтипами (anyts.constants.CLAUSE_DEPS), кроме полных причастий, деепричастий и инфинитивов при существительном («желание уйти»): причастные и деепричастные обороты считаются отдельно, а краткое причастие («дом построен») - сказуемое своей клаузы. Со связью xcomp клаузу возглавляет только инфинитив is_infinitive_clause: личная форма со связью xcomp у русских моделей - ошибка разбора. Инфинитив-подлежащее (csubj) модального слова («нужно уйти», «можно войти», «следует отметить») своей клаузы не образует. Вставная конструкция (parataxis) и однородное сказуемое (связь conj от вершины клаузы) образуют свою клаузу, только если могут быть сказуемым (is_predicate): «Он сказал: „Уходи“» и «думала, что он умен» - клаузы, а вводные слова «например», «конечно», «во-первых», на которые модели spaCy тоже вешают parataxis, - нет.

    is_infinitive_clause(token)

    Проверяет, возглавляет ли инфинитив со связью xcomp свою клаузу («хочет уйти», «попросил его уйти»): не возглавляет, если образует одну предикацию со своей вершиной (is_infinitive_periphrasis) или стоит в обороте («решивший уйти», «желая уйти»).

    is_infinitive_periphrasis(token)

    Проверяет, образует ли инфинитив одну предикацию со своей вершиной: модальным или фазовым глаголом или модальным словом из INFINITIVE_PERIPHRASES («может уйти», «должен прийти», «начал читать», «взялся читать», «перестал курить», «пришлось уйти», «стоит отметить», «нужно уйти», «можно войти», «пора идти») или побудительным «давай», «давайте» из HORTATIVE_WORDS без отрицания («давайте играть», но не «не давайте детям играть»).

    Параметр Тип По умолчанию Описание
    token Token - Токен

    Инфинитивные клаузы¶

    is_infinitive_clause_head(token)

    Проверяет, возглавляет ли слово инфинитивную клаузу при глаголе: инфинитив со связью xcomp, который образует свою клаузу (is_infinitive_clause: «хочет уйти», «попросил его уйти»), а также однородный ему инфинитив.     Единицы L2SCA¶

    t_units_per_sent · mean_t_unit_len · clauses_per_t_unit · p_complex_t_units · verb_phrases_per_t_unit · coordinate_phrases_per_clause · complex_nominals_per_clause · Lu 2010

    Индексы L2 Syntactic Complexity Analyzer (L2SCA), которых нет среди других метрик, по разметке Universal Dependencies. MLC и C/S - это mean_clause_len и clauses_per_sent; MLS и DC/C получаются из счетчиков: n_words / n_sents и n_subordinate_clauses / n_clauses.

    • T-единица - главная клауза с зависящими от нее клаузами: вершина предложения и каждая вершина клаузы, присоединенная к ней через conj или parataxis (anyts.constants.MAIN_CLAUSE_DEPS), поэтому в я пришел, а он ушел их две; однородный член придаточной клаузы T-единицей не является. Однородный член без собственного подлежащего (я пришел и ушел) - сказуемое, которое делит T-единицу с клаузой, с которой оно сочинено, как в L2SCA, если только его лицо, число или род - его вспомогательного глагола или связки, а без них собственные - не отличаются от лица, числа или рода этой клаузы: в языке, опускающем подлежащее, окончание называет другое подлежащее (llegamos al puerto y nos esperabas). Экзистенциальное there (expl ClearNLP) - подлежащее. T-единица сложная, если в ней есть придаточная клауза (is_subordinate_clause_head), для которой она - ближайшая T-единица сверху.
    • Глагольная группа - сказуемое (is_predicate), которое не является вспомогательным глаголом или связкой: глагол, вспомогательный глагол в роли сказуемого (there is trouble), слово с подлежащим или со связкой.
    • Сочиненная группа - сочинение с однородным членом, который не является вершиной клаузы (мужчина и женщина, был большим и красивым) или является сказуемым без собственного подлежащего (пришел и ушел); она считается один раз, по первому однородному члену, а сочинение клауз с собственными подлежащими считается клаузами.
    • Клаузы - клаузы is_clause_head, как в других метриках: сказуемое с общим подлежащим и инфинитивная клауза считаются клаузами, а L2SCA считает финитные клаузы с подлежащим, поэтому C/T, C/S и CN/C выше, а MLC ниже, чем в L2SCA.
    • Сложная именная группа - существительное с модификатором из anyts.constants.COMPLEX_NOMINAL_DEPS (прилагательным, дополнением, определительной придаточной клаузой или причастным оборотом, приложением, притяжательным словом) или именная клауза - вершина клаузы из anyts.constants.NOMINAL_CLAUSE_DEPS или однородный ей член.
    \[ \textrm{MLT} = \frac{\textrm{Слова}}{\textrm{T-единицы}}, \quad \textrm{C/T} = \frac{\textrm{Клаузы}}{\textrm{T-единицы}}, \quad \textrm{CT/T} = \frac{\textrm{Сложные T-единицы}}{\textrm{T-единицы}}, \quad \textrm{CN/C} = \frac{\textrm{Сложные именные группы}}{\textrm{Клаузы}} \]

    Предложные цепочки¶

    prep_chains_per_sent · max_prep_chain_len · Profiling-UD

    Предложная цепочка - два и более вложенных дополнения с предлогом, каждое из которых висит на предыдущем: на коврике в доме у мэра (длина 3). Звенья - слова крючка is_prep_complement, а цепочки и их длины - те же, что у calc_modifier_chains; цепочка может начинаться с дополнения глагола (obl) или с предложного сказуемого со связкой (был в доме у мэра), но не с однородного члена дополнения (в Мадриде и в доме у моря), а сказуемое определительной придаточной клаузы (дом, который был у реки) звеном цепочки своего существительного не является. Цепочки читают только Universal Dependencies: ClearNLP делает вершиной группы предлог (prep, pobj), поэтому его разборы цепочек не дают.

    Цепочки родительных падежей ruTS (genitive_chains_per_sent) считаются отдельно: их звенья - беспредложные определения в родительном падеже («повышение эффективности использования ресурсов»), а звенья предложной цепочки - дополнения с предлогом.

У глагола берется не больше одной именной части в порядке предпочтения obj, nsubj:pass, nsubj (только у возвратного или пассивного глагола, is_reflexive), iobj, nmod, obl; предложные обстоятельства и агенс пассива (obl:agent, творительный obl) не учитываются.     Схожесть соседних предложений¶

    pos_edit_distance · syntax_similarity · Coh-Metrix

    Насколько схожи структуры двух соседних предложений, в среднем по \(S - 1\) парам. pos_edit_distance - редакционное расстояние частей речи \(P_s\) слов предложений (SYNMEDpos Coh-Metrix), деленное на длину \(n\) более длинного предложения пары, calc_edit_distance. syntax_similarity - схожесть мультимножеств троек зависимостей \(T\) двух предложений (dependency_triples, calc_multiset_similarity) по образцу SYNSTRUT Coh-Metrix, который сравнивает узлы деревьев составляющих.

    \[ \frac{1}{S - 1} \sum_{s=1}^{S-1} \frac{\textrm{lev}(P_s, P_{s+1})}{\max(n_s, n_{s+1})}, \quad \frac{1}{S - 1} \sum_{s=1}^{S-1} \frac{|T_s \cap T_{s+1}|}{|T_s \cup T_{s+1}|} \]

    Отношение существительных к глаголам¶

    noun_verb_ratio

    Количество существительных n_nouns, деленное на количество глагольных форм n_verbs.

    \[ \frac{\textrm{Количество существительных}}{\textrm{Количество глагольных форм}} \]

    Слова последовательности¶

    get_words(tokens, join_hyphens=False)

    Слова последовательности токенов в их порядке; с join_hyphens=True слово, разрезанное токенизатором по дефисам, - одно слово, представленное частью, которая держит его связь, как у зависимых get_children (губернатор в Он вице-губернатор), или первой частью, если связь держит дефис.

    Параметр Тип По умолчанию Описание
    tokens Doc / Span / list[Token] - Последовательность токенов
    join_hyphens bool False Считать дефисное слово одним словом

    Дефисные слова¶

    Токенизатор может разрезать слово по дефисам (во-первых на во, -, первых), и тогда парсер вешает каждую часть на свою вершину. С join_hyphens=True функции дерева считают одним словом вместе с дефисами слово, части которого склеивает anyts.utils.joins_previous. У слова, которое держит вершину предложения, вершины нет; вершина другого слова - вершина его части, которая висит вне слова и ближе всех к корню (при равенстве - слова, а не дефиса). Зависимые слова - слова, чья часть, висящая вне слова, висит на одном из его токенов; каждое представлено этой частью (или своей первой частью, если наружу висит дефис). Поддерево слова - само слово и слова, которые висят на нем прямо или через знаки препинания. Так у каждого слова одна зависимость, и зависит оно от одного слова.

    SyntaxStats и функции русских конструкций всегда склеивают дефисные слова. Функции ядра, в том числе is_predicate, count_noun_modifiers, is_passive, has_agent и is_agentless, по умолчанию принимают join_hyphens=False: значения SyntaxStats они дают с join_hyphens=True.

    Сказуемое клаузы¶

    is_predicate(token, join_hyphens=False)

    Проверяет, может ли слово быть сказуемым своей клаузы: глагол (VERB, AUX), слово с собственным подлежащим (nsubj, csubj и их подтипы, anyts.constants.SUBJECT_DEPS) или со связкой (cop), поэтому именное сказуемое в он высок и в языке, опускающем подлежащее, проходит, а вводное слово - нет.

    Параметр Тип По умолчанию Описание
    token Token - Токен
    join_hyphens bool False Считать дефисное слово одним словом

    Значение, которое не Token, дает SourceTypeError.

    Цепочки модификаторов¶

    calc_modifier_chains(tokens, is_modifier, join_hyphens=False)

    Длины цепочек вложенных модификаторов в порядке слов. Цепочка - два и более модификатора, каждый из которых висит на предыдущем, как дополнения в повышение эффективности использования ресурсов (длина 3); что считать модификатором (дополнение с предлогом, существительное в родительном падеже), решает проверка языка is_modifier. Цепочка начинается с модификатора, вершина которого модификатором не является, а ее длина - число модификаторов в самой длинной ветви. Связи - те же, что у get_children: знак препинания связью не является, а с join_hyphens дефисное слово - одно звено.

    Параметр Тип По умолчанию Описание
    tokens Doc / Span / list[Token] - Последовательность токенов
    is_modifier Callable[[Token], bool] - Является ли слово модификатором цепочки
    join_hyphens bool False Считать дефисное слово одним словом

    Проверка, которую нельзя вызвать, дает SourceTypeError.

    Дополнения с предлогом¶

    is_prep_complement(token, join_hyphens=False)

    Проверяет, является ли слово дополнением с предлогом: слово со связью nmod или obl либо их подтипом (anyts.constants.PREP_COMPLEMENT_DEPS) или сказуемое со связкой вне определительной придаточной клаузы (acl), у которого есть зависимое со связью case - предлог (ADP) или первое слово составного предлога (fixed: в течение). Существительное в падеже без предлога и притяжательный показатель дополнениями с предлогом не являются.

    Параметр Тип По умолчанию Описание
    token Token - Токен
    join_hyphens bool False Считать дефисное слово одним словом

    Значение, которое не Token, дает SourceTypeError.

    Тройки зависимостей¶

    dependency_triples(tokens, join_hyphens=False)

    Тройки зависимостей слов предложения (get_words) в их порядке: часть речи вершины слова - ближайшего слова над ним через знаки препинания, - его отношение без подтипа (base_dep) и его собственная часть речи, например ("NOUN", "amod", "ADJ") для красный дом. Вершина предложения и слово, над которым нет слова, дают пустую вершину и отношение root, какой бы ни была их метка.

    Параметр Тип По умолчанию Описание
    tokens Doc / Span / list[Token] - Последовательность токенов
    join_hyphens bool False Считать дефисное слово одним словом

    Токены, которые не Doc, не Span и не список объектов Token, дают SourceTypeError.

    Редакционное расстояние и схожесть мультимножеств¶

    calc_edit_distance(sents)

    Среднее редакционное расстояние элементов соседних предложений: расстояние Левенштейна каждых двух - наименьшее число вставок, удалений и замен, которые превращают одно в другое, - деленное на число элементов более длинного, 0 для одинаковых последовательностей и 1 для последовательностей без общих элементов; nan, если предложений меньше двух.

    Параметр Тип По умолчанию Описание
    sents list[list] - Элементы каждого предложения, например его части речи

    Предложения, которые не список списков, или элементы, которые нельзя хешировать, дают SourceTypeError.

    calc_multiset_similarity(sents)

    Средняя схожесть мультимножеств элементов соседних предложений: взвешенный коэффициент Жаккара каждых двух - общие элементы, каждый столько раз, сколько он встречается в предложении, где его меньше, деленные на элементы обоих, каждый столько раз, сколько он встречается в предложении, где его больше, - 1 для одинаковых мультимножеств и для двух пустых, 0 для непересекающихся; nan, если предложений меньше двух. Отображение читается по ключам, как множество.

    Параметр Тип По умолчанию Описание
    sents list[list] - Элементы каждого предложения, например его тройки зависимостей

    Предложения, которые не список коллекций, или элементы, которые нельзя хешировать, дают SourceTypeError.
