    Статистики связности¶

    CohesionStats(source, sents_extractor=None, words_extractor=None, connectors=None)

    Статистики связности текста по образцу Coh-Metrix и TAACO: повторы слов в предложениях, данность, темпоральная связность и коннекторы словаря. Предложения сравниваются по леммам. Источник данных - текст или объект Doc библиотеки spaCy.

    Исключения:

    • SourceTypeError - источник, который не строка и не Doc, экстрактор другого типа, коннекторы, которые не словарь словосочетаний и пар строк;
    • SourceError - источник без слов;
    • ParameterError - неизвестный класс или тип коннектора.

    Класс расширяет CohesionStats ядра anyTS русским слоем и, в отличие от ядра, читает и строку. Строка и Doc без границ предложений делятся на предложения русским SentsExtractor; слова строки дает русский WordsExtractor или заданный words_extractor. Для Doc с разметкой частей речи часть речи, время и вид берутся из token.pos_ и token.morph, а лемма - из разбора pymorphy3 с частью речи токена (unit_info); для строки, Doc без разметки и Doc с заданным экстрактором слов - из первого разбора pymorphy3 (words_info), где ответное «нет» - частица. Части дефисного слова, разрезанного spaCy, склеиваются (во-первых - одно слово). Коннекторы ищет RussianConnectorMatcher по словарю load_connectors. Таблица print_stats и сообщения об ошибках - по-русски (COHESION_STATS_DESC и CORE_MESSAGES из ruts.constants).

    Слова классифицируются по разметке pymorphy3 или по разметке Universal Dependencies объекта Doc:

    Понятие pymorphy3 Universal Dependencies (Doc)
    Существительные NOUN NOUN, PROPN
    Местоимения NPRO, Apro, леммы из DEMONSTRATIVE_LEMMAS PRON, DET, леммы из DEMONSTRATIVE_LEMMAS
    Аргументы NOUN, NPRO NOUN, PROPN, PRON
    Знаменательные слова CONTENT_POS без STOPWORD_GRAMMEMES и указательных CONTENT_UD_POS без указательных
    Указательные леммы из DEMONSTRATIVE_LEMMAS: этот, это, тот, такой, таковой, столько, сей, оный те же леммы
    Время и вид граммемы past, pres, futr и perf, impf глагольных форм, время бытийных «нет» и «нету» признаки Tense и Aspect 
    from ruts import CohesionStats

cs = CohesionStats(text)
cs.print_stats()

    Метрики¶

    Каждая метрика - атрибут объекта, который вычисляется при его создании, а повторы в следующих предложениях и абзацах - при первом обращении; get_stats дает метрики из stats_desc, по умолчанию все, кроме mood_repetition. Функции карточек принимают предложение как набор его элементов - лемм существительных, аргументов или знаменательных слов, значений признака его глаголов - и языка не знают.

    argument_overlap_adjacent Доля соседних пар с общим существительным или местоимением 0-1, nan для одного предложения теснее связаны соседние предложения

    Бинарный повтор¶

    noun_overlap_adjacent · noun_overlap_all · argument_overlap_adjacent · argument_overlap_all · content_overlap_adjacent · content_overlap_all · Coh-Metrix

    calc_overlap(sets, adjacent=True)

    Бинарный повтор Coh-Metrix (CRFNO1, CRFAO1, CRFSO1 по соседним парам, CRFNOa, CRFAOa, CRFSOa по всем): доля пар предложений хотя бы с одним общим элементом; для текста короче двух предложений - nan.

    \[ \frac{\textrm{Количество пар с общим элементом}}{\textrm{Количество пар}} \]
    Параметр Тип По умолчанию Описание
    sets list[set[str]] - Элементы каждого предложения
    adjacent bool True Считать только соседние пары, иначе все пары

    Пропорциональный повтор¶

    content_overlap_prop_adjacent · content_overlap_prop_all · Coh-Metrix

    calc_proportional_overlap(sets, adjacent=True)

    Пропорциональный повтор Coh-Metrix (CRFCWO1, CRFCWOa): коэффициент Дайса пары предложений (dice), усредненный по парам; для текста короче двух предложений - nan.

    \[ \frac{1}{\textrm{Количество пар}} \sum_{(A, B)} \textrm{Dice}(A, B) \]
    Параметр Тип По умолчанию Описание
    sets list[set[str]] - Элементы каждого предложения
    adjacent bool True Считать только соседние пары, иначе все пары 
    dice(first, second)

    Коэффициент Дайса двух множеств, 0 для двух пустых множеств.

    \[ \frac{2 \times |A \cap B|}{|A| + |B|} \]
    Параметр Тип По умолчанию Описание
    first frozenset[str] - Первое множество
    second frozenset[str] - Второе множество

    Повтор в следующих предложениях и абзацах¶

    noun_overlap_2_sent · argument_overlap_2_sent · content_overlap_2_sent · noun_overlap_para · argument_overlap_para · content_overlap_para · TAACO

    Соседний повтор TAACO по леммам существительных, аргументов и знаменательных слов: доля разных лемм предложения, повторенных в одном из двух следующих предложений (adjacent_overlap_2_*_sent), и лемм абзаца, повторенных в следующем абзаце (adjacent_overlap_*_para), по всем предложениям или абзацам, у которых они есть (calc_forward_overlap). В отличие от бинарного повтора, пара сегментов учитывается по доле их общих лемм. Абзац - часть текста между пустыми строками, в которой есть слова; его открывает слово с paragraph_start, в том числе внутри предложения, например когда парсер присоединяет заголовок к следующему предложению. TAACO считает абзацем каждую строку: текст, в котором каждый абзац на своей строке, а пустых строк нет, здесь - один абзац, и его *_para равны nan.

    calc_forward_overlap(sets, span=1)

    Доля элементов сегмента, повторенных в следующих: разные элементы каждого сегмента, за которым идут еще span сегментов, встречающиеся в одном из этих сегментов, деленные на разные элементы таких сегментов; если сегментов не больше span или в них нет элементов, значение - nan.

    \[ \frac{\sum_{i=1}^{n-k} |A_i \cap (A_{i+1} \cup \dots \cup A_{i+k})|}{\sum_{i=1}^{n-k} |A_i|} \]
    Параметр Тип По умолчанию Описание
    sets list[set[str]] - Элементы каждого сегмента
    span int 1 Число \(k\) следующих сегментов, с которыми сравнивается сегмент

    Сегменты, которые являются строкой, Doc или итератором, и сегмент, который не список строк, дают SourceTypeError, а span, который не целое число больше 0, - ParameterError.

    В ruTS на абзацы делятся и строка, и Doc.

    from ruts.cohesion_stats import calc_forward_overlap

calc_forward_overlap([{"кот", "окно"}, {"птица"}, {"кот"}], span=2)
text = "Кот сидел на окне. Он смотрел на птиц.\n\nПтицы улетели, и кот уснул. Завтра он снова будет сидеть на этом окне."
paragraphs = CohesionStats(text)
paragraphs.n_paragraphs, paragraphs.noun_overlap_para, paragraphs.content_overlap_para

    Местоимения и указательные¶

    p_pronouns · pronoun_noun_ratio · p_demonstratives

    Местоимения, существительные и указательные - слова, которые так размечает analyze, по умолчанию с признаками word_info.

    \[ \frac{\textrm{Количество местоимений}}{\textrm{Количество слов}}, \quad \frac{\textrm{Количество местоимений}}{\textrm{Количество существительных}}, \quad \frac{\textrm{Количество указательных}}{\textrm{Количество слов}} \]

    В ruTS их размечают функции признаков слова по таблице классов слов.

    Параметр Тип По умолчанию Описание

    Темпоральная связность¶

    tense_repetition · mood_repetition · aspect_repetition · temporal_cohesion · Coh-Metrix

    calc_repetition(sents)

    Повтор времени и вида Coh-Metrix (SMTEMP): доля пар соседних предложений, у глаголов которых одинаковое преобладающее значение признака; пара, в которой у одного из предложений нет глагола с признаком, пропускается, а если ни одной такой пары нет, значение - nan.

    \[ \frac{\textrm{Количество пар с одинаковым преобладающим значением}}{\textrm{Количество пар с признаком}} \]
    Параметр Тип По умолчанию Описание
    sents list[list[str]] - Значения признака глаголов каждого предложения 
    dominant(values)

    Преобладающее значение: самое частое, из равно частых - первое; для пустого списка - None.

    Параметр Тип По умолчанию Описание
    values list[str] - Значения

    Наклонение CohesionStats в ruTS не сравнивает: mood_repetition всегда равен nan, а temporal_cohesion - среднее tense_repetition и aspect_repetition.

    Коннекторы¶

    connectors · connectors_inter · connectors_intra · connectors_<class> · connectors_<kind>

    Вхождения коннекторов, найденных в каждом предложении сопоставителем connector_matcher_class, на 1000 слов. Межпредложенческий коннектор связывает предложение с предыдущими: он открывает предложение, если сопоставитель не считает его подчинительным (is_subordinator) - клауза или группа подчинительного принадлежит тому же предложению; остальные - внутрипредложенческие. Каждый класс и тип сопоставителя дает свою плотность: по умолчанию connectors_causal, connectors_adversative, connectors_concessive, connectors_temporal, connectors_additive, connectors_conditional, connectors_reformulative, connectors_primary и connectors_secondary.

    \[ 1000 \cdot \frac{\textrm{Количество коннекторов}}{\textrm{Количество слов}} \]
    load_connectors()

    Словарь коннекторов ruTS: файл ruts/resources/connectors.tsv - 316 коннекторов с классом из CONNECTOR_CLASSES и типом из CONNECTOR_TYPES модуля ruts.constants, составленных по классификации Криони, Никина и Филипповой (2008) со сверкой по списку маркеров Ru-RSTreebank, базе Рускон и списку причинных маркеров Тольдовой и др. (2018). Однословные «и», «а», «но» входят в словарь, как в Coh-Metrix и TAACO; «что» и «как» коннекторами не считаются.

    Класс Ключ Примеры
    Причинные (включая следственные и целевые) causal потому что, поэтому, в результате, чтобы, таким образом
    Противительные adversative но, однако, зато, с другой стороны, в то же время
    Уступительные concessive хотя, несмотря на, тем не менее, и всё же, в любом случае
    Временные temporal когда, затем, после того как, тем временем, в дальнейшем
    Аддитивные additive и, также, кроме того, более того, например, во-первых
    Условные conditional если, в случае если, при условии что, в противном случае
    Переформулирующие reformulative то есть, иными словами, в общем, подводя итог

    Первичные коннекторы (primary) - союзы, наречия и частицы (потому что, однако, затем), вторичные (secondary) - лексикализованные обороты с существительными и глаголами (в результате этого, с другой стороны, иными словами). Правила, по которым слово словаря считается коннектором, - у сопоставителя.

    Сопоставитель коннекторов¶

    RussianConnectorMatcher(connectors)

    Поиск коннекторов словаря (дискурсивных маркеров: потому что, однако, с другой стороны) в предложениях текста. Словарь задает класс каждого коннектора - причинный, противительный, уступительный, временной, аддитивный, условный или переформулирующий (CONNECTOR_CLASSES) - и его тип, первичный или вторичный (CONNECTOR_KINDS). Коннектор сопоставляется по нормализованным формам его слов: в каждой позиции берется самый длинный, найденные не пересекаются; точку и дефис внутри коннектора токенизатор может отделить (т.е. - т, е). Вхождение - Connector: номер предложения sent, позиции его слов start и end, коннектор text в написании словаря, его класс cls и тип kind.

    Исключения:

    • SourceTypeError - словарь, который не отображение словосочетания в пару строк;
    • ParameterError - неизвестный класс или тип.

    RussianConnectorMatcher - подкласс ConnectorMatcher ядра с правилами русского языка. Слова и коннекторы сравниваются в нижнем регистре без буквы ё и знаков ударения (normalize_yo). Однословному коннектору подходит часть речи из CONNECTOR_POS ядра (CCONJ, SCONJ, PART, ADV, ADP, INTJ, X) или из CONNECTOR_POS_EXTRA для его формы (например: словом - NOUN, главное - ADJ, NOUN, допустим - VERB, точнее - ADJ, т.е. - PUNCT, значит - VERB, ежели и коли - NOUN, PROPN, VERB): «раз» как существительное коннектором не считается. Контекстные правила - списки ruts.constants: слова после коннектора (CONNECTOR_BLOCKED_AFTER: пока что, хоть бы) и перед ним (CONNECTOR_BLOCKED_BEFORE: ещё раз, и так далее), с которыми он не коннектор; коннекторы, которые внутри предложения засчитываются только после отдельных слов (CONNECTOR_ONLY_AFTER: и отсюда) и не засчитываются в его начале (CONNECTOR_NOT_AT_START: вопросительное отчего); части речи слова после коннектора, с которыми он предлог или член предложения (CONNECTOR_BLOCKED_AFTER_POS: после обеда, едва заметный). Через знак препинания правила читают только у CONNECTOR_READ_THROUGH_MARKS (не знал, отчего), так что вводное значит, остается коннектором, а знак между словами коннектора из CONNECTOR_SPLIT_BY_MARKS его разделяет (так, как). Эти части речи и списки - атрибуты сопоставителя: CONNECTOR_POS - pos_tags, остальные - под именем без CONNECTOR_ в нижнем регистре (CONNECTOR_BLOCKED_AFTER - blocked_after); атрибуты not_after_pos и start_only_pos в ruTS пусты, так что эти правила find не действуют.

    find(words, sent_index, pos, breaks, blocked) возвращает вхождения коннекторов в предложении в порядке слов. Слова - слова одного предложения без знаков препинания, первое из них - его начало. С частями речи однословный коннектор засчитывается только при части речи из pos_tags или из pos_extra для его формы, никогда - после части речи из not_after_pos, а с частью речи из start_only_pos - только в начале предложения; слово без части речи (None) проходит. Без частей речи правила, которые их читают, пропускаются. Позиции знаков препинания breaks отделяют коннектор от соседей: правило не читает слово через знак, так что в значит, пойдем слово после запятой не запрещает коннектор и не разрешает его, если коннектор не из read_through_marks, а знак между словами коннектора из split_by_marks делает его не коннектором; без позиций слова читаются как соседние. Ни один коннектор не начинается со слова из blocked, которое язык исключает по большему, чем слова и их части речи, например по своему разбору.

    Параметр Тип По умолчанию Описание
    words list[str] - Слова предложения
    sent_index int 0 Номер предложения для записи во вхождения
    pos list[str] None Части речи слов
    breaks set[int] None Позиции слов, перед которыми стоит знак препинания
    blocked set[int] None Позиции слов, с которых не начинается коннектор

    Слова, которые не список строк, части речи, которые не список строк и None (теги token.pos_ spaCy, а не числа token.pos), и позиции, которые не коллекция, дают SourceTypeError; номер предложения или позиция, которые не целое число, позиция знака, которая не позиция слова после первого, позиция из blocked, которая не позиция слова, и частей речи не столько, сколько слов, - ParameterError.

    is_subordinator(connector, pos=None) проверяет, привязывает ли вхождение коннектора свою клаузу или группу к собственному предложению: коннектор из subordinators или однословный коннектор с частью речи pos SCONJ или ADP, но не из parcellation. Клауза подчинительного союза и группа предлога принадлежат предложению коннектора, где бы он ни стоял, поэтому подчинительный, открывающий предложение (когда он пришел, ..., вопреки ожиданиям, ...), не связывает его с предыдущими. Коннектор, который не Connector, дает SourceTypeError.

    Подчинительные в ruTS сверх однословных с частью речи SCONJ и ADP - CONNECTOR_SUBORDINATORS: многословные союзы и предлоги (так как, после того как, несмотря на) и однословные, которые модели spaCy или pymorphy3 размечают иначе (ежели, коли, пока, раз, хоть, едва). Союз из CONNECTOR_PARCELLATION (ибо) в начале предложения присоединяет его к предыдущему, поэтому подчинительным не считается.

    word_info(word)

    Слова Doc¶

    split_doc_units(source, sents_extractor, join_hyphens=False)

    Разбивает слова Doc или Span по предложениям экстрактора предложений - для Doc без границ предложений или для того, который нужно разбить иначе: предложения находятся в его тексте по порядку, а слово iter_doc_units относится к предложению, в котором лежит его первый токен. Слова вне найденных предложений, отброшенные экстрактором, не учитываются, поэтому если ни одного предложения не найдено, слов нет.

    Параметр Тип По умолчанию Описание
    source Doc / Span - Объект Doc или Span
    sents_extractor SentsExtractor - Инструмент для извлечения предложений
    join_hyphens bool False Склеивать части дефисных слов

    Класс CohesionStats склеивает части дефисных слов всегда, а функция - только с join_hyphens=True.

    unit_text(unit)

    unit_pos(unit)

    unit_text дает текст слова по его токенам без метки порядка байтов, знаков ударения и мягких переносов (ruts.utils.strip_marks), unit_pos - его часть речи UD: для отдельного токена - часть речи токена, для дефисного слова из нескольких токенов - часть речи connector_pos склеенного текста.
